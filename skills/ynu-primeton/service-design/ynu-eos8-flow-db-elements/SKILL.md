# 数据库操作图元（EOS8 服务设计器，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 **服务设计器**的常用图元中，
平台内置了一系列**数据库操作图元**：
**新增数据、更新数据、查询数据、删除数据**（同组还有发起流程、
发送消息图元，分别见各自 skill），支持可视化拖拽配置，
满足数据全生命周期管理。

各图元配置参数（官方「常用图元」文档）：
- **新增数据**：显示名称、目标实体（数据写入的 SDO 对象模型）、
  数据来源（输入数据实体对象，单条或多条——多条用数组/List）、
  来源类型（数据对象结构类型，如 `commonj.sdo.DataObject`
  或实体全类名）、赋值（新增赋值行，右值点 V 图标开选择值弹窗）、
  返回值。
- **更新数据**：目标实体、数据来源、来源类型、
  匹配条件（支持且/或分组；左值=目标实体字段，操作符可选
  =、>、<、>=、<= 等；右值可选常量、变量、表达式或
  数据来源实体字段值）、赋值（操作可选**增加/设置/减少**）、
  **源数据未匹配时策略**（新增/新增赋值/忽略）、返回值。
- **查询数据**：目标实体、匹配条件、排序、分页
  （开启启用分页开关后用 pageIndex/pageSize 传值）；
  数据来源与来源类型不设置。
- **删除数据**：目标实体、数据来源、来源类型、
  匹配条件、返回值（返回已删除数据数量，int）。

补充要点：
- 创建实体类型的逻辑流时，系统自动创建输入参数
  `datasourceName`、`entityName`、`models` 与返回值 `out`。
- 新增/更新支持**子表（1:n）增强操作**：赋值区域点
  「自动设置」自动映射主表字段，加号新增赋值行配子表字段。

流程概览：
确认 IDE 已登录 → AskUserQuestion 确认目标实体与操作 →
作用域确认 → 拖图元入画布并连线 → 配置图元 →
保存 → 执行验证。

**作用域铁律**：仅操作服务设计器中**当前打开的服务编排**，
不碰其他设计器、其他服务；不执行任何删除类按钮。

## When to use

- 用户想在流程/逻辑流里对持久化实体做新增、更新、查询、删除。
- 用户描述「流程里保存数据/查数据/改数据/删数据」等编排需求。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` → **WorkBuddy 模式**：
  用 mcp__browser__* 工具操作；take_snapshot 取可交互元素快照，
  ref 有时效性，画布重渲染后须重取快照；点击前可先对目标元素
  focus 并 sleep 约 2 秒，避免 CDP 超时。
- 工具列表含 integrated_code_mode 的 `Exec`（`await tools.browser_*`）→
  **Trae 模式**：用该运行时操作；同样注意快照 ref 时效性，
  每次操作前重取快照。
- 两者都不可用 → 终止并告知用户当前无可用浏览器运行时。

## 参数

- **目标实体**（必填）：低开中创建的持久化实体。
- **操作类型**（必填）：新增/更新/查询/删除（可多选编排）。
- **数据来源**（按需）：逻辑流入参实体或实体数组，可先定义。
- **匹配条件/赋值映射**（按需）：字段级规则，可后补。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 作用域确认（AskUserQuestion，必经）

确认：「将在服务设计器当前逻辑流中，对实体 <实体名>
执行 <新增/更新/查询/删除> 图元编排，是否继续？」

### Step 3 — 定义参数并拖图元

1. 双击画布空白打开逻辑流属性设置，
   定义实体类型入参（如 `models` 数组）与返回值（如 `out`）。
2. 从元素面板把对应**数据库操作图元**拖入画布
   （落在开始与结束之间），从上一图元拉线连接并连到结束。
   - 画布拖拽若为 HTML5 拖拽，程序化拖拽常失败：
     **两次失败即转用户手动拖拽**，agent 接手配置。

### Step 4 — 配置图元（双击图元打开属性弹窗）

1. 目标实体：下拉选择持久化实体。
2. 数据来源：选择逻辑流入参；来源类型一般自动带出。
3. 按操作类型补齐：
   - 新增：按需加赋值行；未赋值字段默认 null（见 gotchas）。
   - 更新：配匹配条件（左值=实体字段，操作符，右值可取
     数据来源实体字段值）与赋值操作（增加/设置/减少），
     选「源数据未匹配时」策略。
   - 查询：配匹配条件、排序、启用分页（pageIndex/pageSize），
     数据来源不设置。
   - 删除：配匹配条件（如主键 id = 数据来源主键）。
4. 返回值：填逻辑流返回值（如 `out`）。
5. 子表场景：赋值区「自动设置」映射主表字段，
   加号新增行选子表字段对应。

### Step 5 — 保存与执行验证

1. 保存逻辑流。
2. 点击逻辑流编辑器**左上角执行图标**打开执行弹窗，
   输入参数后执行，核对返回的数据对象/数量。
3. 需要观察中间变量：右键图元「设置断点」→ 左上角
   「开启调试」→ 执行查看调试信息。
4. 验证以**返回值实际读出**为准，不以图元配置成功为准。
5. ⚠️ 流程含**删除数据图元**时，执行调试会真实删除
   数据库记录：执行前必须再次向用户确认。

## 不变量

1. **作用域铁律**：只动当前打开的服务编排画布。
2. **删除红线**：IDE 界面任何「删除」按钮/图标/菜单项
   （删图元、删实体、删服务等）严禁点击。
3. **行动后验证**：以执行弹窗返回值实际读出为准。
4. **失败即停**：拖拽两次失败转用户手动；连续失败即报告。

## Notes / gotchas

- **新增赋值字段遗漏**：官方注意事项——新增数据图元如使用
  赋值操作，需对目标实体**所有字段**赋值，未赋值字段默认 null。
- **来源类型**：常见为 `commonj.sdo.DataObject` 或实体全类名，
  通常随数据来源自动选择，勿手改错。
- **删除数据图元 ≠ 删除按钮红线**：配置「删除数据」图元是
  正常业务编排；但红线（严禁点击）指 IDE 界面上的删除按钮/
  图标/菜单项。执行含删除图元的流程前必须用户确认。
- **更新图元赋值操作**：「增加/减少」是左右值相加/相减后
  更新字段，「设置」是直接覆盖。
- **子表方向性**：一个数据来源子表可对应多个目标实体子表，
  反向不行；来源子表删除会联动删除目标子表匹配数据。
- **画布拖拽**：元素面板→画布多为 HTML5 拖拽，
  程序化拖拽常失败，两次失败即请用户手动拖入。
- **ref 时效性**：画布/属性弹窗重渲染后旧 ref 失效，
  操作前重取快照。
- **CDP 超时（仅 WorkBuddy）**：点击前 focus + sleep 约 2 秒。
- **衔接**：发起流程图元与消息图元见
  `ynu-eos8-flow-process-message`；调用远程接口用
  `ynu-eos8-flow-rest`；参数定义细节 `ynu-eos8-flow-io-params`。
