# 分支元素（EOS8 服务设计器，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 服务设计器中为**当前打开的逻辑流**配置
分支（连线条件）。官方要点：
- 除 throws（异常抛出图元）和 End（结束图元）外，
  每个图元支持发出**一根或多根连线**；
  当前图元执行完毕后，条件满足的连线所指向的图元得到执行。
- **默认连线**（连线上无 `*` 符号标识）：不需要设置条件；
  **非默认连线**必须设置简单条件或复杂条件，
  **两者都未设置则保存编译报错**。
- 连线硬规则（文档明确）：
  - 开始图元不能作为连线的**目标**图元；
  - 结束图元不能再连接到其他图元；
  - 除结束/异常图元外，图元后面**至少一根连线**，
    且**有且只能有一条默认连线**；
  - 多条连线同时满足条件时，**只有一条被执行**。
- **简单表达式**：左值 + 比较操作符 + 右值；
  操作符：`==`、`!=`、`>=`、`>`、`<`、`<=`、
  `ObjNotEqual`、`ObjEqual`、`IsNull`、`NotNull`、
  `NullOrEmpty`、`NotNullAndEmpty`；
  右值可为常量、变量或合法 Java 表达式；
  左值支持 XPath（如实体 customer 的 level 属性
  写 `customer/level`）。
- **复杂表达式**：值为 boolean 的 Java 表达式，
  符合 Java 规范、不带分号，如
  `customer.get("level").equals("A")`。

流程概览：确认 IDE 已登录 → AskUserQuestion 确认分支逻辑 →
作用域确认 → 画出多条连线 → 双击连线配置条件 →
保留默认兜底 → 保存执行验证。

**作用域铁律**：仅操作服务设计器中当前打开的服务编排，
不碰其他设计器与其他服务。

## When to use

- 需要按条件走不同处理路径（排他分支）。
- 排查「分支永远不走/条件不生效」类问题。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` → **WorkBuddy 模式**：
  用 mcp__browser__* 工具操作；take_snapshot 取可交互元素快照，
  ref 有时效性，画布/弹窗重渲染后须重取快照；点击前可先对
  目标元素 focus 并 sleep 约 2 秒，避免 CDP 超时。
- 工具列表含 integrated_code_mode 的 `Exec`（`await tools.browser_*`）→
  **Trae 模式**：用该运行时操作；同样注意快照 ref 时效性，
  每次操作前重取快照。
- 两者都不可用 → 终止并告知用户当前无可用浏览器运行时。

## 参数

- **分支逻辑**（必填）：各分支条件与去向
  （如 price<500 走 A，否则走 B）。
- **条件表达式**（必填）：简单表达式（左值/操作符/右值）
  或复杂 Java 表达式；**写入前向用户展示确认**。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 作用域确认（AskUserQuestion，必经）

确认：「将在服务设计器中为 <服务/流程名> 配置分支：
<分支逻辑概述 + 各条件表达式全文>，是否继续？」

### Step 3 — 画出分支连线

1. 确认分支两端图元已在画布就位
   （图元拖拽两次失败转用户手动）。
2. 从源图元拉出**多根连线**分别指向各分支目标图元；
   保留一根**默认连线**指向兜底分支（相当于 else）。

### Step 4 — 配置连线条件

1. **双击**目标连线打开连线配置弹窗。
2. **取消「默认连线」勾选**（勾选着就配不了条件）。
3. 选择条件类型：
   - **简单表达式**：填左值（支持 XPath）、
     比较操作符、右值及右值类别（常量/变量/表达式）；
   - **复杂表达式**：填 Java 表达式
     （boolean、不带分号、**写入前已向用户展示确认**）。
4. 逐条配置其余非默认连线；**保留且仅保留一条默认连线**。

### Step 5 — 保存并执行验证

1. 保存逻辑流（若报「连线未设置条件」类编译错误，
   回查是否有非默认连线漏配条件）。
2. 用不同入参执行多次，断点观察分支走向；
   **以实际走的分支与结果为准**。

## 不变量

1. **作用域铁律**：只动当前打开的服务编排画布。
2. **删除红线**：任何「删除」按钮/图标/菜单项严禁点击
   （含删除连线类入口——本 skill 只配置连线，不删除连线）。
3. **代码红线**：条件表达式写入编辑器前
   必须先向用户展示并确认。
4. **行动后验证**：以断点/执行结果中实际分支走向为准。
5. **失败即停**：连线弹窗两次定位失败即报告。

## Notes / gotchas

- **非默认线漏配条件必报错**：保存编译时报错是首查项。
- **默认连线即兜底**：所有非默认条件都不满足时走默认线；
  只能有一条。
- **多条件同时满足只走一条**：不要指望并行执行。
- **简单表达式只支持单条件**：多条件与/或需用复杂
  Java 表达式表达。
- **Java 表达式不能带分号**。
- **ref 时效性**：连线配置弹窗重渲染后旧 ref 失效，
  操作前重取快照。
- **CDP 超时（仅 WorkBuddy）**：点击前 focus + sleep 约 2 秒。
- **衔接**：循环图元的条件设置同款表达式
  （`ynu-eos8-flow-loop`）；条件逻辑复杂时用脚本图元
  `ynu-eos8-flow-script`。
