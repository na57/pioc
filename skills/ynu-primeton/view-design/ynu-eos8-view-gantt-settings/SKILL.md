# 甘特图设置（EOS8 视图，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 IDE 的**甘特图视图设置面板**中配置甘特图。
本 skill 为**聚合型**：分为**字段绑定**（时间、任务、里程碑、
前置任务、进度，共 5 项）、**通用设置**（时间刻度、表格、
工作日历、悬浮显示、其他、事件，共 6 项）、**颜色设置**
（时间条、分组、进度条、连线，共 4 项）与**分组设置**
（父任务、分组字段、两者共存），合计 15 项。
**按用户指定的单项走对应小节，不要求每次全跑。**

字段绑定的**前置条件**：需先将甘特图所需字段和实体字段绑定。

流程概览：
确认 IDE 已登录 → AskUserQuestion 确认目标甘特图与配置项 →
打开目标视图 → 打开设置面板 → 按配置项走对应小节 → 验证生效。

**作用域铁律**：仅在用户确认的目标甘特图设置面板内操作，
不碰无关资源、不改其他视图配置。

## When to use

- 用户要配置甘特图的字段绑定（时间条、里程碑、前置任务、进度）
  或通用设置（时间刻度、表格、工作日历、悬浮窗、导出、事件等）。
- 用户要自定义甘特图时间条/分组/进度条/连线的颜色。
- 用户要按父子任务或指定字段对甘特图任务分组展示。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` → **WorkBuddy 模式**。
- 工具列表含 integrated_code_mode 的 `Exec`（`await tools.browser_*`）→ **Trae 模式**。
- 两者都没有 → 提示用户启用对应浏览器扩展，终止流程。

## 参数

- **目标甘特图**（必填）：要配置的甘特图视图名称。
- **要配置的项**（必填）：用户指定的配置项，可多项；
  未指定的项一律不碰。
- **字段绑定所需字段名**（按需）：做字段绑定时用户提供
  开始/结束时间、任务、里程碑、前置任务、进度等对应字段。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 作用域确认（AskUserQuestion，必经）

确认：「将在甘特图 <视图名> 的设置面板中配置
<配置项列表>，是否继续？」

### Step 3 — 打开目标甘特图

在 IDE 中打开目标视图（资源树/页面列表定位并打开；
找不到 → AskUserQuestion 请用户指认，不要乱点）。

### Step 4 — 打开视图设置面板（探测式入口）

1. 找视图右上角的「设置」/齿轮入口，点击打开设置面板。
2. 入口具体形态以实际界面为准（截图/快照确认）；
   找不到 → AskUserQuestion 请用户指认，不要乱点。

### Step 5 — 按用户指定的配置项走对应小节

#### 字段绑定（前置：需先将甘特图所需字段和实体字段绑定）

**时间**：绑定开始/结束时间字段；实体字段类型须为
**date 或 timestamp**；绑定后甘特图中**拖拽可改时间**。

**任务**：时间条后面的文字内容字段。

**里程碑**：Boolean 类型字段；图中显示为**菱形**。

**前置任务**：String 类型字段；**逗号分隔**存储多个任务 ID；
前置任务与后置任务之间有连线，**箭头指向后置任务**。

**进度**：Number 类型（0-100）；甘特图中**可拖进度条修改**。

#### 通用设置

**时间刻度**：自定义可选刻度 + 默认选中。

**表格**：左侧表格宽度，或默认隐藏。

**工作日历**：工作时间段以**浅绿色**显示。

**悬浮显示**：Vue 模板编写，hover 时间条弹出浮窗；
可指定显示模式和位置。
⚠️ **Vue 模板代码必须先经用户确认再写入**。

**其他**：展开任务/搜索任务/导出甘特图（整体导出）。

**事件**：自定义时间条颜色 + 自定义点击时间条事件。

#### 颜色设置

可自定义**时间条、分组、进度条、连线**四类元素的颜色。

**时间条**：颜色支持**绑定一个字段**或**设置固定值**；
绑定字段时字段值需遵循 **CSS 标准格式**。

**分组**：分组条颜色指定为一个**固定值**；若分组信息采用
**数据字典**形式，则进度条颜色与数据字典保持一致。

**进度条**：颜色可灵活配置，支持**固定色彩**或**透明度
调节**；若同时设置，**以所选透明度为最终效果**。

**连线**：连线颜色指定为一个**固定值**。

#### 分组设置

允许对任务进行分组展示，支持两种分组方式，**两种方式允许
同时存在**：

**父任务**：设置父任务后，子任务将被移动到父任务的子节点下。

**分组字段**：指定分组字段后，会将任务按字段值分组展示，
**列表和甘特图中都会显示分组信息**；分组信息支持数据来源
配置，可将分组指定为一个**字典/实体/变量**。

**同时设置**：同时设置父任务和分组字段时，两者共同生效，
**以分组字段作为主根**。

### Step 6 — 验证并汇报

1. 行动后验证：以甘特图**实际显示效果**为准
   （时间条/菱形/连线/刻度/工作日历是否按配置显示）。
2. 向用户汇报改了哪些项、生效情况。

## 不变量

1. **作用域铁律**：仅在用户确认的目标甘特图设置面板内操作，
   不碰无关资源与其他视图。
2. **删除红线**：面板中任何「删除」按钮/图标**严禁点击**；
   删除类操作只写红线、转用户手动。
3. **代码确认制**：悬浮显示的 Vue 模板、事件 js 代码，
   写入前必须向用户展示并确认。
4. **行动后验证**：配置项以界面实际生效为准，不以点击成功为准。
5. **失败即停**：同一关键操作两次失败即转用户手动，不反复重试。

## Notes / gotchas

- **字段类型硬性要求**：时间字段须 date/timestamp、里程碑须
  Boolean、前置任务须 String、进度须 Number——绑定前先核对，
  不匹配先告知用户。
- **拖拽操作**：甘特图内拖拽改时间/拖进度条若自动化拖拽失败 →
  请用户手动操作。
- **ref 时效性（Trae）**：操作前后快照变化，重新取 ref。
- **CDP 超时（仅 WorkBuddy）**：点击前 focus + sleep 约 2 秒。
- **Vue 条件渲染 hover 图标可能不渲染**：重试一次，
  仍不出现转用户手动。
- **右键菜单降级路线**：如需右键菜单而自动化无法呼出，转用户手动。
- 找不到目标视图时，可用 `ynu-eos8-view-entity-pages`
  定位实体生成的页面清单。
