# 地图视图设置（EOS8 视图，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 IDE 的**地图视图设置面板**中配置地图。
本 skill 为**聚合型**：覆盖位置字段、图标颜色、显示地址搜索、
标题字段、副标题字段、封面字段、封面位置、显示方式、
图片高度共 9 项。
**按用户指定的单项走对应小节，不要求每次全跑。**

流程概览：
确认 IDE 已登录 → AskUserQuestion 确认目标地图视图与配置项 →
打开目标视图 → 打开设置面板 → 按配置项走对应小节 → 验证生效。

**作用域铁律**：仅在用户确认的目标地图视图设置面板内操作，
不碰无关资源、不改其他视图配置。

## When to use

- 用户要配置地图视图的位置字段、搜索、图标颜色、
  卡片信息与封面展示等。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` → **WorkBuddy 模式**。
- 工具列表含 integrated_code_mode 的 `Exec`（`await tools.browser_*`）→ **Trae 模式**。
- 两者都没有 → 提示用户启用对应浏览器扩展，终止流程。

## 参数

- **目标地图视图**（必填）：要配置的地图视图名称。
- **要配置的项**（必填）：用户指定的配置项，可多项；
  未指定的项一律不碰。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 作用域确认（AskUserQuestion，必经）

确认：「将在地图视图 <视图名> 的设置面板中配置
<配置项列表>，是否继续？」

### Step 3 — 打开目标地图视图

在 IDE 中打开目标视图（资源树/页面列表定位并打开；
找不到 → AskUserQuestion 请用户指认，不要乱点）。

### Step 4 — 打开视图设置面板（探测式入口）

1. 找视图右上角的「设置」/齿轮入口，点击打开设置面板。
2. 入口具体形态以实际界面为准（截图/快照确认）；
   找不到 → AskUserQuestion 请用户指认，不要乱点。

### Step 5 — 按用户指定的配置项走对应小节

**位置字段**：选**一个**定位字段，提取数据显示在地图
（前置：表单中存在绑定**定位组件**的字段）。

**图标颜色**：配置地图图标颜色。

**显示地址搜索**：开关；开启后右上角显示搜索；
点击搜索结果，地图以该地点为中心。

**标题字段**：作为位置显示标题 + 卡片显示标题。

**副标题字段**：长文本字段。

**封面字段**：必须绑定**附件组件**的字段。

**封面位置**：上/左/右。

**显示方式**：填满/完整显示/圆形/矩形；
⚠️ **图片在上方时只支持填满、完整显示**。

**图片高度**：显示方式为**圆形/矩形时不生效**。

**交互说明**（只读提示，非配置项，可向用户解释）：
鼠标放坐标点显示卡片信息；点击结果列表一行显示
当前行卡片信息。

### Step 6 — 验证并汇报

1. 行动后验证：以地图**实际显示效果**为准
   （坐标点、搜索入口、图标颜色、卡片信息是否按配置生效）。
2. 向用户汇报改了哪些项、生效情况。

## 不变量

1. **作用域铁律**：仅在用户确认的目标地图视图设置面板内操作，
   不碰无关资源与其他视图。
2. **删除红线**：面板中任何「删除」按钮/图标**严禁点击**；
   删除类操作只写红线、转用户手动。
3. **行动后验证**：配置项以界面实际生效为准，不以点击成功为准。
4. **失败即停**：同一关键操作两次失败即转用户手动，不反复重试。

## Notes / gotchas

- **字段组件约束**：位置字段须绑定定位组件、封面字段须绑定
  附件组件——先核对再绑定，不满足先告知用户。
- **显示方式联动**：封面在上方时仅支持填满/完整显示；
  圆形/矩形时图片高度不生效——配置前告知用户。
- **ref 时效性（Trae）**：操作前后快照变化，重新取 ref。
- **CDP 超时（仅 WorkBuddy）**：点击前 focus + sleep 约 2 秒。
- **Vue 条件渲染 hover 图标可能不渲染**：重试一次，
  仍不出现转用户手动。
- **右键菜单降级路线**：如需右键菜单而自动化无法呼出，转用户手动。
- 找不到目标视图时，可用 `ynu-eos8-view-entity-pages`
  定位实体生成的页面清单。
- 官方文档：
  https://help.primeton.com/eos/b4dca8c4422b365/lowcode_reference/view_design/map_view/base_set.html
