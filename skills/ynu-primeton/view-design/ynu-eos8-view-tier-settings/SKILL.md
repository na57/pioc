# 层级视图设置（EOS8 视图，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 IDE 的**层级视图设置面板**中配置层级视图。
本 skill 为**聚合型**：覆盖选择关联实体、卡片设置
（标题字段/显示字段/封面字段/封面位置及显示方式/卡片宽度）、
显示方式、根节点显示位置、默认展开层级、视图高度
共 10 项。
**按用户指定的单项走对应小节，不要求每次全跑。**

流程概览：
确认 IDE 已登录 → AskUserQuestion 确认目标层级视图与配置项 →
打开目标视图 → 打开设置面板 → 按配置项走对应小节 → 验证生效。

**作用域铁律**：仅在用户确认的目标层级视图设置面板内操作，
不碰无关资源、不改其他视图配置。

## When to use

- 用户要配置层级视图的关联实体、节点卡片展示、
  展开层级与视图高度等。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` → **WorkBuddy 模式**。
- 工具列表含 integrated_code_mode 的 `Exec`（`await tools.browser_*`）→ **Trae 模式**。
- 两者都没有 → 提示用户启用对应浏览器扩展，终止流程。

## 参数

- **目标层级视图**（必填）：要配置的层级视图名称。
- **要配置的项**（必填）：用户指定的配置项，可多项；
  未指定的项一律不碰。
- **关联实体**（按需）：用户要求配置关联实体时提供
  实体名（须含 1:n 关系）。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 作用域确认（AskUserQuestion，必经）

确认：「将在层级视图 <视图名> 的设置面板中配置
<配置项列表>，是否继续？」

### Step 3 — 打开目标层级视图

在 IDE 中打开目标视图（资源树/页面列表定位并打开；
找不到 → AskUserQuestion 请用户指认，不要乱点）。

### Step 4 — 打开视图设置面板（探测式入口）

1. 找视图右上角的「设置」/齿轮入口，点击打开设置面板。
2. 入口具体形态以实际界面为准（截图/快照确认）；
   找不到 → AskUserQuestion 请用户指认，不要乱点。

### Step 5 — 按用户指定的配置项走对应小节

**选择关联实体**：选**一个或多个**实体；
⚠️ **必须含 1:n 关系**（自关联或一对多）；
关联表单可选；「和子节点关联字段」= 1:n 中的主键
（"1" 端属性）；「和父节点关联字段」= 外键
（"n" 端属性）；每一个实体对应一个卡片设置
（自关联一个卡片设置，多表关联多个）。

**卡片设置**：标题字段 / 显示字段 /
封面字段（必须绑定**附件组件**的字段）/
封面位置及显示方式（同画廊：上方 → 完整显示/填满；
左右 → 另加圆形/矩形）/ 卡片宽度。

**显示方式**：多种可选（以面板实际选项为准）。

**根节点显示位置**：配置根节点的显示位置。

**默认展开层级**：⚠️ **最多加载五层**。

**视图高度**：支持 px/vh/calc
（如 50px、50vh、calc(100vh - 100px)）。

### Step 6 — 验证并汇报

1. 行动后验证：以层级视图**实际显示效果**为准
   （层级树展示、卡片内容/封面、展开层级、高度是否按配置生效）。
2. 向用户汇报改了哪些项、生效情况。

## 不变量

1. **作用域铁律**：仅在用户确认的目标层级视图设置面板内操作，
   不碰无关资源与其他视图。
2. **删除红线**：面板中任何「删除」按钮/图标**严禁点击**；
   删除类操作（如移除关联实体）只写红线、转用户手动。
3. **行动后验证**：配置项以界面实际生效为准，不以点击成功为准。
4. **失败即停**：同一关键操作两次失败即转用户手动，不反复重试。

## Notes / gotchas

- **1:n 关系硬性要求**：关联实体须为自关联或一对多关系；
  绑定前先核对实体关系（可用 `ynu-eos8-create-relation`
  / `ynu-eos8-service-entity-relation` 了解实体关系，
  经用户确认），不满足先告知用户。
- **关联字段语义**：子节点关联字段是"1"端主键、
  父节点关联字段是"n"端外键——不要配反。
- **默认展开层级上限**：最多五层，超出部分不会加载——
  配置前告知用户。
- **ref 时效性（Trae）**：操作前后快照变化，重新取 ref。
- **CDP 超时（仅 WorkBuddy）**：点击前 focus + sleep 约 2 秒。
- **Vue 条件渲染 hover 图标可能不渲染**：重试一次，
  仍不出现转用户手动。
- **右键菜单降级路线**：如需右键菜单而自动化无法呼出，转用户手动。
- 找不到目标视图时，可用 `ynu-eos8-view-entity-pages`
  定位实体生成的页面清单。
