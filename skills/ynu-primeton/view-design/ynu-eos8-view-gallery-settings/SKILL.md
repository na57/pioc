# 画廊视图设置（EOS8 视图，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 IDE 的**画廊视图设置面板**中配置画廊卡片。
本 skill 为**聚合型**：覆盖布局自适应、布局固定占比、字段布局、
标题字段、副标题字段、封面字段、封面位置及显示方式、图片高度、
操作按钮设置共 9 项。
**按用户指定的单项走对应小节，不要求每次全跑。**

流程概览：
确认 IDE 已登录 → AskUserQuestion 确认目标画廊视图与配置项 →
打开目标视图 → 打开设置面板 → 按配置项走对应小节 → 验证生效。

**作用域铁律**：仅在用户确认的目标画廊视图设置面板内操作，
不碰无关资源、不改其他视图配置。

## When to use

- 用户要配置画廊视图的卡片布局、字段展示、封面与操作按钮等。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` → **WorkBuddy 模式**。
- 工具列表含 integrated_code_mode 的 `Exec`（`await tools.browser_*`）→ **Trae 模式**。
- 两者都没有 → 提示用户启用对应浏览器扩展，终止流程。

## 参数

- **目标画廊视图**（必填）：要配置的画廊视图名称。
- **要配置的项**（必填）：用户指定的配置项，可多项；
  未指定的项一律不碰。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 作用域确认（AskUserQuestion，必经）

确认：「将在画廊视图 <视图名> 的设置面板中配置
<配置项列表>，是否继续？」

### Step 3 — 打开目标画廊视图

在 IDE 中打开目标视图（资源树/页面列表定位并打开；
找不到 → AskUserQuestion 请用户指认，不要乱点）。

### Step 4 — 打开视图设置面板（探测式入口）

1. 找视图右上角的「设置」/齿轮入口，点击打开设置面板。
2. 入口具体形态以实际界面为准（截图/快照确认）；
   找不到 → AskUserQuestion 请用户指认，不要乱点。

### Step 5 — 按用户指定的配置项走对应小节

**布局自适应**：配置卡片**最小宽度**（按最小宽度平分取整
决定一行卡片个数）+ 上/下/左/右边距。

**布局固定占比**：一行平均分 6/5/4/3/2 份。

**字段布局**：纵向（一行一字段，从上往下）/
横向（配置占比 n，一行显示 n 个字段值）。

**标题字段**：n:1 模型自动获取显示字段。

**副标题字段**：长文本字段。

**封面字段**：⚠️ **必须选表单中绑定「附件上传」组件的字段**。

**封面位置及显示方式**：位置上/左/右；上方支持
完整显示/填满；左右另支持圆形/矩形。

**图片高度**：显示方式为**圆形或矩形时不生效**。

**操作按钮设置**：折叠 / 平铺居上 / 平铺居下。

### Step 6 — 验证并汇报

1. 行动后验证：以画廊**实际显示效果**为准
   （卡片布局、封面位置/形状、按钮位置是否按配置生效）。
2. 向用户汇报改了哪些项、生效情况。

## 不变量

1. **作用域铁律**：仅在用户确认的目标画廊视图设置面板内操作，
   不碰无关资源与其他视图。
2. **删除红线**：面板中任何「删除」按钮/图标**严禁点击**；
   删除类操作只写红线、转用户手动。
3. **行动后验证**：配置项以界面实际生效为准，不以点击成功为准。
4. **失败即停**：同一关键操作两次失败即转用户手动，不反复重试。

## Notes / gotchas

- **封面字段约束**：先核对所选字段是否绑定了「附件上传」组件，
  未绑定的字段不能作为封面字段——先告知用户。
- **图片高度联动**：显示方式选圆形/矩形时图片高度不生效，
  配置前告知用户避免困惑。
- **ref 时效性（Trae）**：操作前后快照变化，重新取 ref。
- **CDP 超时（仅 WorkBuddy）**：点击前 focus + sleep 约 2 秒。
- **Vue 条件渲染 hover 图标可能不渲染**：重试一次，
  仍不出现转用户手动。
- **右键菜单降级路线**：如需右键菜单而自动化无法呼出，转用户手动。
- 找不到目标视图时，可用 `ynu-eos8-view-entity-pages`
  定位实体生成的页面清单。
- 官方文档：
  https://help.primeton.com/eos/b4dca8c4422b365/lowcode_reference/view_design/card_view/base_set.html
