# 列表视图设置（EOS8 视图，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 IDE 的**列表视图设置面板**中配置列表。本 skill 为
**聚合型**：覆盖基础项（允许编辑、配置持久化、定时刷新、
斑马线、序号、行高及对齐、单选/多选、表尾计算、js 控制
单元格合并、分页、移动端配置、移动端展示、同 PC 端，共
13 项）与进阶项（显示字段与表头、查询条件、高级排序、
导入导出、分享表单、树表设置、高级设置，共 7 组），
合计 20 项。
**按用户指定的单项走对应小节，不要求每次全跑。**

流程概览：
确认 IDE 已登录 → AskUserQuestion 确认目标列表视图与配置项 →
打开目标视图 → 打开设置面板 → 按配置项走对应小节 → 验证生效。

**作用域铁律**：仅在用户确认的目标列表视图设置面板内操作，
不碰无关资源、不改其他视图配置。

## When to use

- 用户要配置/修改某个列表视图的可配置项（行内编辑、样式、
  分页、表尾统计、多选、移动端适配等）。
- 用户要配置显示字段、自定义表头、多级表头、列宽/对齐/
  固定列、单元格颜色、显示格式（链接/图片/图标）。
- 用户要配置查询条件（筛选区显示模式、查询字段、左侧导航、
  高级查询/高开模式）。
- 用户要配置多列排序、Excel 导入导出、分享表单、树表、
  高级设置（方法/参数/生命周期事件/变量/级联查询/代码模式）。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` → **WorkBuddy 模式**。
- 工具列表含 integrated_code_mode 的 `Exec`（`await tools.browser_*`）→ **Trae 模式**。
- 两者都没有 → 提示用户启用对应浏览器扩展，终止流程。

## 参数

- **目标列表视图**（必填）：要配置的列表视图名称。
- **要配置的项**（必填）：用户指定的配置项，可多项；
  未指定的项一律不碰。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 作用域确认（AskUserQuestion，必经）

确认：「将在列表视图 <视图名> 的设置面板中配置
<配置项列表>，是否继续？」
若配置项含「允许编辑」：同时告知 ⚠️
**编辑模式下表单生命周期事件和单业务规则不支持**。

### Step 3 — 打开目标列表视图

在 IDE 中打开目标视图（资源树/页面列表定位并打开；
找不到 → AskUserQuestion 请用户指认，不要乱点）。

### Step 4 — 打开视图设置面板（探测式入口）

1. 找视图右上角的「设置」/齿轮入口，点击打开设置面板。
2. 入口具体形态以实际界面为准（截图/快照确认）；
   找不到 → AskUserQuestion 请用户指认，不要乱点。

### Step 5 — 按用户指定的配置项走对应小节

**允许编辑**：开关开启后，hover 行单元格点击进入编辑模式，
修改触发保存确认框；可配置「每次仅允许编辑一行」。
⚠️ 编辑模式下**表单生命周期事件和单业务规则不支持**。

**配置持久化**：列宽/列顺序/列显示的持久化开关。

**定时刷新**：设置刷新时间。

**斑马线**：默认启用。

**序号**：默认启用；标题默认「#」、宽度 40px。

**行高及对齐**：默认 30px；头部/内容对齐默认居左。

**单选/多选**：多入口配置——① 表格设置中的可选配置；
② 高级设置-事件中 js 初始化；③ 动作设置-工具栏自定义按钮。
全选用 `this.Api.setAllCheckboxRow()`；可按条件控制行是否可勾选；
无有效数据时列头复选框禁用。

**表尾计算**：表格设置-表尾，配置合计/平均值；
「服务端全量统计」开启后计算当前页全部数据。

**js 控制单元格合并**：高级设置-事件中使用
`this.Api.mergeCells()`。

**分页**：默认分页 [10,20,30,50,100]；「不分页」= 关闭分页器会
一次性加载全部数据（⚠️ 大数据量会卡顿，先向用户警示）；
改首次加载条数在高级设置-事件「视图加载前」。

**移动端配置**：显示标题 + 显示列（默认占比 1/2，可调宽，
支持拖拽排序）；仅支持添加当前视图内的字段。

**移动端展示**：视图上方切换按钮或预览模式查看；
行操作默认折叠，需展开。

**同 PC 端**：移动端设置 → 显示方式 → 表格(同PC)。

#### 显示字段与表头

**显示字段**：添加显示字段时可选择**当前表单引用的实体字段**
（表单中已存在并与控件绑定的字段）或**关联实体字段**
（自定义字段时可选实体字段与关联实体字段两种）。

**自定义表头**：开启后可用 HTML 标签和属性替换原有表头名称，
设置文字样式、更改 HTML 标签；支持使用变量作为动态数据，
如 `<div style="color: red">{{v_variable}}</div>`
（v_variable 需在变量中设置）。⚠️ HTML/变量内容先经用户确认。

**表头图标**：视图设置中选择显示字段，点击需要添加图标的
列名，进行表头图标配置。

**多层复合表头**：视图设置-显示字段-添加分组 → 拖拽行数据
至分组当前行或分组内部 → 点击列名可改组名/删除分组 →
拖拽调整布局 → 添加显示列（可选默认项目字段和自定义字段，
自定义字段可改显示名称和绑定列名）→ 样式调整（显示、宽度、
超宽、对齐、格式、锁定、排序）。

**表头背景色**：可按自定义条件显示表头样式（js 按
`column.field` 判断返回 backgroundColor）。⚠️ js 代码先经
用户确认。

**表格设置（列级）**：宽度（默认自适应，支持 px/%，无后缀
默认 px）、内容超宽（省略/折行）、对齐（居左/居中/居右，
默认居左）、固定列（锁定居左/居右，视图超宽滚动时锁定列
优先显示）、排序（默认不排序，可升序/降序）、单元格颜色
（背景色+字体色，可按条件 js 设置）。

**显示设置（格式）**：显示为链接（点击执行代码）、自定义
输入（显示为 checkbox/输入框，格式设为自定义）、显示图片
（字段绑定附件上传组件时，格式设为图片并设宽/高/适配，
**同时需设置视图行高同图片高度**）、图标配置（固定颜色/
主题色/字典配置/条件方法返回）、显示颜色控制（行/单元格/
表头/表尾样式完全自定义）。⚠️ 涉及 js 代码先经用户确认。

#### 查询条件

**显示模式**：展开模式（所有筛选项按顺序展开，可设标签
宽度，点击按钮搜索/重置）、极简模式（隐藏筛选项标签，
点击输入框内图标搜索）、聚合模式（筛选项集成到一个下拉框，
可设默认搜索字段与展开前输入提示，下拉框宽度支持像素/
百分比）。

**筛选条件**：视图设置-快速筛选中新增筛选条件，可选**默认
条件**（从当前显示字段中选择，延续显示时设置的控件类型）
或**自定义条件**（自行选择表单内字段并设置控件类型，可配
组件：文本框/下拉选择器/多选框/单选框/日期范围/人员选择器/
组织选择器）。各条件关系默认「并且(&&)」可切换为
「或者(||)」，条件可拖拽排序。默认值可设常量/字段/变量/
表达式；显示设置可将筛选条件调整为只读或隐藏、调整宽度
占比。自定义条件数据格式：in/not in 用单选格式，
contains/not contains 用多选格式。

**高开模式**：筛选条件转换到代码中（左侧编辑器查
「condition」对象），用于个性化查询场景开发。启用高开模式时
可在【视图设置>高级设置>事件>视图查询前】中 `return false`
**阻止默认查询**。⚠️ 代码先经用户确认。

**左侧导航**：开启后设置导航标题及关联字段，默认导航宽度
1/2，可单独设置宽度占比；**只有具有 datasource 属性的字段**
（人员、员工、树形下拉等下拉组件）可配置侧边树；支持
下拉结构/树形结构；开启「以选中列表作为默认值」后点击
左侧导航会根据点击内容刷新右侧视图。

**高级查询**：通过事件设置查询条件（视图查询前或按钮点击
时调用）：向 `finalCondition.and.items` 添加条件对象
（propertyName/propertyValue/op，op 支持 =、!=、<>、>、<、
>=、<=、like、contains、not contains、between、not between、
null、notnull 等）；非空查询用 `this.condition` 设置字段关系
为 NOTNULL；查询校验可在视图查询前事件 js 拦截
（`this.loading = false; return false`）或用表单嵌套视图做
组合校验。⚠️ 所有代码先经用户确认。

#### 高级排序（多列排序）

按多个列的值对数据排序：主排序列优先，主列同值再按次排序列，
可继续指定第三、四列等多级排序。

**添加排序列**：开启多列排序后选择字段设置多列排序，字段
可拖拽排序、删除、设置升降序；保存后视图按多列排序显示，
常用于设置视图默认展示效果。

**允许用户自定义**：开启后视图工具栏右侧出现多列排序按钮，
用户可自行选择排序字段；可配置让用户可选的排序字段清单。

#### 导入导出

入口：视图设置-动作设置-工具栏-系统按钮-添加**导入/导出**
按钮。

**导入**：支持 xls/xlsx，大小不超过 20M，最多 10000 行、
200 列。

- **下载模版**：导入前需先下载模板，**勿修改模板表格的
  【字段标题】**防止导入失败；下载模板可选部分字段。动作设置
  中编辑导入按钮开启「固定下载模版字段」后，下载模板不再
  弹字段选择，直接按固定字段下载。
- **历史导入记录**：上传成功后在历史导入记录中查看日志。
- **转码配置**：动作设置中编辑导入按钮配置——对导入字段值
  转码后入库（字典：字典名称→字典 code；机构：机构名称→
  机构 id；人员：人员名称→人员 id；实体：实体显示字段名称→
  实体值字段；日期：日期值→格式化后的值）；默认值可设置
  导入字段空值时的默认值（常量/变量/参数）。
- **导入成功后事件**：导入成功后执行的代码（先经用户确认）。
- **多选/部门/成员/字典/实体导入**：支持多选项，Excel 单元格
  内各选项之间用英文逗号「,」隔开。
- **匹配字段**：选字段作为数据匹配依据，**默认以主键字段
  匹配，暂不支持多字段组合匹配**。
- **主子孙多级导入**：只支持 **1:n:n 单条关联线实体**；
  下载模板开启「导入子表数据」（开启后固定下载模板字段默认
  开启）；n 端子字段的转码配置按关联视图中的表单字段显示，
  **添加 n 端字段前必须先在下载模板配置中完成关联视图选择**。

**导出**：

- **导出数据范围**：导出查询的全部数据 / 导出当前页 /
  导出勾选数据。
- **按原始数据导出**：开启后导出 Excel 不翻译显示字段，
  直接导出数据库原始值（字典名称→字典 code、人员名称→
  人员 id 等）。
- **导出字段配置**：允许用户选择时，点击导出按钮弹「请选择
  导出字段」按勾选显示；不允许用户选择时，导出文件表头按
  配置勾选字段直接导出。
- **导出子表数据配置**：只支持 1:n:n 单条关联线实体；开启
  后导出字段配置默认开启、允许用户选择默认关闭；n 端实体
  字段配置关联视图，导出的 n 端子字段按关联视图中的视图
  显示。
- **允许用户选择**：关闭后点击导出按钮不再弹选择配置弹窗，
  按配置直接导出。

#### 分享表单

视图支持通过分享表单收集数据，可设置分享时间和分享密码。

**分享配置**：① 视图设置-动作设置-工具栏添加系统按钮
【分享】，点击配置分享资源权限（默认当前表单实体资源权限
开启且不可关闭；其他实体可开关，可手动添加实体资源，手动
添加的可删除；公共资源如业务字典、机构数据统一开关控制）；
② 分享链接在 **应用中心 → 通用管理 → 首选项 → 低开平台 →
分享** 中配置协议、域名/ip、端口号。

**启用分享**：运行时点击分享按钮启动分享，按首选项配置生成
分享 URL、二维码；设置分享时限后超时无法访问；设置启用密码
后复制的链接自动携带密码。

**分享管理**：分享页面统一在 Afcenter 中管理，**只允许关闭
分享**，启用需通过分享按钮配置。
（应用中心/Afcenter 的配置不在本 skill 操作范围内，引导用户
或另行处理。）

#### 树表设置

树表主要用于**自关联场景**（表中某一列与其他行的同一列
相关联，如员工表的上级领导 pid）。

配置链路：① **建立实体**：主键 id + 额外字段 pid，添加关联
关系（一端选 id 字段，n 端选 pid 字段）；② **配置表单页面**：
pid 字段选下拉选择组件，数据来源绑定该实体，值字段选主键
id；③ **配置视图**：表格类型选择**树表**，关联属性选择 pid；
④ **移动端**：移动端设置中显示方式选「表格(同PC)」。
（实体/表单侧配置不在本 skill 内，引导至对应实体/表单
skill；本 skill 只做视图侧的树表类型与关联属性配置。）

#### 高级设置

处理特定场景或个性化需求：方法绑定、触发条件、自定义参数、
视图事件（生命周期）、自定义变量等，对数据查询条件、返回
结果、展现方式与交互操作进行设置。

**方法设置**：内置方法（视图通用方法模板，可作为基础模板
修改，自行添加执行代码及自定参数；如自定义合计/平均值方法，
前提是表格设置中开启该字段的合计和平均值；合并页脚单元格用
`this.Api.mergeCells([],[{row,col,rowspan,colspan}])`）与
自定义方法（必须设方法名，可传参数，默认异步执行）。方法与
自定义方法设置成功后插入当前视图 methods 中，可在编辑模式
查看。方法内参数可选自定参数或内置参数（当前行数据/索引、
当前列数据/索引等），多参数用逗号分割。

**添加参数**：视图可接受外部参数（URL 传入或表单传入），
参数生成后出现在参数列表中供事件及方法调用。

**生命周期事件**：视图加载前（mounted 之前，查询条件初始化/
变量赋值）、视图查询前（doQuery 之前，动态改查询条件）、
视图查询后（数据返回时，加工返回结果）、视图加载后
（mounted 之后，节点选中/属性处理）、视图全选、视图选中
记录后、视图点击行。事件中可用「选择值」按钮添加内置数据值，
可用「代码助手」选择事件模板（打开新窗口、调用服务、发起
流程等），模板配置后插入代码至当前光标后，可重复引入。

**变量**：添加内部变量，可通过代码区赋默认值或通过方法获取
视图内属性，添加后可在事件的自定义变量中调用；⚠️ 使用引用
变量时须确保引用值已存在或生成。

**级联查询**：设置视图级联深度（最大下钻次数）：-1 无限
级联、0 不做级联（默认）、1 只级联一级；有级联时字段关联
其余视图会以弹窗方式展示。

**代码模式**：切换后可自由编写 Vue 模板，但**表格设置/
显示字段/快速筛选等功能将被禁用**——切换前务必告知用户。

⚠️ 本小节所有 js/Vue 代码写入前必须先向用户展示并确认。

> 涉及 js 代码写入的小节（js 初始化多选、单元格合并、
> 视图加载前改条数）：写入前先向用户展示代码内容并确认。

### Step 6 — 验证并汇报

1. 行动后验证：以列表**实际显示效果**为准
   （开关状态、斑马线/序号/表尾是否生效、编辑模式是否可进）。
2. 向用户汇报改了哪些项、生效情况。

## 不变量

1. **作用域铁律**：仅在用户确认的目标列表视图设置面板内操作，
   不碰无关资源与其他视图。
2. **删除红线**：面板中任何「删除」按钮/图标**严禁点击**；
   删除类操作（如移除显示列等）只写红线、转用户手动。
3. **代码确认制**：涉及 js/Vue/HTML 代码写入的小节（js 初始化
   多选、单元格合并、视图加载前改条数、自定义表头、表头/单元格
   条件样式、高开模式查询、高级查询、导入成功后事件、方法/
   事件/变量、代码模式等），写入前必须向用户展示代码并确认。
4. **行动后验证**：配置项以界面实际生效为准，不以点击成功为准。
5. **失败即停**：同一关键操作两次失败即转用户手动，不反复重试。

## Notes / gotchas

- **拖拽操作**：移动端显示列排序若自动化拖拽失败 →
  请用户手动拖。
- **ref 时效性（Trae）**：操作前后快照变化，重新取 ref。
- **CDP 超时（仅 WorkBuddy）**：点击前 focus + sleep 约 2 秒。
- **Vue 条件渲染 hover 图标可能不渲染**：重试一次，
  仍不出现转用户手动。
- **右键菜单降级路线**：如需右键菜单而自动化无法呼出，转用户手动。
- **编辑模式限制**：允许编辑开启后，表单生命周期事件与
  单业务规则不生效——配置前务必告知用户。
- **代码模式副作用**：切到代码模式后表格设置/显示字段/
  快速筛选被禁用，切换前明确告知用户。
- **显示图片需同步行高**：格式设为图片后必须同时把视图行高
  设为图片高度，否则图片被裁切。
- **导入硬限制**：xls/xlsx、≤20M、≤10000 行、≤200 列；
  模板【字段标题】不可修改；多选项用英文逗号分隔；默认主键
  匹配且不支持多字段组合匹配。
- **主子孙多级导入/导出**：只支持 1:n:n 单条关联线实体；
  导入 n 端字段前必须先在下载模板配置中选关联视图。
- **分享双前置**：需先在应用中心首选项配分享地址，且视图
  工具栏加了分享按钮；分享在 Afcenter 只能关闭、不能启用。
- **左侧导航字段限制**：只有带 datasource 属性的字段（人员、
  员工、树形下拉等）可配侧边树。
- 找不到目标视图时，可用 `ynu-eos8-view-entity-pages`
  定位实体生成的页面清单。
