# 新建流程视图（EOS8 视图设计器，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 IDE 的**视图设计器**中新建一个**流程视图**。
官方描述：流程视图通过选择当前表单关联的流程绑定生成，
显示表单字段之外的流程信息（当前处理人、当前处理机构、
当前活动名称、当前活动到达时间、发起人、发起机构、
发起时间、流程状态）。流程视图允许新建、复制、复制编码和
删除操作，可创建多个流程视图。本 skill **只做「新建」**。

⚠️ **关键前置**：新建时**所选流程必须已开启「同步流程
数据」**，否则无法生成流程视图。

流程概览：
确认 IDE 已登录 → 校验前置（流程已开「同步流程数据」）→
AskUserQuestion 确认视图名称与所选流程 → 快照确认处于
视图设计器 → 视图树「默认视图」右侧「+」→ 新建视图弹框
选「流程」→ 输入视图名称、选择流程 → 保存 → 验证自动生成。

**作用域铁律**：本 skill 仅适用于视图设计器；若当前 IDE
不在视图设计器，立即停止并引导用户先打开对应设计器，
绝不跨设计器操作。

**删除红线**：视图管理操作中的「删除」一律不执行；
本 skill 只走新建流程。

## When to use

- 用户想为实体新建一个流程视图（跟踪/办理流程实例）。
- 用户说「新建流程视图」「加一个流程视图」「创建流程视图」。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` 且能列出浏览器 →
  **WorkBuddy 模式**：用 mcp__browser__* 工具操作；
  take_snapshot 取可交互元素快照；ref 有时效性，
  页面重渲染后须重取快照；点击前可先对目标元素 focus
  并 sleep 约 2 秒，避免 CDP 超时。
- 工具列表含 integrated_code_mode 的 `Exec`
  （`await tools.browser_*` 可用）→ **Trae 模式**：
  用该运行时操作；同样注意快照 ref 时效性，
  每次操作前重取快照。
- 两者都不可用 → 终止并告知用户当前无可用浏览器运行时。

## 参数

- **视图名称**（必填）：新建流程视图的名称。
- **所选流程**（必填）：要绑定的流程；**该流程必须已开启
  「同步流程数据」**。
- **目标实体/页面**（按需）：在哪个实体生成的视图设计器中
  新建；未指明时以当前打开的视图设计器为准。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 前置校验 + 作用域确认（AskUserQuestion，必经）

1. **前置校验（关键）**：向用户确认「所选流程 <流程名>
   是否已开启**同步流程数据**？」
   - 用户确认已开启 → 继续；
   - 未开启/不确定 → 告知用户「未开启同步流程数据的流程
     无法生成流程视图」，请用户先到流程侧开启该开关
     （不属于本 skill 操作范围），开启后再继续。
2. 确认：「将在当前实体的视图设计器中新建流程视图
   <视图名称>，绑定流程 <流程名>，是否继续？」

### Step 3 — 快照确认处于视图设计器

标志性 UI 识别点：视图设计器左侧为**视图树**，树中含
**「默认视图」条目**，条目右侧有 **「+」添加按钮**。
快照中能看到该结构 → 确认作用域正确；看不到 → 停止并请
用户先打开视图设计器，不要乱点。

### Step 4 — 新建流程视图

1. 点击视图树中**「默认视图」条目右侧的「+」添加按钮**，
   打开**新建视图弹框**。
2. 弹框中**选择视图类型为「流程」**。
3. **输入视图名称**（用 Step 2 确认的名称）。
4. **选择流程**（用 Step 2 确认的流程；下拉/选择器中
   定位流程名，找不到对应流程 → 回到 Step 2 与用户核实，
   不要瞎选）。
5. **点击保存按钮**，系统将自动生成一个新的流程视图。

**验证**：保存后快照确认——视图树中出现新流程视图条目，
画布自动生成并打开该流程视图。未出现条目 → 视为失败，
按「失败即停」处理；若保存报错与流程数据同步相关，
优先怀疑「同步流程数据」未开启，回到 Step 2。

### Step 5 — 汇报

向用户汇报：新建的视图名称、绑定的流程、视图树条目已生成；
提示流程视图的记录操作（发起、批量办理、终止、挂起、
查看流程）可走 `ynu-eos8-view-flow-operations`。

## 不变量

1. **作用域铁律**：仅在视图设计器内操作，不跨设计器、
   不碰无关资源。
2. **删除红线**：任何「删除」按钮/图标/菜单项**严禁点击**；
   复制、复制编码等非新建管理操作不执行。
3. **行动后验证**：以视图树新条目为准，不以保存按钮
   点击成功为准。
4. **失败即停**：同一关键操作两次尝试仍失败 → 停止并
   报告现场，不盲目重试、不绕路。

## Notes / gotchas

- **「同步流程数据」是硬前置（最高频踩坑）**：流程未开启
  该开关时无法生成流程视图——Step 2 必须先确认；
  保存失败时报错与流程数据相关，优先怀疑此开关。
- **新建视图弹框是 Ant Design 弹层**：渲染在 body 下，
  定位时在整页快照中找，不要局限在「+」按钮附近。
- **流程选择器可能是弹层/下拉**：同样在整页快照中定位；
  流程名相似时仔细核对，选错流程会导致视图绑错数据。
- **ref 时效性（Trae）**：弹框打开、保存后页面重渲染，
  旧 ref 失效，点击前重新获取快照。
- **CDP 超时（仅 WorkBuddy）**：点击前先 focus 目标元素
  并 sleep 约 2 秒再 click。
- 后续流程视图记录操作 → `ynu-eos8-view-flow-operations`。
