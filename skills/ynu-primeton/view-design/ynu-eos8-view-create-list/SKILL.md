# 新建 / 复制列表视图（EOS8 视图设计器，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 IDE 的**视图设计器**中新建或复制**列表（表格）视图**。
官方描述：列表视图允许用户进行新建、复制、复制编码和删除
操作，并且可以创建多个列表视图。**注意：页面生成时第一个
列表视图（默认视图）不允许进行修改和删除操作。**
本 skill **只做新建、复制、复制编码**。

流程概览：
确认 IDE 已登录 → AskUserQuestion 确认操作类型与视图名称 →
快照确认处于视图设计器 → 新建：默认视图右侧「+」→ 选表格 →
输名称保存；复制：视图左侧倒三角菜单 → 复制/复制编码 →
保存跳转 → 验证生成。

**作用域铁律**：本 skill 仅适用于视图设计器；若当前 IDE
不在视图设计器，立即停止并引导用户先打开对应设计器，
绝不跨设计器操作。

**删除红线**：「更多配置」菜单中的「删除」项**严禁点击**；
本 skill 不执行任何删除操作。

## When to use

- 用户想为实体新建一个列表（表格）视图。
- 用户想复制一个已有列表视图，或复制视图编码。
- 用户说「新建列表视图」「加一个表格视图」「复制这个视图」。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` 且能列出浏览器 →
  **WorkBuddy 模式**：用 mcp__browser__* 工具操作；
  take_snapshot 取可交互元素快照；ref 有时效性，
  页面重渲染后须重取快照；点击前可先对目标元素 focus
  并 sleep 约 2 秒，避免 CDP 超时。
- 工具列表含 integrated_code_mode 的 `Exec`
  （`await tools.browser_*` 可用）→ **Trae 模式**：
  用该运行时操作；同样注意快照 ref 时效性，
  每次操作前重取快照。
- 两者都不可用 → 终止并告知用户当前无可用浏览器运行时。

## 参数

- **操作类型**（必填）：`新建` / `复制` / `复制编码`。
- **视图名称**（新建、复制时必填）：新列表视图的名称。
- **源视图**（复制、复制编码时必填）：要复制的已有视图。
- **目标实体/页面**（按需）：在哪个实体生成的视图设计器中
  操作；未指明时以当前打开的视图设计器为准。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 作用域确认（AskUserQuestion，必经）

确认：「将在当前实体的视图设计器中<操作类型>列表视图
<视图名称>，是否继续？」

### Step 3 — 快照确认处于视图设计器

标志性 UI 识别点：视图设计器左侧为**视图树**，树中含
**「默认视图」条目**，条目右侧有 **「+」添加按钮**。
快照中能看到该结构 → 确认作用域正确；看不到 → 停止并请
用户先打开视图设计器，不要乱点。

### Step 4 — 按操作类型走对应小节

#### 4.1 新建列表视图

1. 点击视图树中**「默认视图」条目右侧的「+」添加按钮**，
   打开**新建视图弹框**。
2. 弹框中**选择视图类型为「表格」**。
3. **输入视图名称**（必填项，用 Step 2 确认的名称）。
4. **点击保存按钮**，系统自动生成一个新的列表视图。
5. 说明：保存后新的「+」添加按钮会出现在**最后一个视图
   后面**（下次再建视图时入口位置随之后移）。

**验证**：保存后快照确认——视图树中出现新列表视图条目，
画布自动生成并打开该视图。未出现条目 → 视为失败，
按「失败即停」处理。

#### 4.2 复制视图

1. **选中需要操作的源视图**。
2. 在选中的视图**左侧**，点击**倒三角图标的「更多配置」
   按钮**，系统打开一个菜单。
3. 在菜单中选择**「复制」**操作。
4. 系统弹出**复制视图弹框**：选择视图类型并输入新的视图
   名称（用 Step 2 确认的名称）。
5. **保存后系统自动跳转**到复制后的视图。

**验证**：快照确认已跳转到复制后的新视图，视图树中出现
新条目。

#### 4.3 复制编码

1. 选中需要操作的源视图，点击左侧**倒三角「更多配置」**
   按钮打开菜单。
2. 直接点击**「复制编码」**操作。
3. **验证**：向用户汇报编码已复制（剪贴板内容可由用户
   粘贴确认；agent 不主动读取系统剪贴板）。

⚠️ 菜单中同时存在**「删除」**项——**严禁点击**，
定位菜单项时务必认准「复制」/「复制编码」文字。

### Step 5 — 汇报

向用户汇报：操作类型、新视图名称/复制的编码、视图树条目
已生成、当前已跳转位置。

## 不变量

1. **作用域铁律**：仅在视图设计器内操作，不跨设计器、
   不碰无关资源。
2. **默认视图保护**：页面生成时第一个列表视图（默认视图）
   **不允许修改和删除**——不对默认视图执行任何修改类操作；
   用户要求改默认视图时告知该限制。
3. **删除红线**：「更多配置」菜单中的「删除」项
   **严禁点击**；本 skill 只执行新建/复制/复制编码。
4. **行动后验证**：以视图树新条目/自动跳转结果为准，
   不以保存按钮点击成功为准。
5. **失败即停**：同一关键操作两次尝试仍失败 → 停止并
   报告现场，不盲目重试、不绕路。

## Notes / gotchas

- **「+」按钮位置会移动**：新建保存后，「+」出现在最后一个
  视图后面——连续新建多个视图时，每次都重取快照定位最新的
  「+」，不要用旧位置。
- **新建视图弹框是 Ant Design 弹层**：渲染在 body 下，
  定位时在整页快照中找，不要局限在「+」按钮附近。
- **倒三角菜单是弹层**：「更多配置」菜单同样渲染在 body 下；
  且菜单含「删除」项，点击前务必核对菜单项文字。
- **ref 时效性（Trae）**：弹框打开、保存跳转后页面重渲染，
  旧 ref 失效，点击前重新获取快照。
- **CDP 超时（仅 WorkBuddy）**：点击前先 focus 目标元素
  并 sleep 约 2 秒再 click。
- 后续配置列表视图各项设置，可参考 `ynu-eos8-view-list-settings`。
