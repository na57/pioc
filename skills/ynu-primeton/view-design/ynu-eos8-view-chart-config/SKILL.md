# 图表视图配置（EOS8 视图，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 IDE 的**图表视图设置面板**中配置图表。本 skill 为**聚合型**：
覆盖图表类型、维度、数值、增加 Y 轴、标题、图例位置、颜色、X/Y 轴、
辅助线，以及柱状/条形、折线、饼图、漏斗、雷达的特有配置共 19 项。
**按用户指定的单项走对应小节，不要求每次全跑。**

流程概览：
确认 IDE 已登录 → AskUserQuestion 确认目标图表视图与配置项 →
打开目标视图 → 打开设置面板 → 按配置项走对应小节 → 验证生效。

**作用域铁律**：仅在用户确认的目标图表视图设置面板内操作，
不碰无关资源、不改其他视图配置。

## When to use

- 用户要配置/修改某个图表视图的可配置项（类型、维度/数值、
  坐标轴、标题、图例、颜色、辅助线、各图表类型特有项等）。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` → **WorkBuddy 模式**。
- 工具列表含 integrated_code_mode 的 `Exec`（`await tools.browser_*`）→ **Trae 模式**。
- 两者都没有 → 提示用户启用对应浏览器扩展，终止流程。

## 参数

- **目标图表视图**（必填）：要配置的图表视图名称。
- **要配置的项**（必填）：用户指定的配置项，可多项；
  未指定的项一律不碰。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 作用域确认（AskUserQuestion，必经）

确认：「将在图表视图 <视图名> 的设置面板中配置
<配置项列表>，是否继续？」

### Step 3 — 打开目标图表视图

在 IDE 中打开目标视图（资源树/页面列表定位并打开；
找不到 → AskUserQuestion 请用户指认，不要乱点）。

### Step 4 — 打开视图设置面板（探测式入口）

1. 找视图右上角的「设置」/齿轮入口，点击打开设置面板。
2. 入口具体形态以实际界面为准（截图/快照确认）；
   找不到 → AskUserQuestion 请用户指认，不要乱点。

### Step 5 — 按用户指定的配置项走对应小节

**图表类型**：点击类型图标切换；切换后图表**即时重渲染**，
操作前重取快照。

**维度**：拖数据源字段入维度区。柱状/折线/散点图 = X 轴，
可多选；饼图/雷达/仪表盘为单选。

**数值**：拖字段入数值区（Y 轴），可多选。

**增加 Y 轴**：数值区下拉按钮 → 「增加Y轴」→ 点展开按钮配置
（是否显示/刻度/最大值/最小值/偏移/标题）→ 新选项出现在下拉中 →
绑定到对应 Y 轴。

**标题**：数据标签（顶部数值文字）开关；一级/二级标题显示开关；
标题位置（居左/居中/居右）。

**图例位置**：横向（左/中/右）；纵向（上/中/下）。

**颜色**：点色盘选色后确定。颜色 **9 个一组**按顺序对应数值项，
**超出 9 个从首位循环**（第 10 项复用第 1 色）。

**X 轴**：数据标签（底部 label）开关、标题、文字倾斜
（下拉选角度或自定义角度）。

**Y 轴**：刻度标签开关、最大值、最小值。

**辅助线**：点「添加辅助线」→ 选固定值（选一条数值 + 输入基准值）
或动态值（最大/平均/最小）；可编辑多条。
⚠️ **删除辅助线只写红线**：需要删除时告知用户手动操作，严禁代点。

**柱状/条形图**：勾选堆叠。

**折线图**：曲线开关、面积开关（可叠加）。

**饼图**：环形/细环形配置；数据标签单独配置。

**漏斗**：模式三选一——默认（数据顺序上→下）/ 真实（按值大小，
不规则）/ 反转（下→上）；底部样式：平滑=梯形、尖锐=锥形
（默认尖锐）。

**雷达**：填充开关。

### Step 6 — 验证并汇报

1. 行动后验证：以图表**实际重渲染效果**为准（标题/图例/颜色/
   辅助线是否按配置显示），不以点击成功为准。
2. 向用户汇报改了哪些项、生效情况。

## 不变量

1. **作用域铁律**：仅在用户确认的目标图表视图设置面板内操作，
   不碰无关资源与其他视图。
2. **删除红线**：辅助线的「删除」以及面板中任何「删除」按钮/图标
   **严禁点击**；删除类操作只写红线、转用户手动。
3. **行动后验证**：配置项以界面实际生效（重渲染结果）为准。
4. **失败即停**：同一关键操作两次失败即转用户手动，不反复重试。

## Notes / gotchas

- **拖拽操作**：维度/数值字段拖入若自动化拖拽失败 → 请用户手动拖，
  agent 接手后续配置。
- **即时重渲染**：切换类型/配置后面板结构可能变化，
  操作前重取快照。
- **ref 时效性（Trae）**：操作前后快照变化，重新取 ref。
- **CDP 超时（仅 WorkBuddy）**：点击前 focus + sleep 约 2 秒。
- **Vue 条件渲染 hover 图标可能不渲染**：重试一次，
  仍不出现转用户手动。
- **右键菜单降级路线**：如需右键菜单而自动化无法呼出，转用户手动。
- **删除红线**：设置面板中任何「删除」按钮/图标严禁点击。
- 找不到目标视图时，可用 `ynu-eos8-view-entity-pages`
  定位实体生成的页面清单。
- 官方文档：
  https://help.primeton.com/eos/b4dca8c4422b365/lowcode_reference/charts_configuration/edit_chartView.html
