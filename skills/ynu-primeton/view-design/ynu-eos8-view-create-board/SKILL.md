# 新建看板视图（EOS8 视图设计器，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 IDE 的**视图设计器**中新建一个**看板视图**。
官方描述：看板视图允许用户进行新建、复制、复制编码和删除
操作，并且可以创建多个看板视图。本 skill **只做「新建」**。

流程概览：
确认 IDE 已登录 → AskUserQuestion 确认视图名称 →
快照确认处于视图设计器 → 提示分组字段前置 →
视图树「默认视图」右侧 + → 新建视图弹框选看板 →
输入名称 → 保存 → 验证自动生成。

**作用域铁律**：本 skill 仅适用于视图设计器；若当前 IDE
不在视图设计器，立即停止并引导用户先打开对应设计器，
绝不跨设计器操作。

**删除红线**：视图管理操作中的「删除」（含复制、复制编码
等非新建操作）一律不执行；本 skill 只走新建流程。

## When to use

- 用户想为实体新建一个看板视图。
- 用户说「新建看板视图」「加一个看板」「创建看板」。
- 用户想按分组列管理记录（类 Kanban），需要先建看板视图。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` 且能列出浏览器 →
  **WorkBuddy 模式**：用 mcp__browser__* 工具操作；
  take_snapshot 取可交互元素快照；ref 有时效性，
  页面重渲染后须重取快照；点击前可先对目标元素 focus
  并 sleep 约 2 秒，避免 CDP 超时。
- 工具列表含 integrated_code_mode 的 `Exec`
  （`await tools.browser_*` 可用）→ **Trae 模式**：
  用该运行时操作；同样注意快照 ref 时效性，
  每次操作前重取快照。
- 两者都不可用 → 终止并告知用户当前无可用浏览器运行时。

## 参数

- **视图名称**（必填）：新建看板视图的名称。
- **目标实体/页面**（按需）：在哪个实体生成的视图设计器中
  新建；未指明时以当前打开的视图设计器为准。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 作用域确认（AskUserQuestion，必经）

确认：「将在当前实体的视图设计器中新建看板视图
<视图名称>，是否继续？」
同时说明：新建后的看板需在设置中配置分组字段才会显示
分组列（见 Step 6），先向用户确认分组字段意向。

### Step 3 — 快照确认处于视图设计器

标志性 UI 识别点（来自文档）：视图设计器左侧为**视图树**，
树中含**「默认视图」条目**，条目右侧有 **「+」添加按钮**。
快照中能看到该结构 → 确认作用域正确；
看不到 → 停止并请用户先打开视图设计器，不要乱点。

### Step 4 — 前置说明：封面与分组字段

1. **封面（可选）**：看板视图的对应表单，有一个字段绑定
   **附件上传**组件进行图片信息的录入，可以作为看板视图
   的卡片封面图。无此字段也可创建，仅卡片无封面图。
2. **分组字段（必需，创建后配置）**：看板需设置分组字段，
   未设置分组字段时视图显示为空白页。提前向用户说明，
   避免把空白页误判为创建失败。

### Step 5 — 新建看板视图

1. 点击视图树中**「默认视图」条目右侧的「+」添加按钮**，
   打开**新建视图弹框**。
2. 弹框中**选择视图类型为「看板」**。
3. **输入视图名称**（用 Step 2 确认的名称）。
4. **点击保存按钮**，系统将自动生成一个新的看板视图。

**验证**：保存后快照确认——视图树中出现新看板视图条目，
画布自动生成并打开该看板视图。**此时画布为空白页属正常**
（未配置分组字段），判定成功与否看视图树条目，
不看画布内容。未出现条目 → 视为失败，按「失败即停」处理。

### Step 6 — 分组字段提醒并汇报

1. 提醒用户：新看板未选择分组字段，显示为空白页；
   需到该看板视图的设置面板配置**分组字段**后，
   分组列才会显示。
2. 向用户汇报：新建的视图名称、类型、视图树条目已生成、
   画布空白的原因与下一步。

## 不变量

1. **作用域铁律**：仅在视图设计器内操作，不跨设计器、
   不碰无关资源。
2. **删除红线**：任何「删除」按钮/图标/菜单项**严禁点击**；
   复制、复制编码等非新建管理操作不执行。
3. **行动后验证**：以视图树新条目为准（画布空白≠失败），
   不以保存按钮点击成功为准。
4. **失败即停**：同一关键操作两次尝试仍失败 → 停止并
   报告现场，不盲目重试、不绕路。

## Notes / gotchas

- **空白页陷阱（最高频）**：新看板视图未配置分组字段时
  画布是空白页——这是文档明确的正常现象，不是创建失败；
  不要因此重试创建或误报错误。
- **分组字段自动配置项**：分组字段为字典、实体、自定义
  变量、1:n 实体时，设置面板会自动显示对应的配置项。
- **新建视图弹框是 Ant Design 弹层**：渲染在 body 下，
  定位时在整页快照中找，不要局限在「+」按钮附近。
- **ref 时效性（Trae）**：弹框打开、保存后页面重渲染，
  旧 ref 失效，点击前重新获取快照。
- **CDP 超时（仅 WorkBuddy）**：点击前先 focus 目标元素
  并 sleep 约 2 秒再 click。
- 后续在设置面板配置分组字段、布局、卡片等，可参考
  看板设置官方文档：
