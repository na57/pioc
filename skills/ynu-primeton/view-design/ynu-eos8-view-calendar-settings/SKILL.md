# 日历视图设置（EOS8 视图，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 IDE 的**日历视图设置面板**中配置日历。
本 skill 为**聚合型**：覆盖开始日期字段、结束日期字段、
记录显示字段、自定义模板、显示首尾两端、自定义卡片颜色
共 6 项。
**按用户指定的单项走对应小节，不要求每次全跑。**

流程概览：
确认 IDE 已登录 → AskUserQuestion 确认目标日历视图与配置项 →
打开目标视图 → 打开设置面板 → 按配置项走对应小节 → 验证生效。

**作用域铁律**：仅在用户确认的目标日历视图设置面板内操作，
不碰无关资源、不改其他视图配置。

## When to use

- 用户要配置日历视图的日期字段绑定、记录条展示样式、
  自定义模板与卡片颜色。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` → **WorkBuddy 模式**。
- 工具列表含 integrated_code_mode 的 `Exec`（`await tools.browser_*`）→ **Trae 模式**。
- 两者都没有 → 提示用户启用对应浏览器扩展，终止流程。

## 参数

- **目标日历视图**（必填）：要配置的日历视图名称。
- **要配置的项**（必填）：用户指定的配置项，可多项；
  未指定的项一律不碰。
- **自定义模板内容**（按需）：用户要求配置自定义模板时，
  由用户提供模板代码/需求。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 作用域确认（AskUserQuestion，必经）

确认：「将在日历视图 <视图名> 的设置面板中配置
<配置项列表>，是否继续？」
若涉及自定义模板：说明代码会先展示给用户确认后再写入。

### Step 3 — 打开目标日历视图

在 IDE 中打开目标视图（资源树/页面列表定位并打开；
找不到 → AskUserQuestion 请用户指认，不要乱点）。

### Step 4 — 打开视图设置面板（探测式入口）

1. 找视图右上角的「设置」/齿轮入口，点击打开设置面板。
2. 入口具体形态以实际界面为准（截图/快照确认）；
   找不到 → AskUserQuestion 请用户指认，不要乱点。

### Step 5 — 按用户指定的配置项走对应小节

**开始日期字段**：⚠️ **设置后才可以展示日历页面**
（未设置时日历无法展示）。

**结束日期字段**：未设置时所有记录默认结束=开始、
记录条宽度仅一天；设置后记录条宽度=间隔天数；
记录条可**跨周（行）、跨月（页）**。

**记录显示字段**：选择字段 + 字体 + 背景颜色，
配置**实时预览**；背景色可清除
（清除操作转用户手动，严禁代点）。

**自定义模板**：开关 + 编辑图标；按提示将 field 替换为
表单字段，可显示 label/value，可增删改字段样式。
⚠️ **模板代码必须先经用户确认再写入**。

**显示首尾两端**：开关 + 颜色，清晰看到每条记录的
开始/结束位置。

**自定义卡片颜色**：为记录卡片配置自定义颜色。

### Step 6 — 验证并汇报

1. 行动后验证：以日历**实际显示效果**为准
   （日历是否展示、记录条宽度/颜色/首尾标记是否按配置生效）。
2. 向用户汇报改了哪些项、生效情况。

## 不变量

1. **作用域铁律**：仅在用户确认的目标日历视图设置面板内操作，
   不碰无关资源与其他视图。
2. **删除红线**：面板中任何「删除」按钮/图标**严禁点击**；
   删除类操作（如删除记录显示字段）只写红线、转用户手动。
3. **代码确认制**：自定义模板代码写入前必须向用户展示并确认。
4. **行动后验证**：配置项以界面实际生效为准，不以点击成功为准。
5. **失败即停**：同一关键操作两次失败即转用户手动，不反复重试。

## Notes / gotchas

- **开始日期字段是展示前提**：日历页面展示依赖开始日期字段，
  配置其他项前先确认该项已设置。
- **结束日期字段联动**：未设置时记录条宽度仅一天——
  向用户解释该默认行为。
- **实时预览**：记录显示字段配置有实时预览，
  验证以预览/实际渲染为准。
- **ref 时效性（Trae）**：操作前后快照变化，重新取 ref。
- **CDP 超时（仅 WorkBuddy）**：点击前 focus + sleep 约 2 秒。
- **Vue 条件渲染 hover 图标可能不渲染**：重试一次，
  仍不出现转用户手动。
- **右键菜单降级路线**：如需右键菜单而自动化无法呼出，转用户手动。
- 找不到目标视图时，可用 `ynu-eos8-view-entity-pages`
  定位实体生成的页面清单。
