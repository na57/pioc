# 新建层级视图（EOS8 视图设计器，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 IDE 的**视图设计器**中新建一个**层级视图**。
官方描述：层级视图允许用户进行新建、复制、复制编码和
删除操作，并且可以创建多个层级视图。本 skill **只做
「新建」**。

⚠️ **前置条件**：层级视图的**对应表单需要是自关联实体，
或者含有一对多（1:n）关系的实体**。前置不满足时应先告知
用户，由用户决定是否先调整实体/表单。

流程概览：
确认 IDE 已登录 → 校验前置（自关联/1:n 关系）→
AskUserQuestion 确认视图名称 → 快照确认处于视图设计器 →
视图树「默认视图」右侧「+」→ 新建视图弹框选「层级」→
输入视图名称 → 保存 → 验证自动生成。

**作用域铁律**：本 skill 仅适用于视图设计器；若当前 IDE
不在视图设计器，立即停止并引导用户先打开对应设计器，
绝不跨设计器操作。

**删除红线**：视图管理操作中的「删除」一律不执行；
本 skill 只走新建流程。

## When to use

- 用户想为实体新建一个层级视图（树形层级展示数据）。
- 用户说「新建层级视图」「加一个层级视图」「创建层级视图」。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` 且能列出浏览器 →
  **WorkBuddy 模式**：用 mcp__browser__* 工具操作；
  take_snapshot 取可交互元素快照；ref 有时效性，
  页面重渲染后须重取快照；点击前可先对目标元素 focus
  并 sleep 约 2 秒，避免 CDP 超时。
- 工具列表含 integrated_code_mode 的 `Exec`
  （`await tools.browser_*` 可用）→ **Trae 模式**：
  用该运行时操作；同样注意快照 ref 时效性，
  每次操作前重取快照。
- 两者都不可用 → 终止并告知用户当前无可用浏览器运行时。

## 参数

- **视图名称**（必填）：新建层级视图的名称。
- **目标实体/页面**（按需）：在哪个实体生成的视图设计器中
  新建；未指明时以当前打开的视图设计器为准。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 前置校验 + 作用域确认（AskUserQuestion，必经）

1. 向用户确认前置条件：「层级视图要求对应表单是**自关联
   实体**或**含 1:n 关系实体**，当前表单是否满足？」
   用户不确定时，可提示其到实体设计器确认实体关联关系
   （不属于本 skill 操作范围）。
2. 确认：「将在当前实体的视图设计器中新建层级视图
   <视图名称>，是否继续？」

### Step 3 — 快照确认处于视图设计器

标志性 UI 识别点：视图设计器左侧为**视图树**，树中含
**「默认视图」条目**，条目右侧有 **「+」添加按钮**。
快照中能看到该结构 → 确认作用域正确；看不到 → 停止并请
用户先打开视图设计器，不要乱点。

### Step 4 — 新建层级视图

1. 点击视图树中**「默认视图」条目右侧的「+」添加按钮**，
   打开**新建视图弹框**。
2. 弹框中**选择视图类型为「层级」**。
3. **输入视图名称**（用 Step 2 确认的名称）。
4. **点击保存按钮**，系统将自动生成一个新的层级视图。

**验证**：保存后快照确认——视图树中出现新层级视图条目，
画布自动生成并打开该层级视图。未出现条目 → 视为失败，
按「失败即停」处理。

### Step 5 — 后续配置提醒并汇报

1. 提醒用户：层级视图的层级关系、展示字段等需在设置面板
   中配置；引导至 `ynu-eos8-view-tier-settings`。
2. 向用户汇报：新建的视图名称、类型、视图树条目已生成、
   下一步建议。

## 不变量

1. **作用域铁律**：仅在视图设计器内操作，不跨设计器、
   不碰无关资源。
2. **删除红线**：任何「删除」按钮/图标/菜单项**严禁点击**；
   复制、复制编码等非新建管理操作不执行。
3. **行动后验证**：以视图树新条目为准，不以保存按钮
   点击成功为准。
4. **失败即停**：同一关键操作两次尝试仍失败 → 停止并
   报告现场，不盲目重试、不绕路。

## Notes / gotchas

- **前置条件先说清**：表单不是自关联实体且不含 1:n 关系
  实体时，层级视图无法按预期工作——Step 2 必须先确认，
  不要建完才发现用不了。
- **新建视图弹框是 Ant Design 弹层**：渲染在 body 下，
  定位时在整页快照中找，不要局限在「+」按钮附近。
- **ref 时效性（Trae）**：弹框打开、保存后页面重渲染，
  旧 ref 失效，点击前重新获取快照。
- **CDP 超时（仅 WorkBuddy）**：点击前先 focus 目标元素
  并 sleep 约 2 秒再 click。
- 后续层级关系与展示配置 → `ynu-eos8-view-tier-settings`。
- 官方文档：
  https://help.primeton.com/eos/b4dca8c4422b365/lowcode_reference/view_design/tiers_view/create_view.html
