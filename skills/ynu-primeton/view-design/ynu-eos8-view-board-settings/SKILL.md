# 看板设置（EOS8 视图设计器，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 IDE 的**看板视图设置面板**中配置看板。
本 skill 为**聚合型**：覆盖**分组设置**（分组字段、分组范围、
默认分组颜色、分组排序）、**布局设置**（自适应、固定占比）、
**卡片设置**（标题字段、副标题字段、封面字段、封面位置及
显示方式、图片高度）共 3 组。
**按用户指定的单项走对应小节，不要求每次全跑。**

官方说明：看板设置只介绍看板专属配置；显示、筛选、动作设置、
高级设置等**与表格视图一致**，不再介绍——需要这些通用设置时
**引导至 `ynu-eos8-view-list-settings`**（见文末小节）。

流程概览：
确认 IDE 已登录 → AskUserQuestion 确认目标看板与配置项 →
打开目标看板视图 → 打开设置面板 → 按配置项走对应小节 →
验证生效。

**作用域铁律**：仅在用户确认的目标看板视图设置面板内操作，
不碰无关资源、不改其他视图配置。

## When to use

- 用户要配置看板的分组字段、分组范围、分组颜色、分组排序。
- 用户要调整看板布局（自适应宽度/边距，或固定占比分列）。
- 用户要设置看板卡片的标题、副标题、封面图等显示内容。
- 用户说「设置看板分组」「看板卡片封面」「看板固定占比」。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` → **WorkBuddy 模式**：
  用 mcp__browser__* 工具操作；take_snapshot 取可交互元素快照；
  ref 有时效性，页面重渲染后须重取快照；点击前可先对目标元素
  focus 并 sleep 约 2 秒，避免 CDP 超时。
- 工具列表含 integrated_code_mode 的 `Exec`
  （`await tools.browser_*` 可用）→ **Trae 模式**：
  用该运行时操作；同样注意快照 ref 时效性，每次操作前重取快照。
- 两者都不可用 → 终止并告知用户当前无可用浏览器运行时。

## 参数

- **目标看板视图**（必填）：要配置的看板视图名称。
- **要配置的项**（必填）：用户指定的配置项，可多项；
  未指定的项一律不碰。
- **配置目标值**（按需）：分组字段名、颜色数组、排序方式、
  列宽/边距数值、占比份数、标题/副标题/封面字段名等，
  由用户提供。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 作用域确认（AskUserQuestion，必经）

确认：「将在看板视图 <视图名> 的设置面板中配置
<配置项列表>，是否继续？」

### Step 3 — 打开目标看板视图并打开设置面板

1. 在 IDE 中打开目标看板视图（资源树/视图列表定位并打开；
   找不到 → AskUserQuestion 请用户指认，不要乱点）。
2. 找视图右上角的「设置」/齿轮入口，点击打开设置面板；
   入口形态以实际界面为准（快照确认），找不到 →
   AskUserQuestion 请用户指认。

### Step 4 — 按用户指定的配置项走对应小节

#### 4.1 分组设置 — 分组字段

1. 设置列分组字段。**未设置分组字段时，视图显示为空白页**
   （正常现象，配置后即有分组列）。
2. 当字段为**字典、实体、自定义变量、1:n 实体**时，
   会自动显示对应的配置项，无需额外操作。
3. **分组合计显隐**：可显示/隐藏分组合计，合计值显示在
   每个分组列的标题后面。
4. **无数据分组显隐**：可隐藏/显示无数据分组（列中无记录的
   分组）。
5. **验证**：保存后快照确认分组列按字段值生成。

#### 4.2 分组设置 — 分组范围

分为**默认范围**和**用户设置范围**：

- **默认范围**：分组字段为数据字典、实体、自定义变量时，
  将其范围作为分组范围；分组字段为其他类型字段时，
  记录列表数据中该字段已存在的值作为默认分组范围。
  数据字典、实体、自定义变量如果设置过颜色，也会在分组列上
  显示出来。
- **用户设置范围**：需先在**高级设置中配置一个变量**，
  配置项数组对象中需包含 **code、name、color** 等字段；
  再点击按钮**绑定该变量**。绑定后分组列标题被替换为用户
  设置的名称，**不在用户设置范围内的列及卡片记录会隐藏掉**。
  ⚠️ 用户设置范围的**优先级高于**字段本身默认范围。
  变量值若需代码写入，先向用户展示并确认。

#### 4.3 分组设置 — 默认分组颜色

复制提示标签中的颜色（或自定义颜色）数组，粘贴到
「默认分组颜色」输入框。若不存在用户设置范围或字段本身的
默认范围（数据字典、实体、自定义变量），分组列会按该颜色
数组的顺序循环展示。

#### 4.4 分组设置 — 分组排序

- **默认排序**：需指定排序类型（按字母、按分组合计）和
  升降序。
- **允许用户拖拽排序**：视图记录用户拖拽列自行产生的顺序，
  并在加载视图时还原。⚠️ **切换回默认排序后，用户的拖拽
  列顺序会清空**——切换前向用户说明。

#### 4.5 布局设置 — 自适应

可配置项：

- **列宽度**：设置分组列宽度，看板按设置的宽度值展示分组列，
  页面展示不完全时可横向滚动。
- **列左/右边距**：分组列之间的间距。
- **卡片上/下边距**：分组列内卡片之间的上下边距。
- **卡片左/右边距**：卡片距离分组列边界的左右边距。

#### 4.6 布局设置 — 固定占比

固定占比把看板中一行平均分成（6/5/4/3/2）份，显示 n 个卡片。
按用户选择的份数设置即可；验证时以一行实际显示卡片数为准。

#### 4.7 卡片设置

- **标题字段**：设置卡片显示标题。
- **副标题字段**：选择一个长文本字段作为卡片补充介绍。
- **封面字段**：选择表单中绑定**附件上传组件**的字段作为
  封面字段，从而显示图片。
- **封面位置及显示方式**：
  - 显示位置「上」：显示方式可选 完整显示 / 填满；
  - 显示位置「左/右」：显示方式可选 完整显示 / 填满 /
    圆形 / 矩形。
- **图片高度**：设置图片显示高度。⚠️ 显示方式为**圆形或
  矩形时图片高度不生效**。

#### 4.8 其他通用设置（引导）

显示、筛选、动作设置、高级设置等与表格视图一致，
**引导至 `ynu-eos8-view-list-settings`** 处理，
本 skill 不重复展开。

### Step 5 — 验证并汇报

1. 行动后验证：以看板**实际显示效果**为准（分组列、颜色、
   布局、卡片内容是否按配置显示）。
2. 向用户汇报改了哪些项、生效情况。

## 不变量

1. **作用域铁律**：仅在用户确认的目标看板视图设置面板内
   操作，不碰无关资源与其他视图。
2. **删除红线**：面板中任何「删除」按钮/图标**严禁点击**；
   删除类操作只写红线、转用户手动。
3. **行动后验证**：配置项以界面实际生效为准，不以点击
   成功为准。
4. **失败即停**：同一关键操作两次失败即转用户手动，
   不反复重试。

## Notes / gotchas

- **空白页不是失败**：未设置分组字段时看板画布为空白页——
  配置分组字段后即正常，不要误判为视图损坏。
- **用户设置范围的变量结构**：必须是含 code/name/color 的
  数组对象，且需先在高级设置中配置变量再绑定；
  绑定后范围外的列与卡片会被隐藏（属预期行为，先告知用户）。
- **排序方式切换有副作用**：从「允许用户拖拽排序」切回
  「默认排序」会清空用户已拖出的列顺序。
- **封面字段前提**：表单中需有绑定附件上传组件的字段，
  否则无图可显。
- **图片高度失效条件**：封面显示方式为圆形/矩形时高度
  设置不生效，避免无效调整。
- **ref 时效性（Trae）**：面板切换、保存后页面重渲染，
  旧 ref 失效，操作前重取快照。
- **CDP 超时（仅 WorkBuddy）**：点击前 focus + sleep 约 2 秒。
- **颜色数组输入**：默认分组颜色为数组粘贴，注意保持数组
  格式完整（含引号与逗号）。
- 找不到目标视图时，可用 `ynu-eos8-view-entity-pages`
  定位实体生成的页面清单。
- 通用设置（显示/筛选/动作/高级）→ `ynu-eos8-view-list-settings`；
  看板记录操作（拖拽卡片、新增/查看/修改记录）→
  `ynu-eos8-view-board-operations`。
- 官方文档：
  https://help.primeton.com/eos/b4dca8c4422b365/lowcode_reference/view_design/board_view/base_set.html
