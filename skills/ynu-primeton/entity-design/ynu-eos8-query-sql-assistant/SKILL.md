# 查询实体 SQL 助手（EOS8 实体设计器，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 实体设计器中，查询实体 SQL 编辑区提供 **SQL 助手**
（官方图一位置 4），辅助完成 sql 语句输入。
本 skill 负责打开助手、拿到生成的 SQL、经用户确认后
回填到 SQL 编辑区，并走与手动编辑相同的验证流程
（点击查询 → 查询条件下方表格展示结果 → 确认生成查询实体）。

流程概览：
确认 IDE 已登录 → AskUserQuestion 确认目标查询实体与查询意图 →
双击查询实体 → 打开 SQL 编辑区 → 点击 SQL 助手 →
生成 SQL → 用户确认 → 回填 → 点击查询验证 → 确认生成。

**作用域铁律**：仅在当前已打开的实体设计器内操作，
不新建构件包、不碰无关资源。

## When to use

- 用户希望借助 SQL 助手（向导）生成查询实体的 SQL，
  而非手写 SQL。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` → **WorkBuddy 模式**。
- 工具列表含 integrated_code_mode 的 `Exec`（`await tools.browser_*`）→ **Trae 模式**。
- 两者都没有 → 提示用户启用对应浏览器扩展，终止流程。

## 参数

- **目标查询实体**（必填）：画布上的查询实体名称。
- **查询意图**（必填）：用户想查什么（表、字段、过滤条件），
  作为与助手交互的输入。
- **默认数据源**（选填）：默认 `default`。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 作用域确认（AskUserQuestion，必经）

确认：「将在 <设计器> 中为查询实体 <实体名> 使用 SQL 助手
生成 SQL，确认后生成查询实体，是否继续？」

### Step 3 — 打开查询实体的 SQL 编辑区

1. 前置条件：画布上须已存在目标查询实体；没有则提示用户
   先用 `ynu-eos8-drag-create-entity` 拖拽创建查询实体，本 skill 终止。
2. **双击**目标查询实体进入配置界面。
3. 定位 SQL 编辑区（含默认数据源选择、SQL 输入框、
   查询按钮、tab 栏）。

### Step 4 — 打开 SQL 助手并生成 SQL

1. 在 SQL 编辑区找到 **SQL 助手**图标（官方图一位置 4，
   位于 SQL 输入区附近）并点击。
2. 按助手界面交互输入查询意图（助手具体交互形态文档未详述，
   以实际界面为准；若与预期不符，转用户手动操作助手，agent 接手读结果）。
3. 拿到助手生成的 SQL 后**原文展示给用户确认**，
   确认后方可回填——助手产物不得未经确认直接执行。

### Step 5 — 回填并验证（以结果表格为准）

1. 将确认后的 SQL 回填到 SQL 输入框。
2. 点击**查询**按钮执行。
3. **验证方式**：查询后数据库记录展示在**查询条件下方的表格**中；
   以表格实际出现列名与数据行为准，不以按钮点击成功为准。
4. 可收起查询 SQL 配置；向用户复述实体名与属性映射后点击**确认**生成查询实体。

## 不变量

1. **SQL 只读红线**：助手生成的 SQL 只允许 SELECT 语义；
   含增删改语义时拒绝回填（查询实体只能用于查询）。
2. **助手产物必须经用户确认**：生成 SQL → 用户确认 → 才执行查询；
   不得跳过确认。
3. **删除红线**：界面上任何「删除」按钮/图标/菜单项严禁点击。
4. **行动后验证**：以查询结果表格实际展示为准，不以点击成功为准。
5. **失败即停**：助手打不开、生成失败、查询后表格未出现，停止并汇报。

## Notes / gotchas

- **助手形态待人工核对**：官方文档仅说明「可使用 sql 助手
  （图一位置 4）辅助完成 sql 语句输入」，未给出助手界面细节，
  以实际界面为准。
- **id 保留字**：查询实体里不能定义属性名叫 id 的属性
  （唯一标识对应的属性可以使用 id 这个名称）；回填前检查生成 SQL
  的列名是否合法。
- **重名列必须起别名**：2 个相同列名需起不同别名区分。
- **唯一标识注意事项**：未指定唯一标识时 EOS 自动用常量作唯一标识，
  默认唯一标识不能与持久化实体做单向 1:1 和单向 N:1 关联，
  否则对持久化实体做操作会抛异常。
- **生成实体按 default 查询**：运行时找不到对应连接类型配置时
  回退 default；跨库连接类型见 `ynu-eos8-query-join-type`。
- **右键菜单可能无反应**：降级路线 ①重取快照重试 →
  ②键盘 ContextMenu 键 → ③hover 看图标 → ④请用户手动点出菜单。
- **Vue 条件渲染**：hover 图标以 `<!---->` 占位可能不因合成事件渲染，
  两次失败转用户手动。
- **ref 时效性（Trae）**：快照变化后旧 ref 失效，重新取。
- **CDP 超时（仅 WorkBuddy）**：点击前 focus + sleep 约 2 秒。
- **衔接**：手动编辑/执行 SQL 全流程见 `ynu-eos8-query-edit-sql`。
