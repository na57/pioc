# 拖曳创建实体（EOS8 实体设计器，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 **实体设计器**（画布界面，含资源树菜单/实体面板/数据源/toolbar
四部分）中，从**实体面板**选择实体类型，**拖曳**到画布创建实体。

实体面板提供的类型：
- **持久化实体**（⚠️ 创建后必须生成对应数据库表）
- **服务实体**
- **引用实体**
- **查询实体**
- **注释**

流程概览：
确认 IDE 已登录 → AskUserQuestion 确认类型与命名 → 打开实体设计器 →
拖曳类型到画布 → 配置实体属性 → 验证 →（持久化实体）引导生成表。

**作用域铁律**：创建的实体类型、名称及落点（哪个实体设计器/构件包）
必须经 `AskUserQuestion` 确认。

## When to use

- 用户要在实体设计器画布上新建实体（手绘方式）。
- 批量导入建实体改用 `ynu-eos8-import-entity`；
  从数据库表反向生成改用 `ynu-eos8-create-entity-from-datasource`。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` → **WorkBuddy 模式**。
- 工具列表含 integrated_code_mode 的 `Exec`（`await tools.browser_*`）→ **Trae 模式**。
- 两者都没有 → 提示用户启用对应浏览器扩展，终止流程。

## 参数

- **实体类型**（必填）：持久化 / 服务 / 引用 / 查询 / 注释。
- **实体名称**（必填）：用户期望的实体名（画布内重命名或属性面板填写）。
- **目标设计器**（必填）：在哪个构件包的哪个实体集下操作
  （打开哪个实体设计器）。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 作用域确认（AskUserQuestion，必经）

确认：「将在 <构件包/实体集> 的实体设计器中拖曳创建
<类型>实体 <名称>，是否继续？」
类型为持久化实体时，提示「稍后需要生成数据库表」。

### Step 3 — 打开实体设计器

在左侧资源树展开构件包 → 「实体」→ 目标实体集/实体，
**双击**节点打开实体设计器（入口文档未明示，实测确认；
双击无效改试单击）。
等待画布加载完成（实体面板、数据源面板、toolbar 出现）。

### Step 4 — 从实体面板拖曳类型到画布

1. 在实体面板定位目标类型（持久化实体/服务实体/引用实体/查询实体/注释）。
2. 执行拖拽（Trae：Exec 内 `browser_drag`（若可用）或
   按下-移动-释放序列；WorkBuddy：对应拖拽工具）。
3. **拖拽可能不被画布识别**（HTML5 原生 drag & drop 对合成事件
   最敏感）：失败时降级——① 重取快照后重试一次；
   ② 改用「点击类型 + 点击画布落点」的候选交互（若界面支持）；
   ③ 请用户手动拖放，agent 接手后续配置。
4. ⚠️ 红线：界面中任何「删除」入口一律不点击。

### Step 5 — 配置实体

1. 画布上选中新实体，在属性区填写实体名称等基本配置。
2. 用户有字段要求时按需添加基本属性（复杂编辑交给
   `ynu-eos8-edit-entity`）。
3. 每次填写后重取快照/DOM 确认 value。

### Step 6 — 验证

1. 重取快照/DOM：画布中出现新实体节点，名称正确。
2. **持久化实体**：提醒用户尚无数据库表，引导执行
   `ynu-eos8-generate-table`（经用户确认后执行）。

### Step 7 — 保留会话

保持标签页与设计器打开，供后续 skill 复用。

## 不变量

1. **创建前必确认**：类型、名称、目标设计器经 AskUserQuestion 确认。
2. **行动后验证**：以画布出现新实体为准。
3. **失败即停**：拖拽两次失败转用户手动，不无限重试。
4. **持久化实体必有表**：创建持久化实体后必须提示生成表。
5. **删除红线**：任何「删除」入口一律不点击、不尝试。

## Notes / gotchas

- **HTML5 拖拽是本 skill 最大风险点**：合成事件可能不触发画布 drop，
  优先用运行时 drag 工具，两次失败转用户手动。
- **Vue 条件渲染**：面板/节点内的操作控件可能以 `<!---->` 占位，
  不因合成事件或 hover 渲染——看不到就别硬找，走降级路线。
- **ref 时效性（Trae）**：画布变化后旧 ref 失效，重新快照。
- **CDP 超时（仅 WorkBuddy）**：拖拽/点击前 focus + sleep 约 2 秒。
- **衔接**：后续生成表 `ynu-eos8-generate-table`、
  生成页面 `ynu-eos8-generate-page`。
