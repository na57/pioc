# 实体编辑（EOS8 实体设计器，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 实体设计器中编辑实体：
- **双击实体**快速进入**实体属性设置界面**，可编辑
  **实体属性**与**数据库属性**；
- 界面提供**添加基本属性**、**添加审计字段**等快捷按钮；
- 支持**字段的复制粘贴**操作；
- 右键实体也可打开操作菜单（含编辑相关入口）。

流程概览：
确认 IDE 已登录 → AskUserQuestion 确认实体与改动内容 →
打开实体设计器 → 双击实体进入属性设置 → 按改动清单修改 →
保存 → 验证。

**作用域铁律**：编辑是**写操作**。改动前必须用 `AskUserQuestion`
列出改动清单（实体名、要加/改/删的属性）获得确认；
只改用户确认的项。

## When to use

- 用户说「给实体加字段」「改实体属性」「编辑实体」。
- 「添加审计字段」也可由此完成（或用 toolbar 开关先看：
  `ynu-eos8-toggle-audit-fields`）。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` → **WorkBuddy 模式**。
- 工具列表含 integrated_code_mode 的 `Exec`（`await tools.browser_*`）→ **Trae 模式**。
- 两者都没有 → 提示用户启用对应浏览器扩展，终止流程。

## 参数

- **目标实体**（必填）：设计器画布中的实体。
- **改动清单**（必填）：逐条列出——
  添加属性（名称/类型）、修改属性（原名→新值）、删除属性等。
  ⚠️ 涉及**删除属性**的条目需用户逐条再确认后才能执行。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 改动确认（AskUserQuestion，必经）

确认：「将编辑实体 <名称>，改动：<逐条清单>，是否继续？」

### Step 3 — 打开实体设计器

资源树双击实体集/实体打开实体设计器；
画布中定位目标实体节点。

### Step 4 — 双击实体进入属性设置界面

1. **双击**目标实体（Trae：dblclick 或两次 click；
   WorkBuddy：双击工具），进入实体属性设置界面。
2. 双击无响应 → 降级：右键实体看菜单中的编辑入口
   （右键无反应的降级路线同其他 skill）。
3. 等待属性设置界面加载（实体属性/数据库属性区出现）。

### Step 5 — 按清单修改

1. **添加基本属性**：点快捷按钮 → 填属性名/类型 → 复验 value。
2. **添加审计字段**：点快捷按钮（一次性补 createUser/createTime/
   updateUser/updateTime 一组）。
3. **字段复制粘贴**：按界面支持的方式操作，粘贴后核对目标字段内容。
4. **修改实体属性/数据库属性**：逐项修改，每项改完重取快照/DOM 确认。
5. 填写失败重试一次；仍失败停下报告，不带病保存。
6. ⚠️ 红线：界面中任何「删除」按钮仅在用户清单明确含删除项
   且已二次确认时才允许点；其他一律不碰。

### Step 6 — 保存并验证

1. 点保存（若界面为即时保存则跳过）。
2. 重取快照/DOM：属性清单与改动清单一致。
3. 向用户汇报改动结果（逐条对应）。

### Step 7 — 保留会话

保持标签页与设计器打开，供后续 skill 复用。

## 不变量

1. **改动先确认**：改动清单经 AskUserQuestion 确认，逐条执行不超纲。
2. **删除从严**：删除属性条目需用户二次确认。
3. **行动后验证**：每项改动后复验，保存后整体核对。
4. **失败即停**：不带病保存。

## Notes / gotchas

- **双击 vs 右键**：文档推荐双击进入编辑；右键是备用入口。
- **实体属性 vs 数据库属性**：两个区，改前核对所在区，
  数据库属性的改动会影响建表/重新加载结果。
- **ref 时效性（Trae）**：界面切换后旧 ref 失效，重新快照。
- **CDP 超时（仅 WorkBuddy）**：点击/输入前 focus + sleep 约 2 秒。
- **衔接**：属性变动后如需同步表结构，引导 `ynu-eos8-generate-table`
  （经用户确认）；同步数据库数据用 `ynu-eos8-reload-entity`。
