# 创建引用实体——资源树拖拽（EOS8 实体设计器，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 实体设计器中创建**引用实体**。
官方描述：创建引用实体有两种方式——
① 从实体面板创建：从实体面板拖拽引用实体到画布，
双击后弹出选择实体弹框，选中实体点确定；
② **从资源树创建**：从资源树中，选择**其他实体集的持久化实体**，
拖入到画布中。

本 skill 只负责**资源树拖拽入口**；
实体面板拖拽入口由 `ynu-eos8-drag-create-entity` 覆盖，此处不重复。

引用实体适用场景：目标实体在其他模块，或离线开发时已经建立，
当前模块低开时需要使用；**引用实体只能在源定义处修改**。

流程概览：
确认 IDE 已登录 → AskUserQuestion 确认源实体集与源持久化实体 →
资源树展开定位源实体 → 拖拽到画布 →
验证画布出现引用实体 → 汇报。

**作用域铁律**：仅在当前已打开的实体设计器内操作，
不新建构件包、不碰无关资源、不修改源实体集。

## When to use

- 用户要在当前实体集中引用其他实体集已有的持久化实体
  （跨实体集/跨模块复用），且明确走资源树拖拽。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` → **WorkBuddy 模式**。
- 工具列表含 integrated_code_mode 的 `Exec`（`await tools.browser_*`）→ **Trae 模式**。
- 两者都没有 → 提示用户启用对应浏览器扩展，终止流程。

## 参数

- **源实体集**（必填）：资源树中被引用实体所在的实体集。
- **源持久化实体**（必填）：要拖入画布的持久化实体名称
  （必须是持久化实体，其他类型不适用本入口）。
- **目标设计器**（按需）：拖入到哪个实体集的画布。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 作用域确认（AskUserQuestion，必经）

确认：「将在 <目标设计器> 画布中，从资源树拖入
<源实体集>.<源实体> 生成引用实体，是否继续？」

### Step 3 — 定位资源树中的源实体

1. 资源树双击实体集/实体打开实体设计器（入口实测确认）。
2. 在**资源树**中展开：构件包 → 实体 → 源实体集，
   定位目标持久化实体节点。
3. 若源实体在另一个构件包下，注意资源树可能需要先折叠/展开
   到对应构件包（保持当前设计器标签不动）。

### Step 4 — 拖拽源实体到画布

1. 将资源树中的源实体节点**拖拽**到画布空白处
   （Trae：Exec 内模拟拖拽；WorkBuddy：对应 drag 工具）。
2. **拖拽是 HTML5 原生拖拽，自动化成功率低**——
   降级路线：①重取快照后重试一次（换落点坐标，落到画布空白处）；
   ②仍失败 → **请用户手动拖**，agent 在拖拽完成后接手
   Step 5 的验证与汇报，不要反复重试拖拽超过 2 次。
3. 拖拽过程严禁点到资源树节点的右键菜单或图标按钮。

### Step 5 — 验证与汇报

1. **验证方式**：重取画布快照，确认画布上出现引用实体节点
   （名称与源实体一致）。
2. 与资源树中的源实体名核对，确认拖入的是正确实体。
3. 向用户汇报：新增的引用实体、源实体全称
   （构件包.实体集.实体名，可用 `ynu-eos8-copy-entity-name` 获取）；
   并提示：引用实体只能在源定义处修改。

## 不变量

1. **源实体只读**：本 skill 只「引用」不改源——
   不在源实体集内做任何编辑、生成、重载操作。
2. **删除红线**：界面上任何「删除」按钮/图标/菜单项严禁点击。
3. **行动后验证**：以画布实际出现引用实体为准，不以拖拽调用成功为准。
4. **失败即停**：拖拽重试 2 次失败即转用户手动拖，不无限重试。

## Notes / gotchas

- **拖拽降级是常态预案**：HTML5 原生拖拽对自动化不友好，
  提前告知用户可能需要手动拖一下，agent 负责之后的一切确认。
- **面板拖拽入口**：从实体面板拖拽引用实体 → 双击 →
  在选择实体弹框中选中实体 → 确定按钮，见
  `ynu-eos8-drag-create-entity`。
- **引用实体不可改**：引用实体只能在源定义处修改；
  引用实体不能作为关系主端（见 `ynu-eos8-reference-relation`）。
- **右键菜单可能无反应**：降级路线 ①重取快照重试 →
  ②键盘 ContextMenu 键 → ③hover 看图标 → ④请用户手动点出菜单。
- **ref 时效性（Trae）**：拖拽前后快照变化，重新取 ref。
- **CDP 超时（仅 WorkBuddy）**：拖拽/点击前 focus + sleep 约 2 秒。
- **衔接**：建好引用实体后要与持久化实体建立关系时用
  `ynu-eos8-reference-relation`。
