# 创建实体关系（EOS8 实体设计器，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 实体设计器中为**持久化实体**创建关联关系。
官方支持四种：**单向1:1、单向1:N、单向N:1、双向1:N**。
关系在设计图（画布）上建立；服务实体的关系不走连线
（那用 `ynu-eos8-service-entity-relation`），本 skill 只管
持久化实体。

各类型关键约束（创建前必须校验）：

| 类型 | 关键约束 | 页面引入子实体方式 | 数据结构 |
|------|---------|-------------------|---------|
| 单向1:1 | 两实体均须**单主键**；主键一致性由用户保证；无延迟加载（左外联查询） | 资源容器 | 子实体在主实体下生成**对象** |
| 单向1:N | **1端关联字段必须是主键**；N端选择相同个数的列与1端主键匹配（全主键或全非主键）；支持延迟加载 | 子表格 | 子实体在主实体下生成**数组** |
| 单向N:1 | **1端必须是主键**；N端指定关联属性（可主键可非主键），选择相同个数属性匹配；支持延迟加载 | — | 子实体生成**对象** |
| 双向1:N | 参考单向1:N与单向N:1 | — | — |

流程概览：
确认 IDE 已登录 → AskUserQuestion 确认两实体与关系类型 →
校验主键约束 → 画布连线/菜单创建关系 → 配置关联属性 →
保存验证。

**作用域铁律**：仅在当前已打开的实体设计器内操作，
只建立用户确认的那一条关系，不碰画布上其他实体与连线。

## When to use

- 用户要在两个持久化实体间建立 1:1 / 1:N / N:1 / 双向1:N
  关联关系。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` → **WorkBuddy 模式**。
- 工具列表含 integrated_code_mode 的 `Exec`（`await tools.browser_*`）→ **Trae 模式**。
- 两者都没有 → 提示用户启用对应浏览器扩展，终止流程。

## 参数

- **主实体与子实体**（必填）：画布上的两个持久化实体
  及主从角色。
- **关系类型**（必填）：单向1:1 / 单向1:N / 单向N:1 / 双向1:N。
- **关联属性**（1:N、N:1 必填）：参与匹配的属性
  （N 端被选属性须同为主键或同为非主键）。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 作用域确认（AskUserQuestion，必经）

确认：「将在 <设计器> 中建立 <关系类型>：<主实体> →
<子实体>，关联属性：<清单>，是否继续？」
类型为**单向1:N** 时，明确警示：N 端被选为关联的属性
将被**移除**并以 1 端实体引用代替（结构性变更）。

### Step 3 — 校验主键约束

1. 双击实体核对主键设置：
   - 1:1 → 两实体均须单主键；
   - 1:N / N:1 → 1 端关联字段必须是主键。
2. 校验不通过 → 停下报告差距，经用户确认先改主键
   （`ynu-eos8-edit-entity`）再回来。

### Step 4 — 建立关系

1. 在画布上从主实体向子实体**连线**创建关系
   （拖线绘制；若界面提供右键/工具入口则用之；
   具体交互以现场为准，见 gotchas）。
2. 在弹出的关系配置中选择关系类型、关联属性。
3. 每步后重取快照/DOM 确认。
4. ⚠️ 红线：界面中任何「删除」按钮/图标/菜单项严禁点击
   （包括已有关系连线与属性行的删除图标）。

### Step 5 — 保存并验证

1. 保存配置（若为即时保存则跳过）。
2. 重取快照/DOM 验证：画布出现关系连线，或主实体下
   出现子实体引用；关联属性配置与确认一致。
3. 向用户汇报关系类型、主从实体、关联属性；提示页面
   生成时的引入方式（1:1 资源容器 / 1:N 子表格）。
   保持设计器打开供复用。

## 不变量

1. **约束先行**：主键约束校验不通过不建关系。
2. **1:N 结构变更先确认**：N 端属性将被移除替换，
   必须在 Step 2 显式确认后才继续。
3. **删除红线**：任何「删除」入口严禁点击。
4. **行动后验证**：以画布/属性区实际出现关系为准。
5. **失败即停**：连线交互两次失败转用户手动。

## Notes / gotchas

- **连线交互细节待人工核对**：官方文档以配图展示关系建立，
  文字未描述具体连线操作；本 skill 以「画布拖线」为首选、
  右键/工具为备选，现场以实际界面为准。
- **1:N 的属性替换是平台行为**：N 端被选属性会被移除并用
  1 端实体代替，随后需通过 1 端主键访问其值——不是 bug。
- **服务实体不连线**：服务实体关系在属性配置中手动关联，
  画布上没有线，别在本流程里给服务实体画线。
- **拖拽/连线对合成事件敏感**（HTML5 drag）：两次失败
  转用户手动拖线，agent 接手配置弹窗。
- **右键菜单可能无反应**，降级路线：①重取快照重试 →
  ②键盘 ContextMenu 键 → ③hover 看图标 → ④请用户手动点出菜单。
- **ref 时效性（Trae）**：画布变化后旧 ref 失效，重新快照。
- **CDP 超时（仅 WorkBuddy）**：拖线/点击前 focus + sleep 约 2 秒。
- **衔接**：生成页面（含子表格/资源容器）用
  `ynu-eos8-generate-page`；生成表 `ynu-eos8-generate-table`。
