# 引用实体建立关系（EOS8 实体设计器，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 实体设计器中为**持久化实体与引用实体**建立关联关系。
官方描述：持久化实体和引用实体可以关联关系，但**引用实体只能
作为被指向端**——如果作为源端，无法动态增加引用属性；
即**持久化实体只能作为主端**跟引用实体关联**单向的三种关系**
（单向 1:1、单向 1:n、单向 n:1）。操作步骤跟持久化实体一样。

流程概览：
确认 IDE 已登录 → AskUserQuestion 确认主端持久化实体、
被指向的引用实体与关系类型 → 画布中从主端发起关系创建 →
指向引用实体并按类型配置关联属性 → 验证关系存在 → 汇报。

**作用域铁律**：仅在当前已打开的实体设计器内操作，
不新建构件包、不碰无关资源。

## When to use

- 用户要在画布上为持久化实体（主端）与引用实体（被指向端）
  建立单向 1:1 / 单向 1:n / 单向 n:1 关联关系。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` → **WorkBuddy 模式**。
- 工具列表含 integrated_code_mode 的 `Exec`（`await tools.browser_*`）→ **Trae 模式**。
- 两者都没有 → 提示用户启用对应浏览器扩展，终止流程。

## 参数

- **主端持久化实体**（必填）：关系发起方，必须是持久化实体。
- **被指向端引用实体**（必填）：关系目标，必须是引用实体。
- **关系类型**（必填）：单向 1:1 / 单向 1:n / 单向 n:1 三选一。
- **关联属性**（按需）：1:n / n:1 需要在 N 端选择与 1 端主键
  个数相同的属性匹配。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 作用域与方向确认（AskUserQuestion，必经）

确认：「将在 <设计器> 画布中，从持久化实体 <主端> 向引用实体
<被指向端> 建立单向 <1:1 / 1:n / n:1> 关系，是否继续？」
若用户要求方向为「引用实体 → 持久化实体」，说明方向红线并拒绝
（见不变量 1），可建议反向建立。

### Step 3 — 前置条件检查

1. 画布上同时存在主端持久化实体与被指向端引用实体；
   缺引用实体 → 先走 `ynu-eos8-create-reference-entity` 创建。
2. 关系类型合法性预检：
   - 单向 1:1：两个实体均为单主键，靠共享主键关联；
   - 单向 1:n：主端（1 端）关联字段必须是主键，被指向端（n 端）
     需选择相同个数的属性与 1 端主键匹配（被选属性或全部是主键、
     或全部是非主键）；
   - 单向 n:1：主端（n 端）指定用于关联的属性，被指向端（1 端）
     必须是主键，主端选择相同个数的属性匹配。
3. 双向 1:N 不可选——引用实体不能作为主端，直接向用户说明。

### Step 4 — 画布建立关系（操作步骤同持久化实体）

1. 在画布中从**主端持久化实体**发起关系创建、指向**引用实体**
   （官方未详述画布连线手势，以实际界面为准；探测路线：
   hover 主端实体找连接锚点 → 右键主端实体看关系/关联菜单 →
   两者都没有则转用户手动发起，agent 接手配置）。
2. 在关系配置中选定关系类型与关联属性（按 Step 3 预检规则选择）。
3. 严禁在关系配置界面点击任何「删除」类控件。

### Step 5 — 验证与汇报

1. **验证方式**：重取画布快照确认关系连线已出现，
   并打开实体配置核对关联属性已按所选类型落上
   （1:n 时主端出现子实体集合，n:1 时主端出现引用属性对象）。
2. 向用户汇报：主端、被指向端、关系类型、关联属性映射；
   若为单向 1:1，提示其无延迟加载（左外联查询主控与关联对象）。

## 不变量

1. **方向红线（本 skill 核心约束）**：只能 持久化实体（主端）→
   引用实体（被指向端）；严禁从引用实体发起建关系，
   严禁把引用实体设为主端/源端。
2. **删除红线**：界面上任何「删除」按钮/图标/菜单项严禁点击。
3. **行动后验证**：以画布关系连线与实体配置实际内容为准，
   不以操作调用成功为准。
4. **失败即停**：找不到关系入口、配置报错，停止并汇报，
   转用户手动。

## Notes / gotchas

- **为什么方向受限**：引用实体作为源端时无法动态增加引用属性，
  故只能做被指向端。
- **关系类型约束**：与引用实体只能建单向 1:1、单向 1:n、单向 n:1
  三种；双向 1:N 不可用。
- **连线手势待人工核对**：官方文档仅说明「操作步骤跟持久化实体
  一样」，画布上具体如何拖出关系以实际界面为准。
- **引用实体不可改**：引用实体只能在源定义处修改；
  关系建立不影响源实体集。
- **右键菜单可能无反应**：降级路线 ①重取快照重试 →
  ②键盘 ContextMenu 键 → ③hover 看图标 → ④请用户手动点出菜单。
- **Vue 条件渲染**：hover 实体出现的锚点/图标若以 `<!---->` 占位，
  可能不因合成事件渲染，两次失败转用户手动。
- **ref 时效性（Trae）**：快照变化后旧 ref 失效，重新取。
- **CDP 超时（仅 WorkBuddy）**：点击/拖拽前 focus + sleep 约 2 秒。
- **衔接**：创建引用实体见 `ynu-eos8-create-reference-entity`；
  持久化实体间关系的类型与通用逻辑见官方持久化实体文档第 6 节。
