# 查看页面——查看表单（EOS8 实体设计器，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 实体设计器中，通过实体的右键菜单**查看表单**，
系统会展示**由该实体生成的所有页面**数据；
点击「**打开表单**」按钮可迅速跳转到与选定实体相对应的页面
进行数据查阅。

流程概览：
确认 IDE 已登录 → 确认实体 → 右键实体 →
菜单「查看表单」→ 读取页面清单 →（经确认）打开表单跳转。

## When to use

- 用户问「这个实体生成了哪些页面」「实体对应的表单在哪」。
- 生成页面后（`ynu-eos8-generate-page`）核对结果。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` → **WorkBuddy 模式**。
- 工具列表含 integrated_code_mode 的 `Exec`（`await tools.browser_*`）→ **Trae 模式**。
- 两者都没有 → 提示用户启用对应浏览器扩展，终止流程。

## 参数

- **目标实体**（必填）。
- **是否打开表单**（可选）：默认只列出页面清单不跳转；
  用户要求打开某页面时才点「打开表单」。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 作用域确认

确认目标实体；说明「默认只查看不跳转，需要打开表单时告知」。

### Step 3 — 打开实体设计器，定位实体

资源树双击实体集/实体打开实体设计器；画布定位目标实体。

### Step 4 — 右键实体，菜单选「查看表单」

1. 右键实体节点打开操作菜单（含：删除、重新加载、生成页面、
   复制实体名称、查看表单等项）。
2. **右键可能无反应**：① 重取快照重试一次；② 键盘 ContextMenu 键；
   ③ hover 看操作图标；④ 请用户手动点出菜单后继续。
3. 菜单中选「查看表单」（「查看页面」入口）。
4. ⚠️ 红线：菜单中的「删除」项**严禁点击**。
5. 等待查看表单界面出现（页面清单加载）。

### Step 5 — 读取页面清单

1. 从界面读取该实体生成的所有页面（名称等），
   向用户汇报清单。
2. 清单为空 → 告知该实体尚无生成页面，
   可建议 `ynu-eos8-generate-page`（经用户确认）。

### Step 6 — 打开表单（仅在用户要求时）

1. 用户指定打开某个页面 → 在清单中定位该页面的
   「打开表单」按钮点击。
2. 跳转后确认新页面/新标签加载完成（Trae：等特征文本或列标签页；
   WorkBuddy：轮询 DOM）。
3. 向用户汇报跳转结果（页面已打开/URL）。
   **不要为清理而关闭跳转出的页面**。

### Step 7 — 保留会话

保持标签页打开，登录态与页面状态供后续 skill 复用。

## 不变量

1. **只读优先**：默认只查看清单；「打开表单」需用户要求。
2. **行动后验证**：以页面清单实际读出/跳转页面实际加载为准。
3. **失败即停**：不重复触发超过一次。
4. **删除红线**：菜单「删除」项及任何删除入口严禁点击、不尝试。

## Notes / gotchas

- **右键菜单降级路线**见 Step 4。
- **ref 时效性（Trae）**：菜单/跳转后旧 ref 失效，重新快照或重列标签页。
- **CDP 超时（仅 WorkBuddy）**：点击前 focus + sleep 约 2 秒。
- **衔接**：页面未生成时用 `ynu-eos8-generate-page`；
  生成用 `ynu-eos8-generate-page`，查看实体信息可用
  `ynu-eos8-copy-entity-name`。
