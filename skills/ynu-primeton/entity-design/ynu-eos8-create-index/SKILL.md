# 为持久化实体创建索引（EOS8 实体设计器，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 实体设计器中为**持久化实体**创建数据库索引。
官方要点：
- **前置条件**：在生成表后，才可以对实体执行数据库索引创建；
- 从数据源拖表生成实体时，系统会**同步生成相应索引**
  （此类实体可能已有索引，先查看再决定是否新增）；
- 索引创建方式有两种：
  1. 点击实体，选择实体中的**索引配置**，添加索引；
  2. 点击实体**右键**，选择索引相关菜单项
     （文档原文为「选择添加实体进行实体创建」，疑为笔误，
     实际菜单项以界面为准，见 gotchas）。

流程概览：
确认 IDE 已登录 → AskUserQuestion 确认实体与索引字段 →
检查实体已生成表 → 打开索引配置 → 添加索引 → 保存验证。

**作用域铁律**：仅在当前已打开的实体设计器内操作，
不新建构件包、不碰无关资源。

## When to use

- 用户要为某个持久化实体的字段建数据库索引。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` → **WorkBuddy 模式**。
- 工具列表含 integrated_code_mode 的 `Exec`（`await tools.browser_*`）→ **Trae 模式**。
- 两者都没有 → 提示用户启用对应浏览器扩展，终止流程。

## 参数

- **目标实体**（必填）：设计器画布中的持久化实体。
- **索引字段**（必填）：参与索引的属性（单字段或组合）。
- **索引名称**（按需）：用户指定的索引名，缺省用界面默认。
- **目标设计器**（按需）：在哪个构件包的实体设计器中操作。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 作用域确认（AskUserQuestion，必经）

确认：「将在 <设计器> 中为持久化实体 <实体名> 添加索引
（字段：<清单>），是否继续？」

### Step 3 — 前置检查：实体已生成表

1. 索引创建要求**先生成表**。确认方式：该实体此前已执行过
   `ynu-eos8-generate-table`，或实体来自数据源拖表
   （此路径系统已同步生成索引）。
2. 尚未生成表 → 停止本流程，经用户确认后先执行
   `ynu-eos8-generate-table`，再回到本 skill。

### Step 4 — 打开索引配置

1. 首选入口：**双击实体**进入实体属性配置，找到**索引配置**区。
2. 备选入口：**右键实体**打开菜单，选择索引相关项
   （菜单项名称以实际界面为准）。
3. 右键无反应走降级路线（见 gotchas）。

### Step 5 — 添加索引

1. 在索引配置中点击**添加索引**。
2. 填写索引名称（如有）并勾选/选择索引字段。
3. 每次填写后重取快照/DOM 确认内容正确。
4. ⚠️ 红线：界面中任何「删除」按钮/图标/菜单项严禁点击
   （包括已有索引条目旁的删除图标）。

### Step 6 — 保存并验证

1. 保存配置（若为即时保存则跳过）。
2. 重取快照/DOM：索引列表出现新索引，字段与用户指定一致。
3. 以索引条目实际出现为准，不以按钮点击成功为准。
4. 向用户汇报：索引名、字段清单。保持设计器打开供复用。

## 不变量

1. **前置硬性**：实体未生成表不建索引，先走生成表流程。
2. **删除红线**：任何「删除」入口严禁点击。
3. **行动后验证**：以索引列表实际出现新索引为准。
4. **失败即停**：索引配置入口两次定位失败即报告，不硬试。

## Notes / gotchas

- **文档第二种入口原文含糊**：官方文档写「点击实体右键，
  选择添加实体进行实体创建」，疑为笔误；实际右键菜单项
  名称待人工核对，以现场菜单为准。
- **拖表实体自带索引**：从数据源拖表生成的实体系统已同步
  生成索引，添加前先查看是否已存在，避免重复。
- **右键菜单可能无反应**，降级路线：①重取快照重试 →
  ②键盘 ContextMenu 键 → ③hover 看图标 → ④请用户手动点出菜单。
- **ref 时效性（Trae）**：快照变化后旧 ref 失效，重新取。
- **CDP 超时（仅 WorkBuddy）**：点击前 focus + sleep 约 2 秒。
- **衔接**：生成表用 `ynu-eos8-generate-table`；
  实体属性编辑用 `ynu-eos8-edit-entity`。
