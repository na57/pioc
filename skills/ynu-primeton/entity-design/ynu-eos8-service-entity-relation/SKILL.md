# 服务实体配置关系（EOS8，WorkBuddy / Trae 双运行时兼容）

## Overview

为 EOS8 **服务实体**配置实体关系。
官方要点：
- **设计图上，服务实体之间并没有进行连线**——
  不要在画布上找线或画线；
- 需要通过**实体属性配置**手动关联实体；
- 设置 **1:n 关系时，需手动勾选数组类型**。

流程概览：
确认 IDE 已登录 → AskUserQuestion 确认主从实体与关系类型 →
打开实体设计器 → 双击服务实体 → 实体属性配置中添加/编辑
属性并手动关联目标实体 → 1:n 勾选数组类型 → 保存验证。

**作用域铁律**：仅在当前已打开的实体设计器内操作，
只配置用户确认的关联属性，不碰其他实体的属性。

## When to use

- 用户要在服务实体之间建立关联（含 1:n），
  且通过属性配置手动关联。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` → **WorkBuddy 模式**。
- 工具列表含 integrated_code_mode 的 `Exec`（`await tools.browser_*`）→ **Trae 模式**。
- 两者都没有 → 提示用户启用对应浏览器扩展，终止流程。

## 参数

- **主实体（本体）**（必填）：要配置属性的服务实体。
- **关联实体**（必填）：被关联的服务实体。
- **关系类型**（必填）：1:1 / 1:n；**1:n 必须勾选数组类型**。
- **属性名**（按需）：承载关联的属性名，缺省用界面默认。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 作用域确认（AskUserQuestion，必经）

确认：「将在服务实体 <主实体> 的属性配置中手动关联
<关联实体>，关系类型 <1:1 / 1:n>，是否继续？」
类型为 1:n 时强调：将勾选**数组类型**。

### Step 3 — 打开实体属性配置

1. 资源树双击实体集/实体打开实体设计器。
2. **双击主服务实体**进入实体属性配置
   （双击无响应 → 右键实体走编辑入口，
   右键降级路线见 gotchas）。

### Step 4 — 手动关联实体

1. 在属性配置中添加（或编辑）一个属性，
   将其类型指向/关联目标服务实体（**手动关联**，
   不通过画布连线）。
2. **关系为 1:n 时，手动勾选「数组类型」**——
   这是本 skill 最关键的一步，勾选后重取快照/DOM
   确认勾选状态。
3. 每步填写后复验 value/勾选状态。
4. ⚠️ 红线：界面中任何「删除」按钮/图标严禁点击
   （包括属性行的删除图标）。

### Step 5 — 保存并验证

1. 保存配置（若为即时保存则跳过）。
2. 重取快照/DOM 验证：属性列表出现关联属性，
   类型指向正确；1:n 的属性其**数组类型已勾选**。
3. 向用户汇报：主实体、关联实体、关系类型、
   数组类型勾选状态。保持设计器打开供复用。

## 不变量

1. **1:n 必勾数组类型**：未勾选不得保存提交。
2. **只改确认项**：仅配置确认过的关联属性。
3. **删除红线**：任何「删除」入口严禁点击。
4. **行动后验证**：以属性列表实际状态为准。
5. **失败即停**：属性配置入口两次定位失败即报告。

## Notes / gotchas

- **画布上没有线**：服务实体关系不连线，画布无从验证；
  验证只能在实体属性配置里看属性与数组类型。
- **忘勾数组类型是最高频错误**：1:n 不勾数组类型会被按
  单对象处理，语义变成 1:1；保存前必须复核勾选状态。
- **控件名称待人工核对**：类型下拉/数组类型勾选框的具体
  控件名称以现场界面为准（官方文档以配图展示该操作）。
- **右键菜单可能无反应**，降级路线：①重取快照重试 →
  ②键盘 ContextMenu 键 → ③hover 看图标 → ④请用户手动点出菜单。
- **ref 时效性（Trae）**：界面切换后旧 ref 失效，重新快照。
- **CDP 超时（仅 WorkBuddy）**：点击前 focus + sleep 约 2 秒。
- **衔接**：服务实体一键生成服务用 `ynu-eos8-generate-service`；
  持久化实体关系（画布连线）用 `ynu-eos8-create-relation`。
