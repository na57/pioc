# 配置显示模型（EOS8 实体设计器，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 实体设计器中为持久化实体配置**显示模型**。
使用向导生成页面时，会按照显示模型配置去生成页面中的组件。
包含三类配置：

1. **显示控件配置**：在实体属性配置中为属性字段预先配置
   对应显示控件（单行文本、多行文本、下拉选择、日期选择、
   附件上传、子表格等），向导生成页面时字段使用已配置控件。
2. **下拉选择配置**：使用下拉选择控件时可配置下拉内容，
   配置内容同表单开发的下拉选择组件一致；需修改时点击
   下拉组件旁的**「设置」图标**。
3. **显示字段配置**：实体被引用时默认显示字段采用此处配置；
   未配置时默认为该实体的 **name 字段**。（例：A 页面下拉
   绑定 B 实体，B 已配置显示字段为 BField，下拉自动用
   BField 展示。）

流程概览：
确认 IDE 已登录 → AskUserQuestion 确认类别与内容 →
打开实体设计器 → 双击实体 → 按类别配置 → 保存验证。

**作用域铁律**：仅在当前已打开的实体设计器内操作，
只改用户确认的字段/配置项，不碰无关属性。

## When to use

- 用户要在生成页面前预设字段的显示控件。
- 用户要配置下拉选择控件的可选内容。
- 用户要设置实体被其他页面/组件引用时展示哪个字段。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` → **WorkBuddy 模式**。
- 工具列表含 integrated_code_mode 的 `Exec`（`await tools.browser_*`）→ **Trae 模式**。
- 两者都没有 → 提示用户启用对应浏览器扩展，终止流程。

## 参数

- **目标实体**（必填）：设计器画布中的持久化实体。
- **配置类别**（必填）：显示控件 / 下拉选择内容 / 显示字段。
- **字段与控件映射**（类别=显示控件时必填）：
  逐字段列出 → 目标控件。
- **下拉选项内容**（类别=下拉选择内容时必填）：
  选项列表（label/value）。
- **显示字段名**（类别=显示字段时必填）：实体属性名。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 作用域确认（AskUserQuestion，必经）

确认：「将为实体 <实体名> 配置显示模型——<类别与逐项内容>，
是否继续？」

### Step 3 — 打开实体属性配置

1. 资源树双击实体集/实体打开实体设计器。
2. **双击目标实体**进入实体属性配置界面
   （双击无响应 → 右键实体走编辑入口，
   右键降级路线见 gotchas）。

### Step 4 — 按类别配置

1. **显示控件**：逐个定位目标属性的显示控件配置，
   选择用户确认的控件类型；每项选完重取快照/DOM 确认。
2. **下拉选择内容**：定位已设定为下拉选择的属性，
   点击下拉组件旁的**「设置」图标**进入内容配置，
   按确认的选项列表填写。
3. **显示字段**：定位实体级显示字段配置，填入确认的属性名。
4. ⚠️ 红线：界面中任何「删除」按钮/图标严禁点击
   （包括属性行的删除图标）。

### Step 5 — 保存并验证

1. 保存配置（若为即时保存则跳过）。
2. 重取快照/DOM 回读：控件类型/下拉内容/显示字段与
   确认清单一致。
3. 向用户汇报逐项结果，并强调：**只有新生成的页面**
   会按此配置生成，已存在页面不受影响
   （需更新旧页面时经用户确认走 `ynu-eos8-generate-page`
   重新生成）。保持设计器打开供复用。

## 不变量

1. **只改确认项**：仅配置 AskUserQuestion 确认过的条目。
2. **删除红线**：任何「删除」入口严禁点击。
3. **行动后验证**：以配置回读一致为准，不以操作成功为准。
4. **失败即停**：单项两次失败即停下报告，不带病保存。

## Notes / gotchas

- **生效范围是硬约束**：显示模型只影响**新生成**的页面，
  已存在页面不受影响——改完配置 ≠ 旧页面变化，务必说明。
- **显示字段默认值**：未配置显示字段时默认用实体 name 字段。
- **下拉修改入口**：点下拉组件旁「设置」图标，不是重选控件。
- **右键菜单可能无反应**，降级路线：①重取快照重试 →
  ②键盘 ContextMenu 键 → ③hover 看图标 → ④请用户手动点出菜单。
- **ref 时效性（Trae）**：界面切换后旧 ref 失效，重新快照。
- **CDP 超时（仅 WorkBuddy）**：点击/输入前 focus + sleep 约 2 秒。
- **衔接**：页面生成用 `ynu-eos8-generate-page`。
