# 服务实体一键生成服务（EOS8，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 中为**服务实体**一键生成实体服务。
官方要点：
- **前置**：使用一键生成服务之前，**请确保已正确配置主键**
  （主键规则：值唯一、不含特殊符号、仅支持单个主键）。
- 入口：在服务实体的**服务配置页面**中，
  找到并点击**一键生成服务**按钮。
- 在**新建服务弹窗**中输入**关键字**，
  系统将自动根据关键字生成相应的**服务编码**。
- 确认生成后，可在**服务 → 实体服务**中查看已生成的服务。

实体服务模板：根据主键查询、分页查询、新增、修改、删除、
批量查询、批量删除（文档称 9 种模板但列出 7 种名称，
实际以弹窗可选模板为准，见 gotchas）。

流程概览：
确认 IDE 已登录 → AskUserQuestion 确认实体与关键字 →
校验主键已配置 → 双击服务实体 → 服务配置页点一键生成服务 →
弹窗输入关键字 → 确认生成 → 服务-实体服务中验证。

**作用域铁律**：仅对用户确认的服务实体生成服务，
不碰其他实体，不执行任何删除。

## When to use

- 用户要为服务实体批量生成增删改查实体服务。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` → **WorkBuddy 模式**。
- 工具列表含 integrated_code_mode 的 `Exec`（`await tools.browser_*`）→ **Trae 模式**。
- 两者都没有 → 提示用户启用对应浏览器扩展，终止流程。

## 参数

- **目标服务实体**（必填）：画布上的服务实体。
- **关键字**（必填）：用于生成服务编码的关键字。
- **服务编码**（按需）：弹窗中回显的自动生成编码，
  提交前需向用户展示认可。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 作用域确认（AskUserQuestion，必经）

确认：「将为服务实体 <实体名> 一键生成实体服务，
关键字：<关键字>，是否继续？」并回告：提交前会展示
自动生成的服务编码供确认。

### Step 3 — 前置检查：主键已配置

1. 双击目标服务实体进入配置，核对已设置主键
   （唯一、不含特殊符号、仅单主键）。
2. 未配置主键 → 停止，经用户确认先配置主键
   （在实体属性中设置），再回到本步骤重查。

### Step 4 — 一键生成服务

1. 在服务实体的**服务配置页面**中定位
   **一键生成服务**按钮并点击。
2. 在**新建服务弹窗**中输入关键字；系统自动生成服务编码。
3. 将服务编码与可选模板向用户确认后再点确认生成。
4. ⚠️ 红线：界面中任何「删除」按钮/图标/菜单项严禁点击
   （包括已生成服务条目旁的删除图标）。

### Step 5 — 验证与汇报

1. 导航/切换到 **服务 → 实体服务**，重取快照/DOM。
2. 验证：已生成的服务出现在实体服务列表中，
   名称/编码与确认一致；**以实际出现为准**，
   不以弹窗点击成功为准。
3. 向用户汇报生成的服务清单（含各服务用途一句话：
   主键查询/分页查询/新增/修改/删除/批量查询/批量删除）。
   保持页面打开供复用。

## 不变量

1. **主键前置硬性**：未配置主键不执行一键生成。
2. **编码先确认**：服务编码展示给用户确认后再提交生成。
3. **删除红线**：任何「删除」入口严禁点击。
4. **行动后验证**：以服务-实体服务列表实际出现为准。
5. **失败即停**：一键生成按钮两次定位失败即报告。

## Notes / gotchas

- **模板数量文档不一致**：文档称「9种模板」但仅列出
  7 种名称；实际模板以新建服务弹窗中的可选项为准，
  生成前向用户展示确认。
- **关键字决定服务编码**：输入前与用户确认关键字，
  避免生成不想要的服务编码。
- **验证位置固定**：服务 → 实体服务（不是画布、
  不是服务实体属性页）。
- **右键菜单可能无反应**，降级路线：①重取快照重试 →
  ②键盘 ContextMenu 键 → ③hover 看图标 → ④请用户手动点出菜单。
- **ref 时效性（Trae）**：页面切换后旧 ref 失效，重新快照。
- **CDP 超时（仅 WorkBuddy）**：点击前 focus + sleep 约 2 秒。
- **衔接**：服务实体创建本身由 `ynu-eos8-drag-create-entity`
  完成；服务实体关系配置用 `ynu-eos8-service-entity-relation`。
