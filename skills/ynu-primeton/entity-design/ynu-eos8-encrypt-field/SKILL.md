# 字段加密保存（EOS8 实体设计器，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 实体设计器中，为持久化实体的属性开启**加密保存**。
官方描述：选中加密选项后，该列数据在数据库中**存储时加密、
读取时自动解密**（**目前仅支持 string 类型数据**）；
用户可**自定义加密算法及密钥（支持国密）**。

流程概览：
确认 IDE 已登录 → AskUserQuestion 确认字段与算法/密钥 →
打开实体设计器 → 双击实体 → 选中目标字段勾选「加密」→
（按需）配置算法与密钥 → 保存验证。

**作用域铁律**：仅在当前已打开的实体设计器内操作，
只改用户确认的那个字段的加密配置，不碰其他字段。

## When to use

- 用户要给某个字段（如手机号、证件号）开启数据库加密存储。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` → **WorkBuddy 模式**。
- 工具列表含 integrated_code_mode 的 `Exec`（`await tools.browser_*`）→ **Trae 模式**。
- 两者都没有 → 提示用户启用对应浏览器扩展，终止流程。

## 参数

- **目标实体**（必填）：设计器画布中的持久化实体。
- **目标字段**（必填）：要加密的属性；**必须为 String 类型**。
- **算法/密钥**（按需）：用户自定义加密算法及密钥时提供；
  不提供则用界面默认。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 作用域确认（AskUserQuestion，必经）

确认：「将为实体 <实体名> 的字段 <字段名>（String）开启
加密保存<，算法/密钥：…>，是否继续？」

### Step 3 — 前置检查：字段类型

1. 打开实体设计器，双击目标实体进入属性配置。
2. 核对目标字段数据类型为 **String**；非 String →
   停止并告知用户「目前仅支持 string 类型数据加密」，
   不得强行操作。

### Step 4 — 勾选加密并配置算法/密钥

1. 选中目标字段，在数据库属性区找到**加密**选项并勾选。
2. 需要自定义算法时，配置加密算法及密钥（支持国密），
   按用户确认的值填写。
3. 勾选/填写后重取快照/DOM 确认状态。
4. ⚠️ 红线：界面中任何「删除」按钮/图标严禁点击
   （包括字段行上的删除图标）。

### Step 5 — 保存并验证

1. 保存配置（若为即时保存则跳过）。
2. 重取快照/DOM：目标字段的加密选项处于选中状态，
   算法/密钥配置回读一致。
3. 向用户汇报结果，并提示：数据库中该列存储为密文，
   读取由平台自动解密。保持设计器打开供复用。

## 不变量

1. **类型硬性**：非 String 字段不开启加密，直接报告。
2. **只改确认项**：只勾选用户确认的字段，不动其他字段。
3. **删除红线**：任何「删除」入口严禁点击。
4. **行动后验证**：以加密选项实际选中状态为准。
5. **失败即停**：加密选项两次定位失败即报告，不硬试。

## Notes / gotchas

- **存量数据未说明**：文档未说明对已有历史数据的影响；
  对已有数据的列开启加密前，建议先在测试环境验证
  「写入 → 读取」往返正常再上生产。
- **解密自动完成**：读取时平台自动解密，页面/服务层
  无需（也不应）自行处理加解密。
- **双击 vs 右键**：双击实体进入属性配置；右键为备用入口。
- **ref 时效性（Trae）**：快照变化后旧 ref 失效，重新取。
- **CDP 超时（仅 WorkBuddy）**：点击前 focus + sleep 约 2 秒。
- **衔接**：字段类型调整用 `ynu-eos8-edit-entity`（经确认）；
  改动若涉及表结构，引导 `ynu-eos8-generate-table`。
