# 查看数据——表数据预览（EOS8 实体设计器，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 实体设计器的**数据源**面板中预览某张表的数据。
官方描述：数据源数据上划过（hover）时展示**两个图标**：
**表数据预览**和**删除**。点击表数据预览图标即可查看表中数据。

流程概览：
确认 IDE 已登录 → AskUserQuestion 确认目标表 → 打开实体设计器 →
数据源面板 hover 目标表 → 点击「表数据预览」→ 读取数据并汇报。

**删除红线（本 skill 核心安全约束）**：hover 出现的两个图标中
第二个是「删除」。本 skill **只允许点击表数据预览**，
删除图标**严禁点击、严禁尝试**。

## When to use

- 用户想查看/预览某张数据库表的数据内容。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` → **WorkBuddy 模式**。
- 工具列表含 integrated_code_mode 的 `Exec`（`await tools.browser_*`）→ **Trae 模式**。
- 两者都没有 → 提示用户启用对应浏览器扩展，终止流程。

## 参数

- **目标表**（必填）：数据源面板中的表名。
- **目标设计器**（按需）：在哪个构件包的实体设计器中操作。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 作用域确认（AskUserQuestion，必经）

确认：「将在 <设计器> 的数据源面板预览表 <表名> 的数据，是否继续？」

### Step 3 — 打开实体设计器并定位数据源面板

1. 资源树双击实体集/实体打开实体设计器（入口实测确认）。
2. 找到**数据源**面板（画布侧栏，列出数据源类型 → 表）。
3. 展开数据源定位目标表（若找不到表，可能被「显示系统表」开关
   或面板折叠影响，见 gotchas）。

### Step 4 — hover 目标表，点击「表数据预览」

1. 对目标表节点执行 hover（Trae：Exec 内 `browser_hover`；
   WorkBuddy：对应 hover 工具）。
2. hover 后出现**两个图标**：
   - 图标 1 = **表数据预览** → 点击它；
   - 图标 2 = **删除** → **绝对不点击、不定位尝试、不靠近**。
3. 若图标未渲染（Vue 条件渲染以 `<!---->` 占位，合成事件可能
   不触发渲染）：① 重取快照重试 hover 一次；② 仍不出现则
   告知用户 hover 图标自动化不可用，请用户手动点击预览图标，
   agent 接手读取数据。
4. 等待数据预览弹层/表格出现。

### Step 5 — 读取并汇报数据

1. 从预览界面读取表结构（列名）与数据行（Trae：快照/DOM 提取；
   WorkBuddy：DOM 提取）。
2. 向用户汇报：行数（若可见）、列清单、前若干行样例数据。
3. 关闭预览（点关闭按钮）恢复界面，**只关预览，不碰其他**。

## 不变量

1. **只读操作**：本 skill 不修改任何数据；预览窗口内不做任何写操作。
2. **删除红线**：hover 出现的「删除」图标严禁点击。
3. **行动后验证**：以预览数据实际读出为准，不以图标点击成功为准。
4. **失败即停**：图标不渲染两次失败即转用户手动。

## Notes / gotchas

- **hover 图标是 Vue 条件渲染**：实测同类界面中 `<!---->` 占位
  不因合成事件或 `browser_hover` 渲染；预判此风险，及时转用户手动。
- **看不到目标表**：检查数据源一级目录的「显示系统表」开关
  （`ynu-eos8-toggle-system-tables`）与面板折叠状态。
- **ref 时效性（Trae）**：hover 前后快照变化，重新取 ref。
- **CDP 超时（仅 WorkBuddy）**：hover/点击前 focus + sleep 约 2 秒。
- **衔接**：需要基于表生成实体时用 `ynu-eos8-create-entity-from-datasource`。
