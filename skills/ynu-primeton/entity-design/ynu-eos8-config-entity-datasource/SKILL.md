# 配置实体数据源（EOS8，WorkBuddy / Trae 双运行时兼容）

## Overview

为 EOS8 实体配置数据源。**注意：本操作不在实体设计器内**，
官方配置路径为：**应用 → 管理配置 → 实体数据源配置**。
系统默认提供名称为 **default** 的数据源，
不指定数据源引用名称时取默认数据源。

**包含的实体名称 / 排除的实体名称**输入规则（两者相同）：
1. 多个实体名称用**逗号**分割；
2. 实体名称必须是 **entityName**（实体全称：
   构件包名称.实体集名称.实体名称）；
3. 支持名称使用通配符 **\***。

官方示例：`com.primeton.das.eosDictEntry.*,com.primeton.das.criteria.*`

流程概览：
确认已登录 → AskUserQuestion 确认数据源与实体名称清单 →
导航到管理配置-实体数据源配置 → 填写包含/排除实体名称 →
保存验证。

**作用域铁律**：只改动「实体数据源配置」页中用户确认的
输入框，不碰管理配置下的其他任何配置项。

## When to use

- 用户要把某些实体指向非 default 数据源，或调整
  包含/排除实体名单。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` → **WorkBuddy 模式**。
- 工具列表含 integrated_code_mode 的 `Exec`（`await tools.browser_*`）→ **Trae 模式**。
- 两者都没有 → 提示用户启用对应浏览器扩展，终止流程。

## 参数

- **数据源引用名称**（必填）：目标数据源；用 default 需用户明示。
- **包含的实体名称**（按需）：entityName 列表，逗号分割，
  支持通配符 \*。
- **排除的实体名称**（按需）：规则同上。

缺参数 → `AskUserQuestion` 询问，不要猜。
实体全称可先用 `ynu-eos8-copy-entity-name` 从设计器获取。

## Workflow

### Step 1 — 确认平台已打开且已登录

复用 `ynu-lowcode-login` 等产出的标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 作用域确认（AskUserQuestion，必经）

确认：「将在 应用-管理配置-实体数据源配置 中，
数据源设为 <名称>，包含实体：<清单>，排除实体：<清单>，
是否继续？」并回告：entityName 必须是实体全称，
格式 构件包.实体集.实体名称。

### Step 3 — 导航到实体数据源配置

1. 按路径导航：应用 → 管理配置 → 实体数据源配置
   （菜单具体标签以实际界面为准，见 gotchas）。
2. 等待配置页加载（包含/排除实体名称输入框出现）。
3. 导航两次失败即停下请用户指路，不乱点。

### Step 4 — 填写配置

1. 在「包含的实体名称」输入框填入确认的 entityName 清单
   （逗号分割，支持通配符 \*）。
2. 在「排除的实体名称」输入框按需填写。
3. 指定数据源引用名称（按界面提供的选择/输入方式）。
4. 每次填写后重取快照/DOM 确认 value 正确。
5. ⚠️ 红线：页面中任何「删除」按钮/图标严禁点击
   （包括已有配置条目的删除图标）。

### Step 5 — 保存并验证

1. 保存配置（若为即时保存则跳过）。
2. 重取快照/DOM 回读：各输入框内容与确认清单一致。
3. 向用户汇报：数据源、包含/排除清单；并提示
   逻辑流中不传数据源值时默认取 default 数据源。
   保持页面打开供复用。

## 不变量

1. **位置正确**：本操作只发生在管理配置-实体数据源配置页，
   不进入实体设计器改实体。
2. **只改确认项**：仅填写确认过的输入框，不碰其他配置。
3. **删除红线**：任何「删除」入口严禁点击。
4. **行动后验证**：以保存后回读内容为准。
5. **失败即停**：页面导航两次失败即报告。

## Notes / gotchas

- **entityName 是全称**：不是裸实体名；格式
  构件包名称.实体集名称.实体名称；可配合通配符 \*。
- **逗号分割**：官方示例为英文逗号；若界面校验拒绝，
  以界面提示为准核对分隔符。
- **菜单标签待人工核对**：「应用-管理配置-实体数据源配置」
  为官方文档路径，实际菜单层级/名称以现场为准。
- **默认数据源**：不指定即 default；逻辑流多数据源场景
  不传值也取 default。
- **ref 时效性（Trae）**：页面跳转后旧 ref 失效，重新快照。
- **CDP 超时（仅 WorkBuddy）**：点击/输入前 focus + sleep 约 2 秒。
- **衔接**：取实体全称用 `ynu-eos8-copy-entity-name`。
