# 复制实体名称（EOS8 实体设计器，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 实体设计器中，通过实体的右键操作菜单执行
**复制实体名称**。

**实体名称结构**：`构件包名称.实体集名称.实体名称`
（三段式，点号分隔）。

流程概览：
确认 IDE 已登录 → 确认目标实体 → 右键实体 →
菜单「复制实体名称」→ 验证并汇报全名。

## When to use

- 用户需要实体的完整名称（如后续接口/脚本里引用实体）。
- 用户说「复制实体名」「实体全名是什么」。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` → **WorkBuddy 模式**。
- 工具列表含 integrated_code_mode 的 `Exec`（`await tools.browser_*`）→ **Trae 模式**。
- 两者都没有 → 提示用户启用对应浏览器扩展，终止流程。

## 参数

- **目标实体**（必填）：画布/资源树中的实体。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 作用域确认

本操作为只读（仅写剪贴板），向用户确认目标实体即可
（简短确认，不必长流程）。

### Step 3 — 打开实体设计器，定位实体

资源树双击实体集/实体打开实体设计器；画布定位目标实体。

### Step 4 — 右键实体，菜单选「复制实体名称」

1. 右键实体节点打开操作菜单。
2. **右键可能无反应**：① 重取快照重试一次；② 键盘 ContextMenu 键；
   ③ hover 看操作图标；④ 请用户手动点出菜单并选择该项。
3. 菜单中选「复制实体名称」。
4. ⚠️ 红线：菜单中的「删除」项**严禁点击**。

### Step 5 — 验证并汇报

1. **推算全名**：按三段式结构推算预期全名：
   `<构件包名称>.<实体集名称>.<实体名称>`（各段取自当前上下文）。
2. **读取剪贴板验证**（尽力而为）：
   - Trae：Exec 内执行 `await tools.browser_evaluate`（或等价脚本）
     读 `navigator.clipboard.readText()`（需要页面焦点与权限，
     失败不阻塞）；
   - WorkBuddy：对应脚本能力同样尝试；
   - 读不到剪贴板 → 不判定失败，以「已执行复制 + 推算全名」汇报，
     并说明可让用户粘贴核对。
3. 剪贴板内容与推算不一致 → 以剪贴板实际内容为准汇报，并提示差异。

### Step 6 — 保留会话

保持标签页与设计器打开，供后续 skill 复用。

## 不变量

1. **只读操作**：不修改实体与数据。
2. **行动后验证**：剪贴板读不到时用推算名 + 用户粘贴核对，
   不凭「菜单点击成功」断言。
3. **删除红线**：菜单「删除」项严禁点击、不尝试。

## Notes / gotchas

- **三段式结构**：构件包名称.实体集名称.实体名称——
  推算时各段用**名称**而非编码。
- **剪贴板权限**：浏览器自动化读剪贴板常因权限/焦点失败，
  属正常情况，走推算+核对路线。
- **右键菜单降级路线**见 Step 4。
- **ref 时效性（Trae）**：菜单弹出后旧 ref 失效，重新快照。
- **CDP 超时（仅 WorkBuddy）**：点击前 focus + sleep 约 2 秒。
