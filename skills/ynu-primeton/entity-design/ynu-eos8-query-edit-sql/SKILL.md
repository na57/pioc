# 查询实体编辑 SQL（EOS8 实体设计器，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 实体设计器中为**查询实体**编辑 SQL。
官方描述：双击查询实体进入配置，点击编辑并输入查询语句；
设置默认数据源（数据优先匹配该数据源，默认为 default），
输入 sql 语句，点击**查询**按钮进行 sql 查询，
查询后数据库记录展示在**查询条件下方的表格**中；
查询后可收起查询 SQL 配置；点击**确认**后生成查询实体。

流程概览：
确认 IDE 已登录 → AskUserQuestion 确认目标查询实体与 SQL →
双击查询实体进入配置 → 设置默认数据源 → 输入 SQL →
点击查询 → 以结果表格验证 → 点击确认生成查询实体。

**作用域铁律**：仅在当前已打开的实体设计器内操作，
不新建构件包、不碰无关资源。

## When to use

- 用户要为某个查询实体输入/修改查询 SQL 并执行验证。
- 用户要指定查询结果映射到查询实体的属性。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` → **WorkBuddy 模式**。
- 工具列表含 integrated_code_mode 的 `Exec`（`await tools.browser_*`）→ **Trae 模式**。
- 两者都没有 → 提示用户启用对应浏览器扩展，终止流程。

## 参数

- **目标查询实体**（必填）：画布上的查询实体名称。
- **SQL 语句**（必填）：要执行的 SELECT 语句（或用户口述的查询意图，由用户确认后落为 SQL）。
- **默认数据源**（选填）：数据优先匹配该数据源，默认 `default`。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 作用域确认（AskUserQuestion，必经）

确认：「将在 <设计器> 中为查询实体 <实体名> 编辑并执行 SQL，
确认后生成查询实体，是否继续？」同时向用户展示将执行的 SQL 全文。

### Step 3 — 打开查询实体配置

1. 资源树双击实体集/实体打开实体设计器（入口实测确认）。
2. 前置条件：画布上须已存在目标查询实体；没有则提示用户
   先用 `ynu-eos8-drag-create-entity` 拖拽创建查询实体，本 skill 终止。
3. **双击**目标查询实体进入实体配置界面。

### Step 4 — 编辑 SQL 并执行

1. 在 SQL 编辑区**设置默认数据源**（默认 `default`，
   数据优先匹配该数据源）。
2. 在 SQL 输入框输入 SELECT 语句。
3. 点击**查询**按钮执行。

### Step 5 — 验证（以结果表格为准）

1. **验证方式**：执行后查询结果以**表格**展示——
   数据库记录出现在**查询条件下方的表格**中。
   以表格实际出现列名与数据行为准，不以「查询按钮点击成功」为准。
2. 表格出现后可**收起查询 SQL 配置**。
3. 点击**确认**生成查询实体（确认前向用户复述将要生成的实体名与属性映射）。
4. 向用户汇报：返回列数/行数、列清单、样例数据、生成的实体属性。

## 不变量

1. **SQL 只读红线**：SQL 只允许 SELECT 语义；用户要求执行
   增删改语句时拒绝并说明（查询实体只能用于查询，
   不可以对其执行增删改的操作）。
2. **删除红线**：界面上任何「删除」按钮/图标/菜单项严禁点击。
3. **行动后验证**：以查询结果表格实际展示为准，不以点击成功为准。
4. **确认即生成**：点击「确认」会生成查询实体，属写操作，
   必须经用户在 Step 2 确认后再点。
5. **失败即停**：查询按钮点击后表格未出现、或报错，停止流程并汇报原文。

## Notes / gotchas

- **id 保留字**：查询实体里不能定义属性名叫 id 的属性
  （唯一标识对应的属性可以使用 id 这个名称）。
- **重名列必须起别名**：查询 SQL 有 2 个相同列名时，
  需起不同的别名区分，否则无法正确映射。
- **实体名称仅创建时可编辑**：确认生成后实体名称不可再改，
  确认前务必与用户核对实体名称。
- **唯一标识注意事项**：可指定某列或几列作为查询实体唯一标识；
  未指定时 EOS 自动用一个常量作唯一标识——但默认唯一标识
  不能与持久化实体做单向 1:1 和单向 N:1 关联，否则对持久化实体
  做操作会抛异常。有此类关联计划的，确认前提醒用户指定唯一标识列。
- **同一数据集中查询实体名称唯一**。
- **生成实体按 default 查询**：运行时按数据库连接自动判断类型，
  找不到对应连接类型配置时回退 default；跨库 SQL 配置见
  `ynu-eos8-query-join-type`。
- **右键菜单可能无反应**：降级路线 ①重取快照重试 →
  ②键盘 ContextMenu 键 → ③hover 看图标 → ④请用户手动点出菜单。
- **ref 时效性（Trae）**：快照变化后旧 ref 失效，重新取。
- **CDP 超时（仅 WorkBuddy）**：点击前 focus + sleep 约 2 秒。
- **衔接**：SQL 助手辅助输入见 `ynu-eos8-query-sql-assistant`；
  跨数据库连接类型见 `ynu-eos8-query-join-type`。
