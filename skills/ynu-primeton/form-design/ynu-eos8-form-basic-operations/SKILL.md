# 表单设计器基本操作（EOS8 表单设计器，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 表单设计器中执行基本操作。官方描述：设计器整体页面分为
**「顶部操作栏」「左侧组件区」「中间画布」「右侧属性配置面板」**
四个部分。本 skill 聚合文档全部基础操作，按文档小节组织：

- 顶部操作栏：**编码模式**、**预览**、**表单设置**
  （基础设置 / 业务设置 / 扩展逻辑 / 按钮设置 / 打印模版 / 高级设置）；
- 左侧组件区：**大纲树**、**系统组件**（添加组件）、**扩展组件**；
- 中间画布：**画布控件**操作、**表单国际化设置**；
- 右侧属性配置面板：**属性配置**。

流程概览：
确认 IDE 已登录 → AskUserQuestion 确认表单与单项操作 →
定位设计器对应区域 → 按小节执行 → 以实际结果验证。

**作用域铁律**：仅在当前已打开的表单设计器内操作，
不碰无关表单与资源。聚合型 skill：每次只执行用户指定的
单项操作对应的小节，不要求全跑。

**删除红线（本 skill 核心安全约束）**：大纲树右键菜单中的
「批量删除」、画布控件操作中的「删除」**严禁点击、严禁尝试**；
若用户要求删除组件，告知此 skill 不执行删除，请用户手动操作。

## When to use

- 用户要在表单设计器中：查看/修改生成代码（编码模式）、
  预览页面效果、打开表单设置、添加组件、用大纲树调整
  顺序/层级/批量移动、添加扩展组件、在画布中拖拽布局/
  复制/设置状态/回退、设置国际化翻译、配置控件属性。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` → **WorkBuddy 模式**。
- 工具列表含 integrated_code_mode 的 `Exec`（`await tools.browser_*`）→ **Trae 模式**。
- 两者都没有 → 提示用户启用对应浏览器扩展，终止流程。

## 参数

- **目标表单**（必填）：当前打开的表单设计器中的表单。
- **操作项**（必填，单选或多选）：`编码模式` / `预览` /
  `表单设置` / `添加组件` / `大纲树` / `扩展组件` /
  `画布控件` / `国际化` / `属性面板`。
- **操作细节**（按需）：如组件名、目标容器、语言等。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 作用域确认（AskUserQuestion，必经）

确认：「将在表单 <表单名> 中执行 <操作项>，是否继续？」

### Step 3 — 识别设计器四区

重取快照/DOM，确认当前处于表单设计器，并定位：
顶部操作栏（编码模式/预览/表单设置入口）、左侧组件区
（大纲/系统组件/扩展组件）、中间画布、右侧属性配置面板。

### Step 4A — 编码模式（顶部操作栏）

1. 点击顶部「编码模式」，页面分为**编码区**与**效果区**。
2. 编码区标签页：
   - `Script`：定义变量、事件、方法等；其中
     「表单高级设置→事件下的方法」与「组件高级→添加事件下的方法」
     两个代码块支持修改后保存到页面资源；
   - `Pc template`：PC 端页面渲染模版（组件转高级后可改并保存）；
   - `Css`：PC 端 CSS，可直接编写；
   - `Mobile template` / `Mobile css`：移动端模版与 CSS。
3. 修改后点击**右上角保存**或 **Ctrl + S** 保存到页面资源。
4. 验证：保存提示出现；切走再切回标签页，内容仍为修改后内容。

### Step 4B — 预览（顶部操作栏）

1. 点击顶部「预览」，新窗口打开页面效果。
2. 可切换 **PC 端 / 移动端 / 国际化语言**查看对应效果。
3. 验证：新窗口打开且页面渲染正常；向用户汇报所见。
4. 预览窗口为只读观察，不做任何写操作。

### Step 4C — 表单设置（顶部操作栏）

1. 点击顶部「表单设置」，包含页签：**基础设置、业务设置、
   扩展逻辑、按钮设置、打印模版、高级设置**。
2. 高级设置含方法、参数、事件、监听、计算属性、变量的配置。
3. 各页签的专项操作衔接对应 skill：
   基础设置 → `ynu-eos8-form-common-settings`；
   业务设置 → `ynu-eos8-form-business-rules`；
   扩展逻辑 → `ynu-eos8-form-extension-logic`；
   按钮设置 → `ynu-eos8-form-buttons-setting`。
4. 验证：目标页签打开且内容可读。

### Step 4D — 添加组件（左侧组件区 → 画布）

1. 左侧组件区展示**系统组件**（可直接使用）。
2. **点击组件**直接插入画布，或**拖拽**到画布中/大纲树中的
   指定位置（Trae：拖拽用 Exec 内拖拽能力或 click 插入；
   WorkBuddy：用对应拖拽工具）。
3. 验证：画布与大纲树中出现新组件节点。

### Step 4E — 大纲树（左侧组件区「大纲」）

1. 大纲按行列出画布中所有组件。
2. **拖拽**调整组件顺序和层级。
3. 右键大纲节点可对多个组件**批量移动**：
   移动到最外层顶部 / 移动到指定容器 / 移动到最外层底部。
4. ⚠️ 右键菜单中的「**批量删除**」**严禁点击**；删除类操作一律不做。
5. 验证：画布中组件位置/层级随大纲调整同步变化。

### Step 4F — 扩展组件（左侧组件区）

1. 系统组件不满足需求时使用扩展组件。
2. 在左侧组件区切换到「扩展组件」，按界面提供的
   添加步骤添加自定义扩展组件。
3. 添加后像系统组件一样点击或拖拽使用。
4. 验证：扩展组件列表出现新组件，可插入画布。

### Step 4G — 画布控件（中间画布）

1. 画布中根据光标提示**拖拽布局**。
2. 可对控件进行**复制**、**设置状态**、**回退**操作。
3. ⚠️ 控件「删除」**严禁点击**；删除类操作一律不做。
4. 验证：以画布实际呈现结果为准，不以操作成功点击为准。

### Step 4H — 表单国际化设置（中间画布）

1. 点击画布上的**小地球图标**打开国际化设置。
2. 提取页面中的中文 → 通过 **AI 智能翻译**生成翻译 →
   可新增/补充文字翻译 → **保存**结果。
3. AI 翻译结果汇报给用户确认后再保存。
4. 验证：翻译列表出现条目且保存成功。

### Step 4I — 右侧属性配置面板

1. 选中画布中的控件，右侧面板配置控件常用属性。
2. 配置后画布中控件**实时**看到生效结果。
3. 每项修改后重取快照确认已写入，再继续下一项。
4. 验证：以画布实时变化为准。

## 不变量

1. **单项执行**：每次只执行用户指定操作项对应的小节。
2. **行动后验证**：以画布/大纲/保存结果等实际状态为准，
   不以点击成功为准。
3. **失败即停**：同一操作两次失败即停下汇报，不硬试。
4. **删除红线**：大纲「批量删除」与画布「删除」严禁点击；
   只做移动、复制、拖拽等非删除操作。
5. **写前确认**：修改代码（编码模式）、保存国际化等
   写操作先向用户汇报将写入的内容并确认。

## Notes / gotchas

- **编码模式保存范围有限**：Script 中仅「表单高级设置→事件」
  与「组件高级→添加事件」下的方法代码块支持保存；
  template/css 需组件转高级后才可保存——保存无效时如实告知。
- **右键菜单降级路线**：①重取快照重试→②键盘 ContextMenu 键→
  ③hover 看图标→④请用户手动点出菜单。
- **拖拽失败**：大纲/画布拖拽若自动化不稳定，
  降级为点击组件插入 + 大纲右键批量移动，或转用户手动。
- **ref 时效性（Trae）**：切页签/添加组件后快照变化，旧 ref 失效，重新取。
- **CDP 超时（仅 WorkBuddy）**：点击前 focus + sleep 约 2 秒。
- **Vue 条件渲染**：hover 图标以 `<!---->` 占位可能不因合成事件渲染，
  两次失败转用户手动。
- **衔接**：表单设置各页签见对应专项 skill；
  预览发现问题可转 `ynu-eos8-form-business-rules` 调整逻辑。
