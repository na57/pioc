# 表单公共设置（EOS8 表单设计器，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 表单设计器中配置表单公共设置。入口为
**顶部操作栏「表单设置」→「基础设置」页签**（即通用设置）。
文档共 9 项配置，本 skill 按文档小节聚合：

**显示名称**、**资源编码**、**绑定实体**、**级联深度**、
**标签宽度**、**标签对齐**、**移动端展示同PC端**、
**表单尺寸**、**显示样式**。

流程概览：
确认 IDE 已登录 → AskUserQuestion 确认表单与配置项目标值 →
表单设置 → 基础设置 → 逐项修改 → 保存并以实际结果验证。

**作用域铁律**：仅在当前已打开的表单设计器内操作，
只改用户确认过的配置项，不碰其他表单与无关配置。

## When to use

- 用户要修改表单级公共配置：弹窗标题/提示信息名称、
  级联查询层级、标签宽度与对齐、移动端布局同 PC、
  控件尺寸、表格展示样式等。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` → **WorkBuddy 模式**。
- 工具列表含 integrated_code_mode 的 `Exec`（`await tools.browser_*`）→ **Trae 模式**。
- 两者都没有 → 提示用户启用对应浏览器扩展，终止流程。

## 参数

- **目标表单**（必填）：当前打开的表单设计器中的表单。
- **配置项与目标值**（必填，可多项）：
  `显示名称` / `资源编码`（只读操作） / `绑定实体`（只读跳转） /
  `级联深度`（-1/0/1） / `标签宽度` / `标签对齐`（左/右/顶部） /
  `移动端展示同PC端`（开/关） / `表单尺寸` / `显示样式`（正常/表格）。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 作用域确认（AskUserQuestion，必经）

确认：「将在表单 <表单名> 中修改以下配置：<逐项列出
配置项 → 当前值 → 目标值>，是否继续？」

### Step 3 — 打开表单设置 → 基础设置

1. 点击顶部「表单设置」，切换到「基础设置」页签。
2. 重取快照/DOM，逐项读出当前配置值，与用户确认的目标值对照。

### Step 4 — 按配置项修改（按用户指定的项走对应小节）

#### 4.1 显示名称

- 填写「显示名称」输入框。
- 生效位置：表单弹窗 title 和提示信息中显示该内容。
- 验证：保存后调试预览/弹窗标题中出现新名称。

#### 4.2 资源编码（只读操作）

- 用于表单资源的定位。可点击「复制链接」「复制编码」，
  或点击「打开页面」直接定位到表单页面。
- 不修改编码本身；操作后向用户汇报复制内容/新开页面结果。

#### 4.3 绑定实体（只读操作）

- 该项指明当前表单页面的实体。鼠标移上去可查看实体全称
  （构件包.实体集.实体）；点击末尾链接图标可跳转定位到
  实体资源详情。
- 仅查看/跳转汇报，不修改绑定关系；hover 全称或点击链接后
  重取快照读出实体全称并汇报。

#### 4.4 级联深度

- 设置有关系实体的查询层级，一般用于 1:n 场景：
  `-1` 无限级联；`0` 不做级联；`1` 只级联一级（默认 1）。
- 场景示例：供应商与物料 1:n 时，深度 1 查供应商带物料，
  深度 2 连物料下的规则数据也一起带出。
- 修改前向用户确认取值（-1 有性能风险，重点提示）。

#### 4.5 标签宽度

- 设置表单中标签的整体宽度，填写对应输入框。

#### 4.6 标签对齐

- 可选：左对齐、右对齐、顶部对齐，按用户指定选择。

#### 4.7 移动端展示同PC端

- 开启后移动端布局样式与 PC 端一致。
- **前置条件（文档特有）**：PC 端前端全量中需要建一个
  `mobile` 文件夹放移动端前端介质；不满足时如实告知用户，
  不强行开启。

#### 4.8 表单尺寸

- 对表单中整体控件的尺寸进行设置。

#### 4.9 显示样式

- 决定整个表单的展示模式：默认「正常表单」模式，
  可选择「**表格**」模式。

### Step 5 — 保存并验证

1. 保存设置（保存按钮/自动保存以界面实际为准）。
2. **行动后验证**：重取快照回读各配置项已写入；
   涉及显示效果的（显示名称、标签对齐、表单尺寸、显示样式、
   移动端布局）可通过「调试预览」查看实际效果并汇报。
3. 有报错 → 原样报告，不动其他配置。

## 不变量

1. **改前必确认**：每个配置项的当前值与目标值经 AskUserQuestion 确认。
2. **只改指定项**：未确认的配置项一律不碰。
3. **行动后验证**：以回读值/预览效果为准，不以填写成功为准。
4. **失败即停**：同一配置两次写入失败即停下汇报。
5. **删除红线**：界面任何「删除」入口严禁点击（本页通常无，仍列为红线）。

## Notes / gotchas

- **级联深度默认 1**：用户说"要级联"时确认具体层级，
  -1 无限级联可能拖慢查询，需二次确认。
- **移动端同 PC 端的前端介质要求**：需 PC 端前端全量中存在
  `mobile` 文件夹，否则设置不生效。
- **显示样式改表格模式**：改完在「调试预览」中确认效果
  符合预期再收尾。
- **ref 时效性（Trae）**：切换页签/保存后快照变化，旧 ref 失效，重新取。
- **CDP 超时（仅 WorkBuddy）**：点击前 focus + sleep 约 2 秒。
- **Vue 条件渲染**：hover 绑定实体看全称可能出现 `<!---->` 占位，
  两次失败转用户手动 hover。
- **衔接**：按钮、业务规则等配置见
  `ynu-eos8-form-buttons-setting`、`ynu-eos8-form-business-rules`。
