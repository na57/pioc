# 创建表单（EOS8 表单设计器，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 IDE 中创建一个与实体绑定的表单页面。官方描述：创建一个页面
需要选择一个实体进行绑定，生成的页面会根据实体配置的显示控件生成页面。
创建页面有**两种入口**：

1. **从菜单索引创建**：右键点击构件包下「页面」→ 新建页面；
2. **从实体集创建**：右键点击实体 → 生成页面。

流程概览：
确认 IDE 已登录 → AskUserQuestion 确认入口与绑定实体 →
右键目标打开菜单 → 新建页面 / 生成页面 → 选择页面实体 →
点击创建 → 验证设计器打开且资源树出现新页面。

**作用域铁律**：只在目标构件包内创建页面，不碰无关构件包、
无关实体与其他资源；创建前必须经 `AskUserQuestion` 确认。

## When to use

- 用户想新建一个表单页面（页面会绑定某实体）。
- 前置：绑定目标实体已存在（如由 `ynu-eos8-import-entity` /
  `ynu-eos8-drag-create-entity` / `ynu-eos8-create-entity-from-datasource` 创建），
  持久化实体需先有表（`ynu-eos8-generate-table`）。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` → **WorkBuddy 模式**。
- 工具列表含 integrated_code_mode 的 `Exec`（`await tools.browser_*`）→ **Trae 模式**。
- 两者都没有 → 提示用户启用对应浏览器扩展，终止流程。

## 参数

- **入口**（必填二选一）：`菜单索引`（需构件包名）或 `实体集`（需实体名）。
- **绑定实体**（必填）：新建页面要绑定的实体（菜单索引入口在弹窗中选择）。
- **构件包**（按需）：在哪个构件包下创建。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 作用域确认（AskUserQuestion，必经）

确认：「将在构件包 <构件包名> 中，以 <菜单索引 / 实体集> 方式
创建绑定实体 <实体名> 的页面，是否继续？」

### Step 3 — 入口 A：从菜单索引创建

1. 资源树展开目标构件包，右键其下「页面」节点。
2. **右键可能无反应**（合成右键对部分节点不触发自定义菜单）。
   降级路线：① 重取快照重试一次；② 键盘 ContextMenu 键；
   ③ hover 看操作图标；④ 请用户手动点出菜单后继续。
3. 菜单中选「新建页面」，等待新建页面弹窗出现。
4. 在弹窗中选择「页面实体」为要绑定的实体。
5. 点击「创建」按钮。

### Step 4 — 入口 B：从实体集创建

1. 在资源树打开/定位构件包下的目标实体。
2. 右键点击实体，菜单选「生成页面」（降级路线同 Step 3）。
3. 在生成向导/弹窗中点击「创建」。
4. 生成的页面自动与该实体绑定，并根据实体配置的显示控件生成页面。
   此入口与 `ynu-eos8-generate-page` 一致，可互相衔接。

### Step 5 — 验证

1. **成功验证以实际结果为准**：重取快照/DOM，确认
   ① 页面设计器（表单设计器）已打开；且
   ② 构件包「页面」资源下出现新页面节点。
2. 有报错 → 原样报告，不动其他内容。

### Step 6 — 关系实体提示（如适用）

若绑定的实体处于 **1:n 关系**的一方：生成 1 方实体页面时，
平台会**自动创建 n 方的页面**（若 n 方页面已生成则不再重复创建）。
创建后向用户汇报是否连带生成了 n 方页面，仅汇报，不做任何删除或改动。

## 不变量

1. **创建前必确认**：入口、构件包、绑定实体经 AskUserQuestion 确认。
2. **行动后验证**：以资源树出现新页面 + 设计器打开为准，
   不以按钮点击成功为准。
3. **失败即停**：报错原样报告，不擅自改配置重试超过一次。
4. **删除红线**：任何「删除」按钮/图标/菜单项一律不点击、不尝试；
   连带生成的 n 方页面即使不符合预期，也只汇报、不删除。

## Notes / gotchas

- **页面随实体控件生成**：页面内容取决于实体配置的显示控件，
  创建前可提醒用户先在实体设计器确认显示控件配置。
- **右键菜单降级路线**见 Step 3；不要反复硬试右键。
- **ref 时效性（Trae）**：弹窗出现/资源树刷新后旧 ref 失效，重新取。
- **CDP 超时（仅 WorkBuddy）**：点击前 focus + sleep 约 2 秒。
- **衔接**：页面创建后进入表单设计器，可用
  `ynu-eos8-form-basic-operations` 熟悉画布操作、
  `ynu-eos8-form-common-settings` 配置基础设置。
