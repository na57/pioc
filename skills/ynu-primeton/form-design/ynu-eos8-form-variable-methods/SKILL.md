# 变量与方法（EOS8 表单设计器，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 表单设计器中添加**变量与方法**。
官方描述：点击**表单设置 ⇒ 高级设置**，可以添加变量和方法。

本 skill 为聚合型，含 2 项操作（执行时按用户指定的单项走对应小节即可，不要求每次全跑）：

1. **变量**：相当于 Vue 中 `data(){}` 下定义的变量。为避免和内置变量重名，
   变量名会**自动加上 `v_` 前缀**；可以写默认值，也可以通过代码赋值；
   直接通过 `this.v_XXX` 访问。在组件配置区绑定变量时，
   可直接在**变量标签**中选择定义的变量进行绑定。
2. **方法**：相当于 Vue 中 `methods` 中定义的函数方法。
   可声明一个接受参数、执行特定代码块或返回值的函数；
   把一段复杂代码逻辑封装成方法，调用时通过 `this.方法名(参数)`。

流程概览：
确认 IDE 已登录 → AskUserQuestion 确认目标表单与要新增的变量/方法 →
表单设置 → 高级设置 → 走对应小节 → 以界面实际结果验证汇报。

**删除红线（本 skill 核心安全约束）**：变量/方法列表旁可能出现
「删除」图标——本 skill **严禁点击任何删除图标**，
删除操作一律由用户手动决定。

**作用域铁律**：仅在当前已打开的表单设计器内操作，不碰无关表单与资源。

## When to use

- 用户想在表单里定义一个可绑定到组件的变量。
- 用户想把一段复杂代码逻辑封装成方法供表单内调用。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` → **WorkBuddy 模式**。
- 工具列表含 integrated_code_mode 的 `Exec`（`await tools.browser_*`）→ **Trae 模式**。
- 两者都没有 → 提示用户启用对应浏览器扩展，终止流程。

## 参数

- **目标表单**（必填）：在哪个表单设计器中操作。
- **操作项**（必填）：新增变量 / 新增方法（或两者）。
- **变量名与默认值**（新增变量时必填）。
- **方法名、参数与方法体代码**（新增方法时必填）：代码须先经用户确认再写入。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 作用域确认（AskUserQuestion，必经）

确认：「将在表单 <表单名> 的表单设置 → 高级设置中新增 <变量/方法>，是否继续？」
新增方法时附上待写入的代码请用户确认。

### Step 3 — 打开变量与方法区

1. 点击**表单设置**。
2. 进入**高级设置**。
3. 定位**变量与方法**区（变量列表、方法列表与新增入口）。

### Step 4 — 操作项 1：新增变量

1. 点击新增变量，填写变量名与默认值。
2. 注意：系统会自动加上 `v_` 前缀，无需手写前缀。
3. 保存。
4. 验证：变量出现在列表中（名称带 `v_` 前缀）；
   如需绑定组件，在组件配置区**变量标签**中可见并可选。

### Step 5 — 操作项 2：新增方法

1. 点击新增方法，填写方法名、参数与方法体代码。
2. 保存。
3. 验证：方法出现在方法列表中；
   后续调用方式为 `this.<方法名>(参数)`。

### Step 6 — 汇报

汇报新增的变量/方法名称、默认值或代码摘要、验证结果；
提醒访问方式（变量 `this.v_XXX`，方法 `this.方法名(参数)`）。

## 不变量

1. **代码确认红线**：方法体等要写入的代码必须先经用户确认，严禁代用户随手写逻辑。
2. **删除红线**：变量/方法列表旁的「删除」图标严禁点击。
3. **行动后验证**：以列表实际状态为准，不以点击成功为准。
4. **失败即停**：入口找不到或步骤两次失败即停，向用户汇报现状。
5. **作用域铁律**：只操作变量与方法区，不改表单其他配置。

## Notes / gotchas

- **`v_` 前缀自动添加**：实际变量名为 `v_<输入名>`，代码中用 `this.v_XXX` 访问。
- **绑定入口**：组件配置区绑定变量时，直接在**变量标签**中选择定义的变量。
- **代码编辑器输入风险**：方法体编辑器可能有自动补全/格式化，写入后读回比对，不一致先修正再保存。
- **ref 时效性（Trae）**：快照变化后旧 ref 失效，重新取。
- **CDP 超时（仅 WorkBuddy）**：点击前 focus + sleep 约 2 秒。
- **细节待人工核对**：新增变量/方法的编辑弹窗具体字段与控件形态文档未展开，以实际界面为准。
