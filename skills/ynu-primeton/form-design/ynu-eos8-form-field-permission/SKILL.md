# 字段权限（EOS8 表单设计器，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 表单设计器中配置**字段权限**。
官方描述：在表单内配置字段权限后，可同时控制表单和视图内该字段的使用权限，且只有授权的角色可以进行对应字段的查看使用。

本 skill 为聚合型，含 4 项操作（执行时按用户指定的单项走对应小节即可，不要求每次全跑）：

1. **字段授权**：表单页面 → 表单设置 → 字段权限，对需要设置的字段开启控制。
2. **导入**（AFC 应用管理 → 资源管理，非表单设计器内）：把表单中已开启控制的字段导入资源分组。
3. **角色授权**（角色管理，非表单设计器内）：给角色配置字段权限。
4. **快捷授权**（表单设置 → 字段权限 → 授权按钮）：直接进行角色授权。

流程概览：
确认 IDE 已登录 → AskUserQuestion 确认目标表单与操作项 → 走对应小节 → 以界面实际结果验证汇报。

**作用域铁律**：仅在当前已打开的表单设计器（及操作项 2/3 指定的管理页面）内操作，不碰无关表单与资源。

## When to use

- 用户想给表单中某些字段开启权限控制。
- 用户想把已开启控制的字段导入资源分组（AFC 资源管理）。
- 用户想给角色授权字段权限（角色管理或表单内快捷授权）。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` → **WorkBuddy 模式**。
- 工具列表含 integrated_code_mode 的 `Exec`（`await tools.browser_*`）→ **Trae 模式**。
- 两者都没有 → 提示用户启用对应浏览器扩展，终止流程。

## 参数

- **目标表单**（必填）：在哪个表单设计器中操作。
- **操作项**（必填）：字段授权 / 导入 / 角色授权 / 快捷授权 之一。
- **目标字段**（按操作项）：要开启控制的字段清单。
- **目标角色 / 资源分组**（按操作项）：导入、角色授权、快捷授权所需。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 作用域确认（AskUserQuestion，必经）

确认：「将在表单 <表单名> 中执行 <操作项>（涉及字段/角色/资源分组：<清单>），是否继续？」

### Step 3 — 操作项 1：字段授权（表单内）

1. 在表单页面打开**表单设置**，点击**字段权限**。
2. 对需要设置的字段**开启控制**。
3. 验证：目标字段的权限控制已为开启状态。

### Step 4 — 操作项 2：导入（AFC 应用管理 → 资源管理）

1. 在 AFC 的**应用管理**中，选择应用，点开**资源管理**。
2. 选择资源分组后，点击**字段**，选择**导入**。
3. 导入的字段为提前在表单中开启控制的字段（先完成操作项 1 才有可导入字段）。
4. 验证：资源分组的字段列表中出现刚导入的字段。

### Step 5 — 操作项 3：角色授权（角色管理）

1. 在**角色管理**中，选择将要授权的角色进行权限配置。
2. 验证：该角色的权限配置中可见并勾选了目标字段资源。

### Step 6 — 操作项 4：快捷授权（表单内）

1. 在【表单 → 表单设置 → 字段权限】中点击**授权**按钮。
2. 授权配置项为**字段、角色、资源分组**；字段和角色允许多选，且默认字段为已经开启控制的字段。
3. 验证：授权保存成功，配置回显与所选一致。

### Step 7 — 汇报

汇报本次操作结果（开启了哪些字段控制、导入/授权是否成功、验证证据）。

## 不变量

1. **行动后验证**：以界面实际状态（开关/列表/回显）为准，不以点击成功为准。
2. **失败即停**：入口找不到或步骤两次失败即停，向用户汇报现状。
3. **作用域铁律**：不碰无关表单与资源；操作项 2/3 只在文档指定的管理页面内做文档所述操作，不做其他增删改。
4. **跨页红线**：角色管理/资源管理属于平台管理端，严禁顺手修改其他应用、角色或资源分组。

## Notes / gotchas

- **角色授权看不到「字段」选项**：检查业务字典中「资源类型」字典是否存在「字段」字典项，没有需手动添加【column/字段】（文档注意事项）。
- **导入为空**：说明目标表单尚未开启字段控制，先走操作项 1。
- **ref 时效性（Trae）**：快照变化后旧 ref 失效，重新取。
- **CDP 超时（仅 WorkBuddy）**：点击前 focus + sleep 约 2 秒。
- **细节待人工核对**：文档对「开启控制」的具体控件形态（开关位置/文案）描述较简，执行时以实际界面为准。
