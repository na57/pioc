# 监听与计算属性（EOS8 表单设计器，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 表单设计器中添加**监听与计算属性**。
官方描述：点击**表单设置 ⇒ 高级设置**，可以添加监听和计算属性。

本 skill 为聚合型，含 2 项操作（执行时按用户指定的单项走对应小节即可，不要求每次全跑）：

1. **监听**：相当于 Vue 中的 `watch` 属性。监听 `formData` 中某个属性值变化，
   执行相应的回调函数；支持**立即执行**、
   **深度监听**（监听对象时，可监听到对象内部数据的修改）、
   **防抖配置**（持续触发事件时，在设置的时间间隔内只执行一次操作）。
2. **计算属性**：相当于 Vue 中的 `computed` 属性。可以写 `get()`、`set()` 函数；
   定义依赖于其他数据属性的属性，当依赖的数据变化时自动更新；
   一般只需写 `get()` 获取计算值，需要反向改值时写 `set()`；
   通过 `this.c_XXX` 访问定义的属性。

官方计算属性示例代码：

```javascript
fullName: {
  get: function () {
    return this.firstName + ' ' + this.lastName
  },
  set: function (newValue) {
    var names = newValue.split(' ')
    this.firstName = names[0]
    this.lastName = names[names.length - 1]
  }
}
```

流程概览：
确认 IDE 已登录 → AskUserQuestion 确认目标表单与要新增的监听/计算属性及代码
（代码必须经用户确认）→ 高级设置中新增并保存 → 以运行时实际效果验证汇报。

**删除红线（本 skill 核心安全约束）**：监听/计算属性列表旁可能出现
「删除」图标——本 skill **严禁点击任何删除图标**，
删除操作一律由用户手动决定。

**作用域铁律**：仅在当前已打开的表单设计器内操作，不碰无关表单与资源。

## When to use

- 用户想监听 `formData` 某字段变化并执行回调（联动、级联、防抖搜索等）。
- 用户想定义一个由其他数据计算得来的属性（拼接、汇总等）。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` → **WorkBuddy 模式**。
- 工具列表含 integrated_code_mode 的 `Exec`（`await tools.browser_*`）→ **Trae 模式**。
- 两者都没有 → 提示用户启用对应浏览器扩展，终止流程。

## 参数

- **目标表单**（必填）：在哪个表单设计器中操作。
- **操作项**（必填）：新增监听 / 新增计算属性（或两者）。
- **监听目标字段与配置**（新增监听时必填）：监听的 `formData` 属性、
  是否立即执行、是否深度监听、防抖间隔。
- **回调代码**（新增监听时必填）：须先经用户确认再写入。
- **计算属性名与 get/set 代码**（新增计算属性时必填）：须先经用户确认再写入。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 作用域与代码确认（AskUserQuestion，必经）

1. 确认：「将在表单 <表单名> 的表单设置 → 高级设置中新增 <监听/计算属性>，是否继续？」
2. 附上待写入的回调/get/set 代码，请用户确认。

### Step 3 — 打开监听与计算属性区

1. 点击**表单设置**。
2. 进入**高级设置**。
3. 定位**监听与计算属性**区。

### Step 4 — 操作项 1：新增监听

1. 点击新增监听，选择监听目标（`formData` 中某属性）。
2. 按需配置：**立即执行**、**深度监听**、**防抖时间间隔**。
3. 写入经用户确认的回调代码并保存。
4. 验证：监听出现在列表中；运行表单改变目标属性值，
   回调按预期触发（含防抖间隔行为）。

### Step 5 — 操作项 2：新增计算属性

1. 点击新增计算属性，填写属性名。
2. 写入经用户确认的 `get()`（必要时含 `set()`）代码并保存。
3. 验证：计算属性出现在列表中；运行表单改变依赖数据，
   通过 `this.c_XXX` 取到的值自动更新。

### Step 6 — 汇报

汇报新增的监听/计算属性、配置项（立即执行/深度/防抖）、代码摘要与验证证据。

## 不变量

1. **代码确认红线**：回调与 get/set 代码必须先经用户确认，严禁代用户随手写逻辑。
2. **删除红线**：监听/计算属性列表旁的「删除」图标严禁点击。
3. **行动后验证**：以运行时实际触发/取值结果为准，不以保存成功为准。
4. **失败即停**：入口找不到或写入两次失败即停，向用户汇报现状。
5. **作用域铁律**：只新增用户指定的监听/计算属性，不改、不删已有项。

## Notes / gotchas

- **监听对象内部变化需开深度监听**：监听对象时默认监听不到内部数据修改，需勾选深度监听。
- **防抖避免高频触发**：持续触发场景（如输入联想）务必配置防抖间隔。
- **计算属性访问前缀**：通过 `this.c_XXX` 访问（`c_` 前缀由平台生成，类似变量的 `v_` 前缀）。
- **代码编辑器输入风险**：编辑器可能有自动补全/格式化，写入后读回与确认稿比对，不一致先修正再保存。
- **ref 时效性（Trae）**：快照变化后旧 ref 失效，重新取。
- **CDP 超时（仅 WorkBuddy）**：点击前 focus + sleep 约 2 秒。
- **细节待人工核对**：新增监听/计算属性的编辑弹窗具体字段与控件形态文档以截图为主、文字较简，执行时以实际界面为准。
