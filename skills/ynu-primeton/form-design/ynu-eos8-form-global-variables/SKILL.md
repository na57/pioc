# 参数与全局变量（EOS8 表单设计器，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 表单设计器中添加**参数与全局变量**。
官方描述：点击**表单设置 ⇒ 高级设置**，可以添加参数和全局变量。

本 skill 为聚合型，含 5 项（执行时按用户指定的单项走对应小节即可，不要求每次全跑）：

1. **参数**：相当于 Vue 中 `props` 的属性，用于从父组件向子组件传递数据，
   子组件接收后在其模板或逻辑中使用。在组件配置区绑定变量时，
   可直接在**参数标签**中选择定义的参数进行绑定。
2. **场景-视图给表单传参**：视图中新增数据时把参数传给表单。
3. **场景-表单作为资源容器接受参数**：资源容器引用表单时传参。
4. **场景-菜单给表单传参**：表单作为菜单页面时由菜单传参。
5. **全局变量**：将一个参数/变量/字段设置为全局变量，
   子组件可通过 `this.GlobalVariable.[变量名]` 访问，使跨页面传递参数更便捷。

流程概览：
确认 IDE 已登录 → AskUserQuestion 确认目标表单与操作项 →
表单设置 → 高级设置 → 走对应小节 → 以界面实际结果验证汇报。

**删除红线（本 skill 核心安全约束）**：参数/全局变量列表旁可能出现
「删除」图标——本 skill **严禁点击任何删除图标**，
删除操作一律由用户手动决定。

**作用域铁律**：仅在当前已打开的表单设计器（及场景涉及的视图/资源容器/菜单配置处）内操作，不碰无关表单与资源。

## When to use

- 用户想给表单定义入参（由视图、资源容器或菜单传入）。
- 用户想做跨页面传参（全局变量）。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` → **WorkBuddy 模式**。
- 工具列表含 integrated_code_mode 的 `Exec`（`await tools.browser_*`）→ **Trae 模式**。
- 两者都没有 → 提示用户启用对应浏览器扩展，终止流程。

## 参数

- **目标表单**（必填）：在哪个表单设计器中操作。
- **操作项**（必填）：新增参数 / 视图传参 / 资源容器传参 / 菜单传参 / 全局变量 之一。
- **参数或全局变量名与默认值**（必填）。
- **场景配置细节**（按操作项）：绑定的控件、目标视图/资源容器/菜单名称等。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 作用域确认（AskUserQuestion，必经）

确认：「将在表单 <表单名> 的表单设置 → 高级设置中执行 <操作项>（涉及 <参数/变量名>），是否继续？」

### Step 3 — 打开参数与全局变量区

1. 点击**表单设置**。
2. 进入**高级设置**。
3. 定位**参数与全局变量**区。

### Step 4 — 操作项 1：新增参数

1. 在高级设置中新增参数：填写参数名称与默认值。
2. 验证：参数出现在列表中；组件配置区**参数标签**中可见并可选。

### Step 5 — 操作项 2：场景-视图给表单传参

官方示例（参数名 `form_source`，用于「数据来源」控件默认值）：

1. 在表单设置—高级设置添加参数，名称如 `form_source`，默认值为「无」。
2. 给目标控件（如数据来源输入框）的默认值绑定该参数。
3. 在**视图 tab** 下的视图设置—高级设置添加视图参数
   （如 `page_source`，默认值「视图」）。
4. 在视图设置的动作设置—工具栏表格上的「编辑/新增行」动作中
   添加参数：参数名与表单参数对应，值为 `this.page_source`。
5. 验证：视图中新增数据时，表单内绑定控件的默认值显示为视图传入的值。

### Step 6 — 操作项 3：场景-表单作为资源容器接受参数

1. 步骤 1-2 同操作项 2（先在表单高级设置添加参数，再给控件默认值绑定参数）。
2. 在引用表单的**资源容器**中的高级—扩展属性，
   添加同名属性（如 `form_source`）与传入值（如「资源容器」）。
3. 验证：资源容器内打开表单时，绑定控件默认值为传入值。

### Step 7 — 操作项 4：场景-菜单给表单传参

1. 步骤 1-2 同操作项 2。
2. 新建资源页面，选择**低开资源**，输入参数：如 `form_source=菜单`。
3. 配置菜单以及角色授权。
4. 刷新页面即可。
5. 验证：通过菜单打开表单时，绑定控件默认值为菜单传入值。

### Step 8 — 操作项 5：全局变量

1. 在父组件中**定义全局变量**（官方场景：选择供应商的 `supplier_id`）。
2. **使用全局变量**：子组件/子页面中通过 `this.GlobalVariable.<变量名>` 访问；
   官方场景：在物料弹窗选择组件绑定的视图中，为物料的供应商 id 字段
   设置筛选条件，默认值为父页面定义的全局变量 `this.GlobalVariable.supplier_id`。
3. 验证：父页面改变全局变量后，子组件按新值过滤/取值。

### Step 9 — 汇报

汇报新增的参数/全局变量、场景配置结果与验证证据。

## 不变量

1. **删除红线**：参数/全局变量列表旁的「删除」图标严禁点击。
2. **行动后验证**：以界面实际状态（参数列表、绑定回显、传入值生效）为准，不以点击成功为准。
3. **失败即停**：入口找不到或步骤两次失败即停，向用户汇报现状。
4. **作用域铁律**：场景 2-4 涉及视图/资源容器/菜单配置时，只改与目标表单相关的配置项。

## Notes / gotchas

- **参数 = props**：仅父→子单向传参；跨页面便捷传参用全局变量（`this.GlobalVariable.[变量名]`）。
- **三场景共用前两步**：先定义参数并绑定控件默认值，再在对应入口（视图参数 / 资源容器扩展属性 / 低开资源参数）传值。
- **菜单传参需要授权**：场景 4 的「配置菜单以及角色授权」不可省，否则菜单打开可能无权限。
- **ref 时效性（Trae）**：快照变化后旧 ref 失效，重新取。
- **CDP 超时（仅 WorkBuddy）**：点击前 focus + sleep 约 2 秒。
- **细节待人工核对**：文档示例截图较多但文字较简（如「编辑新增行添加参数」的确切入口文案），执行时以实际界面为准。
