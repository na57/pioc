# 公共方法（EOS8 表单设计器，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 表单设计器中管理**公共方法**。
官方描述：公共方法可以在**当前应用下所有表单中调用**，
为避免方法名冲突请谨慎起名。入口：点击**表单设置 ⇒ 高级设置**，
可以添加公共方法。

本 skill 为聚合型，含 3 项操作（执行时按用户指定的单项走对应小节即可，不要求每次全跑）：

1. **新增公共方法**：调用时需加 `this.PubApi.` 前缀（如 `this.PubApi.test()`）。
2. **导入与导出**：导出当前应用已添加的公共方法；在其他应用中导入。
3. **刷新**：点击刷新图标，更新当前应用中最新的公共方法。

流程概览：
确认 IDE 已登录 → AskUserQuestion 确认目标表单与操作项 →
表单设置 → 高级设置 → 公共方法区 → 走对应小节 → 以界面实际结果验证汇报。

**删除红线（本 skill 核心安全约束）**：公共方法列表旁可能出现
「删除」图标——本 skill **严禁点击任何删除图标**，
删除操作一律由用户手动决定。

**作用域铁律**：仅在当前已打开的表单设计器内操作，不碰无关表单与资源。

## When to use

- 用户想新增一个跨表单复用的公共方法。
- 用户想把公共方法导出带走，或导入到其他应用。
- 用户想刷新公共方法列表获取应用内最新版本。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` → **WorkBuddy 模式**。
- 工具列表含 integrated_code_mode 的 `Exec`（`await tools.browser_*`）→ **Trae 模式**。
- 两者都没有 → 提示用户启用对应浏览器扩展，终止流程。

## 参数

- **目标表单**（必填）：在哪个表单设计器中操作。
- **操作项**（必填）：新增 / 导入与导出 / 刷新 之一。
- **方法名与方法体**（新增时必填）：经用户确认后的名称与代码。
- **导入文件**（导入时按需）：已下载的公共方法文件。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 作用域确认（AskUserQuestion，必经）

确认：「将在表单 <表单名> 的表单设置 → 高级设置中执行 <操作项>，是否继续？」
新增时同时附上方法名与方法体代码请用户确认。

### Step 3 — 打开公共方法区

1. 点击**表单设置**。
2. 进入**高级设置**。
3. 定位**公共方法**区（方法列表与新增/导入/导出/刷新操作）。

### Step 4 — 操作项 1：新增公共方法

1. 点击新增入口，填写方法名、方法体。
2. 方法名避免与现有方法重名（公共方法在当前应用下所有表单中调用，冲突风险）。
3. 保存。
4. 验证：方法出现在公共方法列表中。

### Step 5 — 操作项 2：导入与导出

1. **导出**：点击**导出**按钮，导出当前应用已添加的公共方法（产出下载文件）。
2. **导入**：在其他应用中点击**导入**按钮，选择已下载的公共方法文件导入。
3. 验证：导出有文件产出；导入后方法出现在目标应用的公共方法列表。

### Step 6 — 操作项 3：刷新

1. 点击**刷新**图标。
2. 验证：列表更新为当前应用中最新的公共方法。

### Step 7 — 汇报

汇报本次变更（新增了什么方法、导入导出结果、列表现状），
并提醒调用方式为 `this.PubApi.<方法名>()`。

## 不变量

1. **删除红线**：公共方法列表旁的「删除」图标严禁点击。
2. **代码确认红线**：方法体代码须先经用户确认再写入，严禁代用户随手写逻辑。
3. **行动后验证**：以列表实际状态为准，不以点击成功为准。
4. **失败即停**：入口找不到或步骤两次失败即停，向用户汇报现状。
5. **作用域铁律**：只操作公共方法区，不改表单其他配置。

## Notes / gotchas

- **命名冲突**：公共方法应用级共享，起名前先查列表是否已有同名方法。
- **调用前缀**：调用时需要加 `this.PubApi.` 前缀，如 `this.PubApi.test()`。
- **导入导出涉及文件下载/上传对话框**：浏览器自动化对系统文件对话框能力有限，必要时转用户手动选择文件。
- **ref 时效性（Trae）**：快照变化后旧 ref 失效，重新取。
- **CDP 超时（仅 WorkBuddy）**：点击前 focus + sleep 约 2 秒。
- **细节待人工核对**：新增公共方法的编辑器具体形态（参数、返回值等字段）文档未展开，以实际界面为准。
