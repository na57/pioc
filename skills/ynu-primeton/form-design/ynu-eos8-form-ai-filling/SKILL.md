# 智能填单配置（EOS8 表单设计器，WorkBuddy / Trae 双运行时兼容）

## Overview

在 EOS8 表单设计器的**表单设置 →「智能填单」页签**中配置
AI 辅助填写能力。官方描述：启用后，业务人员在填写表单时
点击「智能填单」入口，用自然语言描述业务内容，系统自动识别
描述中的关键信息并填入对应表单字段；用户仍可检查和修改结果，
再按原有流程保存或提交。

例如用户输入「张三明天下午请假半天，原因是家中有事」，系统
可根据表单配置自动识别申请人、请假时间、请假时长、请假原因
等信息，减少手动录入和反复查找字段的工作量。

**适用场景**：字段较多、信息来源复杂、录入内容相对标准化的
业务表单（请假申请、报销申请、客户登记、工单创建、事项申报等
高频新增单据）。**不适合**完全依赖人工判断、字段含义不清晰、
数据来源不规范、或必须逐项人工确认才能录入的场景。

流程概览：
确认 IDE 已登录 → AskUserQuestion 确认目标表单与配置项 →
表单设置 → 智能填单页签 → 启用开关 → 选择智能体 →
配置参与填单字段 → 完善字段描述 → 选择匹配方式 →
设置引导示例 → 保存并发布表单 → 验证。

**作用域铁律**：仅在表单设计器中**当前打开表单**的
「智能填单」页签内操作，不碰其他表单、不碰其他设置页签。

## When to use

- 用户要为表单启用/配置智能填单（AI 辅助填写）。
- 用户说「配置智能填单」「开启 AI 填单」「给表单加智能填单」
  「设置填单智能体」。
- 用户要调整参与填单的字段、字段描述、匹配方式或引导示例。

## Step 0 — 运行时探测（必须最先执行）

- 工具列表含 `mcp__browser__browsers_list` → **WorkBuddy 模式**：
  用 mcp__browser__* 工具操作；take_snapshot 取可交互元素快照；
  ref 有时效性，页面重渲染后须重取快照；点击前可先对目标元素
  focus 并 sleep 约 2 秒，避免 CDP 超时。
- 工具列表含 integrated_code_mode 的 `Exec`
  （`await tools.browser_*` 可用）→ **Trae 模式**：
  用该运行时操作；同样注意快照 ref 时效性，每次操作前重取快照。
- 两者都不可用 → 终止并告知用户当前无可用浏览器运行时。

## 参数

- **目标表单**（必填）：当前打开的表单设计器中的表单。
- **要配置的项**（必填，可多项）：`启用开关` / `选择智能体` /
  `字段配置` / `字段描述` / `匹配方式` / `引导示例`；
  未指定的项一律不碰。
- **字段清单与描述**（按需）：配置字段时由用户提供要加入的
  字段名及对应描述文本。
- **引导示例文本**（按需）：由用户提供或确认。

缺参数 → `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 1 — 确认 IDE 已打开且已登录

复用 `ynu-lowcode-login` 等产出的 IDE 标签页/viewId；
未登录先执行 `ynu-lowcode-login`。

### Step 2 — 作用域确认（AskUserQuestion，必经）

确认：「将在表单 <表单名> 的智能填单页签中配置
<配置项列表>，是否继续？」

### Step 3 — 打开表单设置 →「智能填单」页签

1. 打开需要配置的表单（表单设计器已打开目标表单）。
2. 点击顶部「表单设置」，切换到**「智能填单」页签**。
3. 重取快照，读出当前配置状态（是否已启用、已选智能体、
   已配置字段），与用户确认的目标值对照。

### Step 4 — 按配置项逐项配置

#### 4.1 启用智能填单

打开「启用」开关。启用后该表单在运行时会显示智能填单入口；
未启用时业务人员不会看到该功能入口。

#### 4.2 选择智能体

1. 点击「选择智能体」或「切换智能体」，从已有智能体列表中
   选择一个用于当前表单的智能体。智能体决定系统如何理解
   用户输入、如何处理业务语义、如何返回可填入表单的数据。
2. 选择原则：名称和描述与当前业务表单最匹配的智能体。
3. ⚠️ **列表为空（新部署环境）**：智能体列表数据来自平台
   AI 中心的「我的智能体」。若没有可选智能体，先使用产品
   提供的默认「智能填单」智能体 zip 包：在平台 AI 中心进入
   「我的智能体」，通过导入功能导入该 zip 包（默认智能填单
   zip 包在文档页有「点击下载」链接），导入完成后回到本页
   重新选择智能体。
4. ⚠️ **导入后必须改模型配置**：默认智能填单智能体需按当前
   平台已配置的大模型修改模型设置——点击智能填单智能体卡片
   进入工作流智能体开发页，在「基本信息-编排-模型设置」下
   选择当前平台已有模型；再切换到工作流模块，点击大模型图元
   修改选择平台已有模型，保存并发布该工作流。
   （AI 中心的智能体导入/模型配置不在本 skill 操作范围内，
   需跳转平台 AI 中心时引导用户或另行处理。）

#### 4.3 配置参与填单的字段

在「字段配置」区域选择需要由 AI 辅助填写的字段。系统列出
当前表单可配置的字段，可添加字段、移除字段，或只保留重点
字段。建议优先选择：

- 用户经常漏填或填错的字段；
- 能从自然语言中直接识别出来的字段；
- 有明确选项、字典或关联数据的字段；
- 对业务处理效率影响较大的关键字段。

**不建议把所有字段无差别加入配置**——字段越清晰，
智能填单结果越容易检查和使用。

#### 4.4 完善字段描述

展开某个字段后填写「字段描述」，帮助智能体理解该字段的
含义和填写规则。描述建议写成业务人员能理解的规则，例如：

- 「请填写申请人的姓名，用户输入『我』或『本人』时优先
  匹配当前登录人。」
- 「请根据用户描述识别请假开始时间，支持『明天上午』
  『下周一下午』等表达。」
- 「请根据客户名称或简称匹配客户档案。」

附件组件字段也支持 AI 自动填写，在附件字段描述中添加理解
规则即可，例如：「用于将用户对话中上传的请假病例单的附件 ID
赋值到当前字段」。

#### 4.5 选择匹配方式

部分字段支持选择「AI 匹配」或「数据库匹配」：

- **AI 匹配**：适合识别口语化、模糊描述、同义词、别名等
  内容（文本、备注、日期、金额、数量等自由输入/可提取字段）。
- **数据库匹配**：适合从系统已有数据中查找准确选项（字典、
  人员、组织、岗位、关联表数据等需写入系统已有对象或固定
  选项的字段）。

选择原则：字段必须写入系统已有对象或固定选项 → 数据库匹配；
字段主要是文本内容或需要理解语义 → AI 匹配；不确定 →
先按默认配置试用，再根据识别效果调整。

下拉选择绑定业务字典的字段可选 AI 匹配，系统会自动将字段项
信息放入字段描述中供智能体匹配。⚠️ **字典项内容过多时不要
用 AI 匹配**——会增大 AI 对话报文，导致关键信息丢失或
响应变慢。

#### 4.6 设置引导示例

在「引导示例」中填写一段示例说明，帮助业务人员理解可以怎样
输入内容，也帮助智能体理解当前表单的使用方式。示例：

- 「用户描述中提到的申请人、申请日期、申请原因、所属部门等
  信息，可自动识别并填入当前表单。」
- 「输入『张三明天下午请假半天，原因是家中有事』，系统自动
  识别申请人、请假时间、请假时长和请假原因。」

### Step 5 — 保存并发布表单，验证

1. 配置完成后**保存表单配置**（保存并发布）。
2. **验证**：业务人员再次打开视图，点击新增按钮打开对应
   表单弹窗时，应能看到「智能填单」入口。设计器内验证以
   保存成功 + 智能填单页签配置项回读一致为准；运行时效果
   （对话框识别填充）请用户在实际填报页面确认。
3. 向用户汇报：启用状态、所选智能体、参与填单字段数、
   匹配方式分布、引导示例是否已写。

## 不变量

1. **作用域铁律**：仅在当前表单的「智能填单」页签内操作，
   不碰其他表单、不改其他设置页签。
2. **删除红线**：字段配置区的「移除字段」仅在用户明确指定
   移除某字段时才执行；其余任何「删除」按钮/图标严禁点击。
3. **行动后验证**：以保存后页签回读的配置为准，不以点击
   成功为准。
4. **失败即停**：同一关键操作两次尝试仍失败 → 停止并报告
   现场，不盲目重试、不绕路。

## Notes / gotchas

- **智能填单不替代人工确认**：保存或提交前业务人员务必检查
  关键字段（人员、组织、关联数据、日期、金额等）——配置完成
  后提醒用户这一点；对强校验、强合规或高风险业务，智能填单
  只作初稿生成工具。
- **识别效果不佳的排查顺序**：字段配置 → 字段描述 → 匹配方式
  → 智能体选择。字段名称和字段描述会直接影响识别效果，
  建议用清晰、贴近业务的名称和说明。
- **数据库匹配依赖已有数据**：人员、组织、字典或关联数据
  不存在时无法准确匹配。
- **日期/金额/数量字段**：描述中提供明确表达，避免「最近」
  「差不多」「大概」等模糊说法。
- **智能体导入与模型配置在 AI 中心**：不在表单设计器内，
  需要时引导用户跳转处理，不在本 skill 中越界操作。
- **ref 时效性（Trae）**：页签切换、开关切换、字段添加后
  页面重渲染，旧 ref 失效，点击前重新获取快照。
- **CDP 超时（仅 WorkBuddy）**：点击前先 focus 目标元素
  并 sleep 约 2 秒再 click。
- **弹层定位**：智能体选择列表等弹层为 Ant Design 弹层，
  渲染在 body 下，定位时在整页快照中找。
